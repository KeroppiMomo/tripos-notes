Basic feasible solution $\implies$ extreme point

Let $\v x\in\mathcal{X}(\v b)$ be a basic feasible solution, and write $\v x = t\v y + (1-t)\v z$ where $\v y,\v z\in\mathcal{X}(\v b)$ and $t\in(0,1)$.

If $x_i = 0$ for some index $i = 1,2,\ldots,n$, then since $\v y,\v z\geq \v 0$, we have $y_i = z_i = 0$.

Since $\v x$ is a basic feasible solution, at least $(n-m)$ entrices of $\v x$ are non-zero, and therefore same for $\v y$ and $\v z$. Hence $\v y$ and $\v z$ are basic solutions corresponding to the same basis as $\v x$.

Each basis leads to a unique basic solution, so we must have $\v x=\v y=\v z$. Therefore $\v x$ is an extreme point.

Extreme point $\implies$ basic feasible solution

Suppose $\v x\in\mathcal{X}(\v b)$ is not a basic feasible solution.

This means there are more than $m$ non-zero indices $i_1, i_2, \ldots, i_r$ of $\v x$, where $r>m$. By Assumption A, the rank of $A$ is $m$, so the columns $\v A_{i_1}, \v A_{i_2}, \ldots, \v A_{i_r}$ are linearly dependent. There exists $w_1,\ldots,w_r\in\R$, not all zero, such that $$ \begin{align*} w_1 \v A_{i_1} + w_2 \v A_{i_2} + \ldots + w_r \v A_{i_r} = \v 0. \end{align*} $$

Construct $\vhat w\in\R^n$ such that $$ \begin{align*} \hat w_i = \begin{cases} w_k, &\text{if } i = i_k \text{ for some } k, \\ 0, &\text{otherwise}. \end{cases} \end{align*} $$ By construction, $A\vhat w = 0$, so $A(\v x \pm \epsilon \vhat w) = \v b$ for any $\epsilon$.

Choose $\epsilon$ to be small enough ($\epsilon<\min\set{x_{i_1}, x_{i_2}, \ldots, x_{i_r}}/\max\set{|w_1|,|w_2|,\ldots,|w_r|}$) so that $\v y = \v x + \epsilon\vhat w, \v z=\v x - \epsilon\vhat w\geq 0$ Therefore $\v x = (\v y+\v z)/2$ with $\v y,\v z\in\mathcal{X}(\v b)$ so $\v x$ is not an extreme point.
