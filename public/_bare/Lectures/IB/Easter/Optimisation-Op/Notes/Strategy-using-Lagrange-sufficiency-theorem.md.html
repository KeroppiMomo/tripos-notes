To solve

Problem

$$ \begin{align*} \text{Minimise } &f(\v x) \\ \text{over } &\v x\in\mathcal{X} \\ \text{subject to } &h(\v x) \leq \v b, \end{align*} $$

  1. Add a slack variable to change the inequality constraint to an equality:

Problem

$$ \begin{align*} \text{Minimise } &f(\v x) \\ \text{over } &\v x\in\mathcal{X}, \\ &\v s\in\R^m, \v s\geq 0 \\ \text{subject to } &h(\v x) + \v s = \v b. \end{align*} $$

  1. Set the Lagrangian $$ \begin{align*} L(\v x,\v s,\v \lambda) = f(\v x) - \v \lambda^T (h(\v x) + \v s - \v b). \end{align*} $$

  2. Find $$ \begin{align*} \Lambda = \sb{\v \lambda\in\R^m}{\inf_{\v x\in\mathcal{X},\ \v s\geq 0} L(\v x,\v s,\v \lambda) > -\infty}. \end{align*} $$

  3. For each $\v \lambda\in\Lambda$, find the minimiser $\v x^\ast(\v \lambda), \v s^\ast(\v \lambda)$, i.e. $$ \begin{align*} L(\v x^\ast(\v \lambda), \v s^\ast(\v \lambda), \v \lambda) = \inf_{x\in\mathcal{X},\ \v s\geq 0} L(\v x,\v s,\v \lambda). \end{align*} $$

  4. Find $\v \lambda^\ast$ such that $(\v x^\ast(\v \lambda^\ast), \v s^\ast(\v \lambda^\ast))$ is feasible, i.e. $\v x^\ast(\v \lambda^\ast)\in\mathcal{X}$, $\v s^\ast(\v \lambda^\ast)\geq 0$, and $h(\v x^\ast(\v \lambda)) + \v s^\ast(\v \lambda^\ast) = \v b$.

  5. By Lagrange sufficiency theorem, $\v x^\ast(\v \lambda^{\ast})$ is optimal for the original constrained problem.
