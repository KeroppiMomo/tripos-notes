Let $f: \R^n\to\R$ be a convex objective function and $f_i: \R^n \to \R$ be linear for $1\leq i\leq m$, i.e. $f_i(\v x) = \v a_i^T \v x - b_i$.

Problem

$$ \begin{align*} \text{Minimise } & f(\v x) \\ \text{over } & \v x\in\R^n \\ \text{subject to } & f_i(\v x) \leq 0 \quad\text{for } 1\leq i\leq m. \end{align*} $$

We convert this to an unconstrained problem

Problem

$$ \begin{align*} \text{Minimise } & f(\v x) + \sum_{i=1}^{m} \phi(f_i(\v x)) \\ \text{over } & \v x\in\R^n. \end{align*} $$

Often we pick $\phi(x) = -\log(-x)$, the logarithmic barrier function, leading to

Problem

$$ \begin{align*} \text{Minimise } & t f(\v x) + \Phi(\v x) \\ \text{over } & \v x\in\R^n \\ \text{where } &\Phi(\v x) = -\sum_{i=1}^{m} \log(-f_i(\v x)). \end{align*} $$

$t>0$ is a parameter to trade-off the relative importance of $f$ and $\Phi$.

This is a convex optimisation problem (Derivation).

Algorithm of the barrier method open_in_new

  1. Find a feasible solution $\v x$ (i.e. satisfying $f_i(\v x)\leq 0$for all $i$) and choose some $t>0$ and $\alpha>1$.

  2. Repeat until $t$ is large enough:

    1. Compute the minimiser $x^\ast(t)$ of $tf(\v x) + \Phi(\v x)$ using Newton's method with initial point $\v x$.

    2. Update $x := x^\ast(t)$ and $t:=\alpha t$.

At each $t$ update, the problem is not changed too much, so Newton's method is expected to converge quickly.
