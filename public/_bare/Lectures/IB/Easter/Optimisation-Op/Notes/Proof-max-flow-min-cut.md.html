By the previous theorem, $\delta^\ast \leq c(S)$ for all $S\subseteq V$. It suffices to find $S$ such that $c(S) = \delta^\ast$.

Let $x$ be optimal with flow $\delta^\ast$. Let $$ \begin{align*} S = \sb{i\in V}{\text{there exists an augmenting path for $x$ from $1$ to $i$}} \cup \set{1}. \end{align*} $$

Note that $n\not\in S$ since $x$ is optimal, so $(S, V\setminus S)$ is a valid cut.

From before, $$ \begin{align*} \delta^\ast = f_x(S, V\setminus S) - f_x(V\setminus S, S). \end{align*} $$ If a flow from $u\in S$ to $v\in V\setminus S$ is not full, then since there is an augmenting path from $1$ to $u$, we can extend it to construct an augmenting path from $1$ to $v$, which contradicts with $v\not\in S$. Hence every flow from vertices in $S$ to $V\setminus S$ is full, so $f_x(S, V\setminus S) = c(S)$.

Similarly, if a flow from $v\in V\setminus S$ to $u\in S$ is not zero, then we can extend the augmenting path from $1$ to $u$ further to $v$ and get a contradiction. Hence $f_x(V\setminus S, S) = 0$.

Therefore $\delta^\ast = c(S) - 0 = c(S)$ as required.
