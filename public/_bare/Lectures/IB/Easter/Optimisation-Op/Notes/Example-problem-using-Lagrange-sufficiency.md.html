Problem

$$ \begin{align*} \text{Minimise } & -x_1 - x_2 + x_3 \\ \text{subject to } & x_1^2 + x_2^2 = 4, \\ & x_1 + x_2 + x_3 = 1. \end{align*} $$

The Lagrangian is $$ \begin{align*} L(x_1,x_2,x_3,\lambda_1,\lambda_2) &= (-x_1-x_2+x_3) - \lambda_1(x_1^2 + x_2^2 - 4) - \lambda_2(x_1+x_2+x_3 - 1) \\ &= \left[(-1-\lambda_2)x_1 - \lambda_1x_1^2\right] + \left[(-1-\lambda_2)x_2 - \lambda_1 x_2^2\right] + \left[(1-\lambda_2)x_3\right] + 4\lambda_1 + \lambda_2. \end{align*} $$

We want to fix some $\v \lambda$ and minimise $L(\v x, \v \lambda)$. For minimum to exist, we need $\lambda_2=1$ since otherwise we can set $x_3\to\pm\infty$ to drive $L\to-\infty$. Similarly we need $\lambda_1 < 0$ since otherwise we can set $x_1$ or $x_2\to\pm\infty$ to drive $L\to-\infty$.

Now to minimise $$ \begin{align*} L(x_1,x_2,x_3,\lambda_1,1) = [-2x_1-\lambda_1x_1^2] + [-2x_2 - \lambda_1 x_2^2] + 4\lambda_1 + \lambda_2, \end{align*} $$ we minimise the quadratics to get $x_1=x_2=-1/\lambda_1$.

To construct a feasible solution, we set $$ \begin{align*} 4 &= x_1^2 + x_2^2 = \frac{2}{\lambda_1^2} &&\implies &\lambda_1 &= -\frac{1}{\sqrt{2}}, \\ 1 &= x_1+x_2+x_3 = 2\sqrt{2}+x_3 &&\implies &x_3 &= 1-2\sqrt{2}. \end{align*} $$

Now we apply the Lagrange sufficiency theorem: since $\v x^\ast = (x_1,x_2,x_3) = (\sqrt{2}, \sqrt{2}, 1-2\sqrt{2})$ is feasible and is a minimiser of the unconstrained problem with $(\lambda_1,\lambda_2) = (-1/\sqrt{2}, 1)$, we can conclude that $\v x^\ast$ is a minimiser of the original constrained problem.
