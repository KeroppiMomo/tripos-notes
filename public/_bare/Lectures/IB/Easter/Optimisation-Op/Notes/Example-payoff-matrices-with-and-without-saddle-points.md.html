Consider the payoff matrix $$ \begin{align*} A = \pmat{1 & 2 \\ 3 & 4}. \end{align*} $$

  • If P1 plays first, $i=2, j=1$ and the optimal value is $3$.

  • If P2 plays first, $j=1, i=2$ and the optimal value is $3$ still.

$(2,1)$ is a saddle point.

Now instead $$ \begin{align*} A = \pmat{4 & 2 \\ 1 & 3} \end{align*} $$

  • If P1 plays first, $i=1, j=2$ and the optimal value is $2$.

  • If P2 plays first, $j=2, i=2$ and the optimal value is $3$.

This payoff matrix has no saddle point.
