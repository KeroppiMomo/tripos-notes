Let $M$ be an $R$-module.

We say a subset $S\subseteq M$ freely generates $M$ if

  1. $S$ generates $M$, i.e. any $m\in M$ is a finite $R$-linear combination of $S$; and

  2. any function on $S$ to an $R$-module can be extended to an $R$-module homomorphism, i.e. for $R$-module $N$ and function $f: S\to N$, there exists an $R$-module homomorphism $ϕ_f: M\to N$ such that $ϕ_f(s) = f(s)$ for all $s\in S$.

A module $M$ is called free if it is freely generated by some $S\subseteq M$. We call $S$ a basis.
