The conjugacy action $G$ on $\mathrm{Syl}_p(G)$ gives a homomorphism $ϕ: G\to \mathrm{Sym}(\mathrm{Syl}_p(G)) \isom S_{n_p}$.

Since $G$ is simple, either $\ker(ϕ) = \set{e}$ or $G$. If $\ker(ϕ) = G$, then for all $P\in \mathrm{Syl}_p(G)$, we have $gPg\inv = P$ for all $g\in G$, so $P\lhd G$. Again by simplicity, $P = \set{e}$ or $G$. But $p\mid |G|$ so a Sylow-$p$ subgroup $P$ cannot be $\set{e}$. Meanwhile if $P = G$, then $G$ is a finite $p$-group and hence has a non-trivial and proper normal subgroup $Z(G)$, which contradicts with simplicity. Thus $\ker(ϕ) = \set{e}$. By the first isomorphism theorem, $G\isom G/\set{e} \isom \im(ϕ) \leq S_{n_p}$.

Consider the composition $$ \begin{align*} \mathrm{sgn} \circ ϕ : G \to C_2. \end{align*} $$ If this is surjective, then $\ker(\mathrm{sgn}\circ ϕ)$ has index 2 and is thus normal in $G$, so by simplicity $\ker(\mathrm{sgn}\circ ϕ) = \set{e}$ and so $G\isom C_2$, which contradicts with $G$ being non-abelian. Therefore $G\isom \im(ϕ) \leq \ker(\mathrm{sgn}) = A_{n_p}$ and $|G| \mid |A_{n_p}| = n_p!/2$ by Lagrange.
