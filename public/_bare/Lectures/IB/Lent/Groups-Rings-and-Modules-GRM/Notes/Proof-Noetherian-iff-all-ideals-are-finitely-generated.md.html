All ideals are finitely generated $\implies$ Noetherian

Suppose all ideals are finitely generated. Given a chain of ideals $I_1 \subseteq I_2 \subseteq I_3 \subseteq \ldots$, let $I = \bigcup_{n=1}^{\infty} I_n$. $I$ is an ideal, so there exists $r_1, \ldots, r_k\in R$ that generate it. But $r_i\in I_{n_i}$ for some $n_i$ so for large enough $N$ (say $N = \max_i\set{n_i}$), $I_N = I_{N+1} = I_{N+2} = \ldots = I$.

Noetherian $\implies$ all ideals are finitely generated

Suppose an ideal $I\lhd R$ is not finitely generated. Pick some $r_1\in I$, $r_2\in I\setminus (r_1)$, $r_3\in I\setminus (r_1, r_2)$ and so on. At each step $I \neq (r_1, \ldots, r_k)$ since $I$ is not finitely generated so the process never terminates. Then we get the proper chain $$ \begin{align*} (r_1) \subset (r_1, r_2) \subset (r_1, r_2, r_3) \subset \ldots \end{align*} $$ so $R$ is not Noetherian.
