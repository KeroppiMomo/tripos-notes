$R/I$ is a quotient group with respect to addition.

Multiplication is well-defined. To see this, suppose $r_1 + I = r_1' + I$ and $r_2 + I = r_2' + I$. Then $r_1' = r_1 + a$ and $r_2' = r_2 + b$ for some $a,b\in I$. So $$ \begin{align*} r_1' r_2' + I = r_1 r_2 + \underbrace{ar_2 + r_1b + ab}_{\in I} + I = r_1 r_2 + I \end{align*} $$ by the absorbing property.

The rest is straightforward.
