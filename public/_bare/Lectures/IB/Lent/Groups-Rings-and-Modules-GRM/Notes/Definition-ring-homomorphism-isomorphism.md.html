Let $R$ and $S$ be rings.

A function $f: R\to S$ is called a ring homomorphism if for all $r_1,r_2\in R$,

  1. $f(r_1 + r_2) = f(r_1) + f(r_2)$;

  2. $f(0_R) = 0_S$;

  3. $f(r_1\cdot r_2) = f(r_1) \cdot f(r_2)$;

  4. $f(1_R) = 1_S$.

A bijective ring homomorphism is called a ring isomorphism.

  • The first two implies $f$ is a group homomorphism with respect to addition. We can define the kernel and image similarly.

  • 1 implies 2, but 3 does not imply 4.
