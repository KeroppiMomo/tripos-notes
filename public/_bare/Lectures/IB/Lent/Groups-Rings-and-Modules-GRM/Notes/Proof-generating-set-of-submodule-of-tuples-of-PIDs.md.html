Induct on $m$. For $m=1$, a submodule of $R$ is an ideal, which is principal as $R$ is a principal ideal domain.

Let $N\leq R^m$ be a submodule. Define $$ \begin{align*} I = \sb{s\in R}{(s,r_2, r_3, \ldots, r_m)\in N \quad \text{for some $r_i\in R$}}, \end{align*} $$ which is an ideal in $R$, so $I = (s_1)$. Choose some $n=(s_1, s_2, \ldots, s_m)\in N$ with the first component $s_1$.

For any $n' = (r_1, \ldots, r_m)\in N$, since $r_1\in (s_1)$, write $r_1 = as_1$ for some $a\in R$. Then $$ \begin{align*} n' - an = (0, r_2 - as_2, \ldots, r_m - as_m) \in N \cap (\set{0} \times R^{m-1}). \end{align*} $$ Therefore $N = Rn + N\cap (\set{0} \times R^{m-1})$ where $N\cap (\set{0} \times R^{m-1})$ is (isomorphic to) a submodule of $R^{m-1}$. Then apply induction hypothesis.
