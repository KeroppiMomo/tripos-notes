Free generation $\implies$ linear independence

Suppose $S$ generates $M$ freely but $S$ is not linear independent. Then write $$ \begin{align*} 0 = r_1 m_1 + \ldots + r_k m_k \end{align*} $$ where $r_i$ are not all zeros. By reordering assume $r_1\neq 0$.

Consider the function $$ \begin{align*} f: S &\to R, \\ m_1 &\mapsto 1, \\ m_i &\mapsto 0, \quad \forall i=2,3,\ldots,k. \end{align*} $$ By free generation, extend $f$ to an $R$-module homomorphism $ϕ: M\to R$. But then $$ \begin{align*} 0 = ϕ(0) = ϕ\left(\sum_{i=1}^{k} r_i m_i\right) = \sum_{i=1}^{k} r_i\,ϕ(m_i) = r_1, \end{align*} $$ which is a contradiction.

Generates and linear independence $\implies$ unique expression

$S$ generates $M$, so by definition it is always possible to write $m = r_1 m_1 + \ldots + r_k m_k$.

Suppose $r_1 m_1 + \ldots + r_k m_k = r_1' m_1 + \ldots + r_k' m_k$. Rearranging yields $$ \begin{align*} (r_1' - r_1) m_1 + \ldots + (r_k' - r_k)m_k = 0 \end{align*} $$ so by linear independence, $r_i' = r_i$ for all $i$.

Unique expression $\implies$ free generation

Given a set function $f: S\to N$ where $N$ is an $R$-module, define $$ \begin{align*} ϕ:& & M&\to N \\ && m=\sum_{i=1}^{k} r_i m_i &\mapsto \sum_{i=1}^{k} r_i \, f(m_i). \end{align*} $$ This is well-defined by unique expression, agrees with $f$ on $S$, and is an $R$-module homomorphism.
