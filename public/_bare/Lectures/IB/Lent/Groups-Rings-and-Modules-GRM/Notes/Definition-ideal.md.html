Let $R$ be a ring.

A subset $I\subseteq R$ is called an ideal, written as $I\lhd R$, if

  1. $I$ is a subgroup under addition;

  2. (absorbing property) for all $a\in I$ and $b\in R$, we have $ab\in I$.


  • Since addition is commutative, $I$ is a normal subgroup.

  • If $I$ contains a unit, then $I = R$. (Derivation) In particular:

    • $I\lhd R$ is a subring iff $I = R$.

    • $R$ is a field iff the only ideals are $\set{0}$ and $R$. (Derivation)
