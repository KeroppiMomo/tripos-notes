If $R$ is a field and $I\lhd R$ is a non-zero ideal, then $I$ contains a non-zero element $u$, which is a unit. Then $I = R$.

Conversely if the only ideals of $R$ are $(0)$ and $R$, then for any $r\in R$ non-zero, $(r)\neq (0)$ so $(r) = R$. Therefore $1\in (r)$ so there exists some $r'\in R$ such that $rr'=1$. Hence $r$ is a unit.
