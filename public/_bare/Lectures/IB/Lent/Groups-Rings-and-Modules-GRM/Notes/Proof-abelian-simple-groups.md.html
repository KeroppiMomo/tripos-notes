Any subgroup of an abelian group is normal, so the only subgroups of a abelian simple group are the trivial group and the whole group.

$C_p$ is simple

If $H\leq G$ is a non-trivial subgroup, then any $h\in H\setminus \set{e}$ has order $p$ by Lagrange, so $H = G$.

Non-trivial abelian simple groups are prime groups

Let $g\in G\setminus \set{e}$. By simplicity, the subgroup $\langle g\rangle = \sb{g^n}{n\in \Z}\leq G$ generated by $g$ is either $\set{e}$ or $G$. But $g\neq e$, so $G$ is cyclic and generated by $g$.

$G$ cannot be infinite, since otherwise $G\isom \Z$, which is not simple as $2\Z \lhd \Z$.

Thus $G\isom C_n$ where $n=2,3,\ldots$. For any divisor $q\mid n$, the subgroup generated by $g^{n/q}$ has order $q$, which has to be 1 or $n$ by simplicity. Thus $n$ is prime.
