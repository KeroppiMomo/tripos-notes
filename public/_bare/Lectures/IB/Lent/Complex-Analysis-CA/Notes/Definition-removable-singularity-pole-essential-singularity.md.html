Consider a holomorphic function $f: B(a,r)^\times\to \C$ with an isolated singularity at $z=a$. It has a Laurent expansion $f(z) = \sum_{n=-\infty}^{\infty} c_n (z-a)^n$ valid on $B(a,r)^\times$.

We say $z=a$ is

  1. a removable singularity if $c_n = 0$ for all $n<0$;

  2. a pole (of order $k$) if there exists $k>0$ such that $c_{-k}\neq 0$ but $c_n=0$ for all $n<-k$; or

  3. an essential singularity if otherwise (i.e. $c_n\neq 0$ for infinitely many $n<0$).
