Theta methods

For an initial value problem and some $θ\in [0,1]$, $$ \begin{align*} \v y_{n+1} = \v y_n + h\bigl(θ\,\v f(t_n, \v y_n) + (1-θ)\, \v f(t_{n+1}, \v y_{n+1})\bigr). \end{align*} $$

$θ$

Name

Scheme

$1$

Euler method

$\v y_{n+1} = \v y_n + h\, \v f(t_n ,\v y_n)$

explicit

$1/2$

Trapezoidal rule

$\v y_{n+1} = \v y_n + \frac{1}{2}h\bigl(\v f(t_n ,\v y_n) + \v f(t_{n+1}, \v y_{n+1})\bigr)$

implicit

$0$

Backward Euler

$\v y_{n+1} = \v y_n + h\, \v f(t_{n+1}, \v y_{n+1})$

implicit

For $θ\in [0,1)$, the method is implicit: we need to solve an equation for $\v y_{n+1}$ (by e.g. fixed point iteration, Newton-Raphson, modified Newton-Raphson etc).

Proposition (order of theta methods) open_in_new

A theta method has order

  • 2 if $θ=1/2$ (the trapezoidal rule); or

  • 1 otherwise.
