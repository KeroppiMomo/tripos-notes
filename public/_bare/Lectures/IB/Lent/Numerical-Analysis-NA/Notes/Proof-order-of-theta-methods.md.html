We will restrict to $d=1$. Using Taylor expansion, $$ \begin{align*} y(t_{n+1}) ={}& y(t_n) + hy'(t_n) + \frac{1}{2}h^2 y''(t_n) + \frac{1}{6}h^3 y'''(t_n) + O(h^4). \end{align*} $$ The theta scheme is $$ \begin{align*} y_{n+1} ={}& y_n + h\bigl(θ\, f(t_n, y_n) + (1-θ)\, f(t_{n+1}, y_{n+1})\bigr). \end{align*} $$

Assuming $y(t_n) = y_n$, $f(t_n,y_n) = y'(t_n)$ and $f(t_{n+1}, y_{n+1}) = y'(t_{n+1})$, we get $$ \begin{align*} y_{n+1} ={}& y(t_n) + hθy'(t_n) + h(1-θ) y'(t_{n+1}) \\ ={}& y(t_n) + hθy'(t_n) + h(1-θ)\Bigl(y'(t_n) + hy''(t_n) + \frac{1}{2}h^2y'''(t_n) + O(h^3)\Bigr) \\ ={}& y(t_n) + hy'(t_n) + h^2(1-θ) y''(t_n) + \frac{1}{2}h^3(1-θ) y'''(t_n) + O(h^4) \end{align*} $$ by Taylor expanding $y'(t_{n+1}) = y'(t_n + h)$.

Then by subtracting, we obtain the local truncation error $$ \begin{align*} η_{n+1} ={}& \Bigl(θ-\frac{1}{2}\Bigr)h^2 y''(t_n) + \Bigl(\frac{1}{2}θ - \frac{1}{3}\Bigr)h^3y'''(t_n) + O(h^4). \end{align*} $$ Thus if $θ=1/2$, then $η_{n+1} = O(h^3)$ so the method has order 2, and otherwise $η_{n+1} = O(h^2)$ so the method has order 1.
