Find the real stability interval of the 3-step 3rd-order Adams-Bashforth method $$ \begin{align*} \v y_{n+3} - \v y_{n+2} = h \bigl(\tfrac{23}{12} \v f_{n+2} - \tfrac{4}{3} \v f_{n+1} + \tfrac{5}{12} \v f_n\bigr). \end{align*} $$

With $f = λy$, the characteristic polynomial is $$ \begin{align*} p_z(x) = (x^3 - x^2) - z\bigl(\tfrac{23}{12} x^2 - \tfrac{4}{3} x + \tfrac{5}{12}\bigr). \end{align*} $$ Note $p_z(-1) = -2 - \frac{11}{3}z$ has root $z=-11/6$, so we guess that $$ \begin{align*} I = \mathcal{D}\cap \R \stackrel{?}{=} (-11/6, 0). \end{align*} $$

It's then just analysis:

  • If $z>0$, then $p_z(1) = -z < 0$ and $p_z(\infty) = \infty$ so there is a root $>1$ and thus it is not stable.

  • If $z<-6/11$, then $p_z(-1) = -2-\frac{11}{3}z > 0$ and $p_z(-\infty) = \infty$ so there is a root $<1$ and thus it is not stable.

  • If $-6/11<z<0$, we have $$ \begin{align*} p(-1) &= -2-\tfrac{11}{3}z < 0, \\ p(0) &= -\tfrac{5}{12} z > 0, \\ p(\tfrac{1}{2}) &= -\tfrac{1}{8} - \tfrac{11}{48}z < 0, \\ p(1) &= -z > 0 \end{align*} $$ so all three roots of $p_z$ are real and reside within $(-1,1)$. Therefore the method is stable.
