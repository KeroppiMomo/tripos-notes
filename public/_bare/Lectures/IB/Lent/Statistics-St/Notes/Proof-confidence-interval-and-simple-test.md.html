These are equivalent:

  • $T(θ_0, X)$ is a size $α$ test for $H_0: θ = θ_0$ for all $θ_0\in Θ$

  • $\prob_{θ_0}(T(θ_0, X) = 1) = α$ for all $θ_0\in Θ$

  • $\prob_{θ_0}(θ_0\not\in I(X)) = α$ for all $θ_0\in Θ$

  • $\prob_{θ_0}(θ_0\in I(X)) = 1-α$ for all $θ_0\in Θ$

  • $I(X)$ is a $(1-α)$-confidence set for $θ$.
