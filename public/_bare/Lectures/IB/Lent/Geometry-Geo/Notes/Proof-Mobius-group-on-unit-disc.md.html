First we check those indeed preserve the unit disc: $$ \begin{align*} \left|e^{iθ}\frac{z-a}{1-\bar az}\right| = 1 &\iff (z-a)(\bar z - \bar a) = (1-\bar az)(1 + a\bar z) \\ &\iff (1 + |a|^2) |z|^2 = 1 + |a|^2 \\ &\iff |z| = 1 \end{align*} $$ and so $z\mapsto e^{iθ} \frac{z-a}{1-\bar az}$ preserves the unit circle. It sends $a\in D$ to $0\in D$, so it preserves the unit disc by continuity.

Next for any Möbius transformation $μ$ that preserves the unit disc, let $a = μ\inv(0)$. Then $(z \mapsto \frac{z-a}{1-\bar az}) \circ μ$ fixes $0$ and still preserve the unit disc. Moreover apply a rotation $z\mapsto e^{iθ}z$ to fixes $1\in \partial D$. Now the composition has the form $$ \begin{align*} z \mapsto \frac{z}{cz + (1-c)}. \end{align*} $$ For any $|z| = 1$, since this preserves the unit circle, $$ \begin{align*} 1 = \left|\frac{z}{cz + (1-c)}\right| = \frac{1}{|cz + (1-c)|} \end{align*} $$ so $z \mapsto cz + (1 - c)$ also preserves the unit circle. By substituting in values we see this only works when $c = 1$.
