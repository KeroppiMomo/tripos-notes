An abstract smooth surface $Σ$ is orientable if it admits an atlas $\set{(U_i, ϕ_i)}_{i\in I}$ such that all transition maps are orientation-preserving.

The choice of such an atlas is called an orientation.

  • There is a definition of orientability for a topological surface, but it requires algebraic topology. We here simply define a topological surface to be orientable if it contains no subset homeomorphic to a Möbius band.
