For the initial value problem $$ \begin{align*} \begin{cases} Ly = f, &t>0, \\ y(0) = y'(0) = 0 \end{cases} \end{align*} $$ where $L = \alpha(t) \dd[2]{t} + \beta(t) \dd{t} + \gamma(t)$ and $\alpha(t) \neq 0$, the Green's function $G(t;\tau)$ satisfies $$ \begin{align*} \begin{cases} L[G(t;\tau)] = \delta(t-\tau),\\ G(0; \tau) = \dfd{G}{t}(0;\tau) = 0 \end{cases} \end{align*} $$ for each $\tau\in (0,\infty)$.

The Green's function is determined by

  1. $G(t;\tau) = 0$ for $t<\tau$;

  2. $L[G(t;\tau)] = 0$ on $t>\tau$; and

  3. jump condition $G(\tau^+; \tau) = 0$ and $\dfd{G}{t}(\tau^+, \tau) = 1/\alpha(\tau)$.

Therefore the solution $y$ is $$ \begin{align*} y(t) = \int_{0}^{t} G(t;\tau) f(\tau) \d \tau \end{align*} $$ which preserves causality: $y(t)$ only depends on the values $f(\tau)$ before $\tau<t$.
