Well-defined operations

Suppose $v_1 + U = v_1' + U$ and $v_2 + U = v_2' + U$ where $v_1,v_1',v_2,v_2'\in V$. Then $v_1' = v_1 + u_1$ and $v_2' = v_2 + u_2$ for some $u_1,u_2\in U$. Since $$ \begin{align*} (v_1' + v_2') - (v_1 + v_2) = u_1 + v_2 \in U, \end{align*} $$ we have $(v_1+v_2) + U = (v_1'+v_2') + U$, so vector addition is well-defined.

Suppose $v + U = v' + U$ and $\lambda\in\mathbb{F}$. Let $u\in U$ so that $v' = v+u$. Since $$ \begin{align*} \lambda v' - \lambda v = \lambda u \in U, \end{align*} $$ we have $(\lambda u) + U = (\lambda u') + U$, so scalar multiplication is well-defined.

Vector space axioms

Vector space axioms are inherited from $V$.
