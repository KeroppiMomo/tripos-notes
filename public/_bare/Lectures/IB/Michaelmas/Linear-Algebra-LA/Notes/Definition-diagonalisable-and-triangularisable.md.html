Let $V$ be a finite-dimensional vector space on $\mathbb{F}$.

  • $\alpha\in$ $\mathcal{L}(V,V)$ is diagonalisable if there exists $B$ for $V$ such that $[\alpha]^B_B$ is diagonal.

  • $\alpha\in\mathcal{L}(V,V)$ is triangularisable if there exists $B$ for $V$ such that $[\alpha]^B_B$ is upper triangular.

  • $A\in M_{n\times n}(\mathbb{F})$ is diagonalisable if $A$ is similar to a diagonal matrix.

  • $A\in M_{n\times n}(\mathbb{F})$ is triangularisable if $A$ is similar to an upper triangular matrix.
