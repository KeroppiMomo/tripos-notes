Induct on $k$.

For $k=1$, $v_1\neq \v 0$ so we can set $e_1 = v_1/\|v_1\|$ so that $\|e_1\| = 1$.

Given $e_1, \ldots, e_k$ where $k\leq n-1$, set $$ \begin{align*} \tilde e_{k+1} = v_{k+1} - \sum_{i=1}^{k} \langle v_{k+1}, e_i\rangle e_i. \end{align*} $$

  • $\set{e_1, \ldots, e_k, \tilde e_{k+1}}$ has the same span as $\set{e_1, \ldots, e_k, v_{k+1}}$, i.e. same as $\set{v_1, \ldots, v_k, v_{k+1}}$.

  • $\langle \tilde e_{k+1}, e_i\rangle = 0$ for all $i\leq k$.

  • $\tilde e_{k+1}\neq 0$ as $v_{k+1} \not\in \langle e_1, \ldots, e_k\rangle$.

Set $e_{k+1} = \tilde e_{k+1} / \|\tilde e_{k+1}\|$.
