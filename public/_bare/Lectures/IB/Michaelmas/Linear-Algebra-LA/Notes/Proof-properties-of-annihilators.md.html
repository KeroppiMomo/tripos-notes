1. We apply the subspace test: the zero map $0_{V^\star}\in V^\star$ sends all $s\in S$ to 0, so $0_{V^\star} \in S^0 \neq \emptyset$. Also for any $\theta, \theta' \in S^0$ and $\lambda\in \mathbb{F}$, $$ \begin{align*} (\theta+\lambda\theta')(s) = \theta(s) + \lambda\theta'(s) = 0 + \lambda 0 = 0 \qquad \text{for all } s\in S \end{align*} $$ so $\theta+\lambda\theta' \in S^0$.

  2. Since $S^0$ and $T^0$ are subspaces of $V^\star$, it suffices to check $T^0 \subseteq S^0$. If $\theta\in T^0$, then for all $s\in S$, we have $\theta(s) = 0$ since $s\in T$, so $\theta\in S^0$.

  3. $S\subseteq \langle S\rangle$, so by 2., $\langle S\rangle^0 \leq S^0$. Conversely suppose $\theta\in S^0$. For any $v\in \langle S\rangle$, write $v = \sum_{s\in S} ' \lambda_s s$ for some $\lambda_s \in \mathbb{F}$. Then $$ \begin{align*} \theta(v) = \sum_{s\in S} ' \lambda_s \underbrace{\theta(s)}_{0} = 0 \end{align*} $$ so $\theta\in \langle S\rangle^0$.

  4. For all $\theta\in V^\star$, we have $\theta(\v 0_V) = 0$ since $\theta$ is linear, so $\theta \in \set{\v 0_V}^{0}$. Moreover, if $\theta\in V^0$, then $\theta(v) = 0$ for all $v\in V$, so $\theta = \v 0_{V^\star}$.
