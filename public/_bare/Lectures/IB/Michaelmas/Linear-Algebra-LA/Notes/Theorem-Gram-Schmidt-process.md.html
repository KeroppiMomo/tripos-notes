Let $V$ be an inner product space.

For any linearly independent set $\set{v_1,\ldots,v_n}\subseteq V$, there exists an orthonormal set $\set{e_1, \ldots, e_n} \subseteq V$ such that $$ \begin{align*} \langle e_1, \ldots, e_k\rangle = \langle v_1, \ldots, v_k\rangle \qquad \text{for all } 1\leq k\leq n. \end{align*} $$ Moreover if $\set{v_1, \ldots, v_k}$ for some $k\leq n$ is already orthonormal, then $e_i = v_i$ for $i\leq k$.

Proof

  • If $V$ is finite-dimensional, then performing Gram-Schmidt on a basis produces an orthonormal basis.

  • If $V$ is finite-dimensional and $E\subseteq V$ is an orthonormal set, then we can extend to a basis for $V$ and perform Gram-Schmidt to obtain an orthonormal basis for $V$ containing $E$.
