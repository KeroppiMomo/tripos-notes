These are all linear maps:

  • $\alpha: \mathbb{F}^n \to \mathbb{F}^m$ given by $\alpha(v) = Av$ where $A\in M_{m\times n}(\mathbb{F})$.

  • $\alpha: C^\infty(\R) \to C^\infty(\R)$ given by $\alpha(f) = f'$.

  • $\alpha: C(\R) \to \R$ given by $\alpha(f) = \int_{0}^{1} f(x) \d x$.

  • For a non-empty set $X$ and $x\in X$, the map $\alpha: \mathbb{F}^X \to \mathbb{F}$ given by $\alpha(f) = f(x)$.

  • For a $\mathbb{F}$-vector space, the identity map $V\to V$.

  • The zero map $\alpha: V\to W$ given by $v\mapsto \v 0$.

Non-examples:

  • $\alpha: \R\to\R$ given by $\alpha(x) = x^z$.

  • $\beta: \R\to\R$ given by $\beta(x) = x+1$.

Is $\alpha: \C\to\C$ given by $z\mapsto \bar z$ linear? Yes if $\C$ is a real vector space, no if $\C$ is a complex vector space.
