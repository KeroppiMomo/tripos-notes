Let $U,V,W$ be vector spaces, $\alpha\in \mathcal{L}(V,W)$ and $\beta\in \mathcal{L}(U,V)$.

  1. $\alpha^\star$ is linear.

  2. The function $\mathcal{L}(V,W) \to \mathcal{L}(W^\star, V^\star)$ given by $\gamma\mapsto \gamma^\star$ is linear.

  3. $(\alpha\circ\beta)^\star = \beta^\star\circ\alpha^\star$.

  4. If $\alpha$ is an isomorphism, then so is $\alpha^\star$, and $(\alpha^\star)\inv = (\alpha\inv)^\star$.
