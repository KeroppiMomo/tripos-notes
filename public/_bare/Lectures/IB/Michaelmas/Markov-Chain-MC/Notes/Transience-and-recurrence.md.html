Definition (transience and recurrence) open_in_new

Suppose $\ouline{X} = (X_n)_{n\geq 0}$ is a Markov chain on $I$ with transition matrix $P$.

We say a state $i\in I$ is

  • recurrent if $\prob(X_n = i \text{ for infinitely many } n | X_0 = i) = 1$;

  • transient if $\prob(X_n = i \text{ for infinitely many } n | X_0 = i) = 0$.

We say $P$ is recurrent/transient if all states are recurrent/transient.

Definition (return times) open_in_new

Suppose $\ouline{X} = (X_n)_{n\geq 0}$ is a Markov chain on $I$.

The return times $T_i^{(k)}$ for $i\in I$ are defined inductively as $$ \begin{align*} T_i^{(0)} = 0, \qquad T_i^{(k+1)} = \inf \sb{n>T_i^{(k)}}{X_n = i}. \end{align*} $$ and write $T_i = T_i^{(1)}$ as the first return time.

Lemma (probability for number of visits) open_in_new

Define, for $i\in I$, the total number of visits $$ \begin{align*} V_i = \sum_{n=0}^{\infty} \mathbb{1}(X_n = i). \end{align*} $$ For all $r\geq 0$, $$ \begin{align*} \prob(V_i > r | X_0 = i) = \big(\prob(T_i < \infty| X_0 = i)\big)^r. \end{align*} $$

Proof

Theorem (state is either recurrent or transient) open_in_new

Consider a Markov chain on $I$ with transition matrix $P$, and let $i\in I$.

  1. If $\prob(T_i < \infty | X_0 = i) = 1$, then $i$ is recurrent and $\sum_{n=0}^{\infty}$ $p_{ii}(n)$ $=\infty$.

  2. Otherwise, $i$ is transient and $\sum_{n=0}^{\infty}$ $p_{ii}(n)$ $<\infty$.

Proof

Theorem (both recurrent or transient if communicates) open_in_new

Consider a Markov chain on $I$, and let $x, y\in I$.

If $x$ $\leftrightarrow$ $y$, then they are either both recurrent or both transient.

Proof

As a result, a communicating class consists of either all recurrent states or all transient states.

Theorem (recurrent and closed communicating class) open_in_new

Let $C$ be a communicating class of a Markov chain.

  • If $C$ is recurrent, then $C$ is closed.

  • If $C$ is closed and finite, then $C$ is recurrent.

Proof
