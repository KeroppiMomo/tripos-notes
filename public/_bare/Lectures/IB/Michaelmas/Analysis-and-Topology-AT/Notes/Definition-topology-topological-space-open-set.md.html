A topology $\tau$ on set $X$ is a set of subsets of $X$ satisfying

  1. $\emptyset, X\in \tau$;

  2. for any family $\set{U_i}_{i\in I}$ with $U_i\in \tau$, the union $\bigcup_{i\in I} U_i \in I$;

  3. for any finite family $\set{U_i}_{i\in I}$ with $U_i \in \tau$, the intersection $\bigcap_{i\in I} U_i \in I$.

We call $(X,\tau)$ a topological space.

A subset $U\subseteq X$ is said to be open if $U\in \tau$.
