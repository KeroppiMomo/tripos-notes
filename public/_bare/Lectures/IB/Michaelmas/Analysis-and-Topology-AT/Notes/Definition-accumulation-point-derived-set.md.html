Let $(X,\tau)$ be a topological space and $A\subseteq X$.

We say $x\in X$ is an accumulation point (or limit point) of $A$ if for all neighbourhood $N$ of $x$, $(A\setminus \set{x}) \cap N\neq \emptyset$, i.e. every neighbourhood of $x$ contains a point in $A$ other than $x$ itself.

We define the derived set of $A$ (denoted $A'$) as the set of all accumulation points of $A$.
