Definition (open cover) open_in_new

An open cover of a topological space $(X,d)$ is a family of open sets $\mathcal{U} = \set{U_i}_{i\in I}$ such that $$ \begin{align*} X = \bigcup_{i\in I} U_i. \end{align*} $$

Definition (subcover) open_in_new

Let $\mathcal{U}$ be an open cover of the topological space $(X,\tau)$.

A subset $\mathcal{V}\subseteq U$ is called a subcover if $\mathcal{V}$ is an open cover itself.

Definition (compact) open_in_new

A topological space $(X,\tau)$ is said to be compact if every open cover of $(X,\tau)$ has a finite subcover.

Lemma (closed set in compact space is compact) open_in_new

Let $(X,\tau)$ be a compact topological space.

If $Y\subseteq X$ is closed, then $Y$ is also compact.

Proof

  • The converse is true if $X$ is Hausdorff.

Definition (relatively compact, pre-compact) open_in_new

For a topological space $(X,\tau)$, we say $A\subseteq X$ is relatively compact or pre-compact if the closure $\bar A$ is compact.

Proposition (closed bounded intervals are compact) open_in_new

In $\R^n$ with the Euclidean metric, the subset $[a,b]^n$ is compact.

Proof

Definition (sequential compactness) open_in_new

We say a topological space $(X,\tau)$ is sequentially compact if every sequence in $X$ has a convergent subsequence.

Proposition (sequentially compact subset is closed) open_in_new

Let $(X,d)$ be a metric space and $Y\subseteq X$.

If $Y$ is sequentially compact, then $Y$ is closed.

Proof

Proposition (sequentially compact and compact) open_in_new

A metric space is sequentially compact iff it is compact.

Proof

  • For a general topological space, both implications are not true: counterexamples exist.

  • In second countable topological spaces, they are equivalent.

Definition (bounded, totally bounded) open_in_new

Let $(X,d)$ be a metric space. We say it is

  • bounded if there exists $r>0$ such that $d(x,y) < r$ for all $x,y\in X$; and

  • totally bounded if for every $\epsilon>0$, there exists a finite set $F\subseteq X$ such that $$ \begin{align*} X = \bigcup_{y\in F} B_\epsilon(y), \end{align*} $$ i.e. there is a finite covering of $X$ by open $\epsilon$-balls. We call $F$ an $\epsilon$-net of $X$.

Theorem (Heine-Borel, compact iff totally bounded and complete) open_in_new

A metric space is compact iff it is totally bounded and complete.

Proof

Lemma (continuous image of compact set is compact) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

If $f: X\to Y$ is a continuous function and $(X,\tau)$ is compact, then $f(X) \subseteq Y$ is also compact.

Proof

Proposition (topological inverse function theorem) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

If $f: X\to Y$ is a continuous bijection, $(X,\tau)$ is compact, and $(Y,\rho)$ is Hausdorff, then $f\inv$ is also continuous, and hence $f$ is a homeomorphism.

Proof

  • This also applies to metric spaces, in which case the Hausdorff condition can be dropped.

Proposition (continuous function on compact set attains its bounds) open_in_new

Let $(X,\tau)$ be a topological space and $X\neq\emptyset$.

If $f: X\to\R$ is continuous and $(X,\tau)$ is compact, then $f$ is bounded and there exists $p,q\in X$ such that $$ \begin{align*} f(p) &= \sup_{x\in X} f(x) &\text{and}&& f(q) = \inf_{x\in X} f(x). \end{align*} $$

Proof

  • Consequently, $C(X; Y) = (\set{\text{continuous functions }X\to Y}, \text{sup metric}) =$ $C_b(X; Y)$ is well-defined for any metric space $Y$.

  • In particular if $Y$ is complete, then so is $C(X; Y)$.
