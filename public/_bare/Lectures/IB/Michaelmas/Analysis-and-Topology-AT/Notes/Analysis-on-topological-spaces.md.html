Definition (topology, topological space, open set) open_in_new

A topology $\tau$ on set $X$ is a set of subsets of $X$ satisfying

  1. $\emptyset, X\in \tau$;

  2. for any family $\set{U_i}_{i\in I}$ with $U_i\in \tau$, the union $\bigcup_{i\in I} U_i \in τ$;

  3. for any finite family $\set{U_i}_{i\in I}$ with $U_i \in \tau$, the intersection $\bigcap_{i\in I} U_i \in τ$.

We call $(X,\tau)$ a topological space.

A subset $U\subseteq X$ is said to be open if $U\in \tau$.

  • Compare properties of metric topology. We define open sets directly here.

Definition (coarser and finer topology) open_in_new

Let $X$ be any set, and $\tau_1$ and $\tau_2$ be topologies on $X$.

If $\tau_1\subseteq \tau_2$, then we say $\tau_1$ is coarser and $\tau_2$ is finer.

Definition (base for topology) open_in_new

Let $(X,\tau)$ is a topological space.

We say $\mathcal{B} \subseteq \tau$ is a base for $\tau$ if for all open set $U\in \tau$, there exists a subfamily $\mathcal{C}\subseteq \mathcal{B}$ such that $$ \begin{align*} U = \bigcup_{B\in \mathcal{C}} B. \end{align*} $$

Lemma (defining properties of bases for topology) open_in_new

Let $X$ be a set and $\mathcal{B}\subseteq \mathcal{P}(X) = \set{\text{all subsets of }X}$.

There exists a topology which admits $\mathcal{B}$ as a base iff $\mathcal{B}$ satisfies:

  1. Covering property: $\mathcal{B}$ is an (open) cover of $X$, i.e. $X = \bigcup_{B\in \mathcal{B}} B$.

  2. Intersection property: for all $B_1, B_2 \in \mathcal{B}$ and $x\in B_1\cap B_2$, there exists some $B_3\in \mathcal{B}$ such that $x\in B_3$ and $B_3 \subseteq U_1\cap B_2$.

Proof

Definition (second countable topological space) open_in_new

Let $(X,\tau)$ be a topological space.

$(X,\tau)$ is said to be second countable if it has a countable base.

Definition (Hausdorff topological space) open_in_new

Let $(X,\tau)$ be a topological space.

$(X,\tau)$ is said to be Hausdorff if for all $x,y\in X$ and $x\neq y$, there exists $U, V\in \tau$ such that $x\in U$, $y\in V$ and $U\cap V=\emptyset$.

  • This means $\tau$ can separate different points in $X$. (Illustration)

Definition (metrizable topological space) open_in_new

Let $(X,\tau)$ be a topological space.

$(X,\tau)$ is said to be metrizable if $\tau$ can be induced by some metric, i.e. if we can define a metric on $X$ such that the metric topology equals $\tau$.

Lemma (metrizable implies Hausdorff) open_in_new

Let $(X,\tau)$ be a topological space.

If $X$ is metrizable, then $X$ is Hausdorff.

Proof

Examples of topological spaces

Closed sets in topological spaces open_in_new

We define closed sets, closure and neighbourhood in the same way as in metric spaces.

Definition (accumulation point, derived set) open_in_new

Let $(X,\tau)$ be a topological space and $A\subseteq X$.

We say $x\in X$ is an accumulation point (or limit point) of $A$ if for all neighbourhood $N$ of $x$, $(A\setminus \set{x}) \cap N\neq \emptyset$, i.e. every neighbourhood of $x$ contains a point in $A$ other than $x$ itself.

We define the derived set of $A$ (denoted $A'$) as the set of all accumulation points of $A$.

Proposition (closed sets and derived sets) open_in_new

Let $(X,\tau)$ be a topological space.

  • $A\subseteq X$ is closed iff $A'$ $\subseteq A$.

  • $\cl A$ $= A \cup A'.$

Proof

Convergent sequences in topological space open_in_new

Definition (sequence convergence) open_in_new

Let $(X,\tau)$ be a topological space and $\set{x_n}_{n\geq 1}^{\infty}$ be a sequence in $X$.

We say $\set{x_n}$ is a convergent sequence and converges to $x\in X$ (denoted as $x_n\to x$) if for all neighbourhood $V$ of $x$, there exists $N\in\N$ such that for all $n\geq N$, we have $x_n \in V$.

In particular, if $(X,d)$ is a metric space, this is equivalent to any of the following:

  • for all $\epsilon>0$, there exists some $N\in\N$ such that for all $n\geq N$, we have $d(x_n, x) < \epsilon$;

  • for all $\epsilon>0$, there exists some $N\in\N$ such that for all $n\geq N$, we have $x_n \in$ $B_\epsilon(x)$.

Proposition (uniqueness of limits) open_in_new

If a sequence $\set{x_n}_{n=1}^\infty$ in a Hausdorff topological space converges, then it has a unique limit.

This applies to metric spaces.

Proof

  • $\scl(A) \subseteq \cl(A)$. This implies if $A$ is closed, then $A$ is sequentially closed.

  • If $X$ is second countable, then $\scl(A) = \cl(A)$. This implies closed iff sequentially closed. This applies to metric spaces.

Continuity on topological spaces open_in_new

Definition (continuity on topological space) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

We say a function $f: X\to Y$ is continuous at $x_0\in X$ if for all neighbourhood $V$ of $f(x_0)$, we have $f\inv(V)$ being a neighbourhood of $x$.

If $(X,d)$ and $(Y,d')$ are metric spaces, this is equivalent to any of the following:

  • for all $\epsilon>0$, there exists $\delta=\delta(\epsilon)>0$ such that for all $x\in X$, if $d(x,x_0) < \delta$, then $d'(f(x), f(x_0)) < \epsilon$;

  • for all $\epsilon>0$, there exists $\delta=\delta(\epsilon)>0$ such that for all $x\in$ $B_\delta(x_0)$, we have $f(x) \in B'_{\epsilon}(f(x_0))$;

  • for all $\epsilon>0$, there exists $\delta = \delta(\epsilon)>0$ such that $B_{\delta}(x_0) \subseteq f\inv(B'_\epsilon(f(x_0)))$;

We say $f$ is continuous if this holds for all $x_0\in X$.

Lemma (continuous iff taking preimage preserves open or closed sets) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces, and $f: X\to Y$. The following are equivalent:

  • $f$ is continuous;

  • for all open set $V$ in $(Y,\rho)$, the preimage $f\inv(V)$ is open in $(X,\tau)$;

  • for all closed set $V$ in $(Y,\rho)$, the preimage $f\inv(V)$ is closed in $(X,\tau)$.

Proof

Lemma (continuous iff preimage of base elements is open) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces, and $\mathcal{B}$ be a base for $\rho$.

A function $f:X\to Y$ is continuous iff $f\inv(B)$ is open for all $B\in \mathcal{B}$.

Proof

Lemma (composition preserves continuity) open_in_new

Let $f: (X,\tau)\to (Y,\rho)$ and $g: (Y,\rho)\to (Z,\sigma)$ be functions between topological spaces.

If $f$ is continuous at $x_0\in X$ and $g$ is continuous at $f(x_0)\in Y$, then $g\circ f$ is continuous at $x_0$.

Proof

Product topology open_in_new

Definition (product topology) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

The product topology is the topology on $X\times Y$ which admits $\mathcal{B} = \sb{U\times V}{U\in \tau, V\in \rho}$ as a base.

This can be extended to finite products.

Lemma (projection map is continuous) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

The projection maps $$ \begin{align*} \pi_X: X\times Y&\to X &\pi_Y: X\times Y&\to Y \\ (x,y) &\mapsto x & (x,y) &\mapsto y \end{align*} $$ are continuous relative to the product topology.

Proof

  • The definition of the product topology is the coarsest possible topology such that this lemma is true.

Proposition (continuity in product spaces) open_in_new

Let $(X,\tau)$, $(Y,\rho)$ and $(Z,\sigma)$ be topological spaces.

A function $f: Z\to X\times Y$ is continuous iff both $\pi_X$${}\circ f$ and $\pi_Y \circ f$ are continuous.

Proof

Quotient topology open_in_new

Definition (quotient space, quotient map, quotient topology) open_in_new

Let $(X,\tau)$ be a topological space, and $\sim$ be an equivalence relation on $X$. Define

  • the quotient space $Q=X/{\sim} = \sb{[x]}{x\in X}$, where $[x] = \sb{y\in X}{y\sim x}$, as the set of all equivalence classes;

  • the quotient map $q: X\to Q$ by $x\mapsto [x]$;

  • the quotient topology $$ \begin{align*} \tau_\sim = \sb{V\subseteq Q}{q\inv(V) \in \tau}. \end{align*} $$

Proof that the quotient topology is a topology

  • $\tau_\sim$ is defined this way so that $q: (X,\tau) \to (Q,\tau_\sim)$ is continuous: the preimage of an open set (in $\tau_\sim$) is open (in $\tau$).

Proposition (continuity on quotient space) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces, $\sim$ be an equivalence relation on $X$, $Q = X/{\sim}$ be the quotient space and $q: X\to Q$ be the quotient map.

A function $f: Q\to Y$ is continuous iff $f\circ q$ is continuous.

Proof

Compactness in topological spaces open_in_new

Definition (open cover) open_in_new

An open cover of a topological space $(X,d)$ is a family of open sets $\mathcal{U} = \set{U_i}_{i\in I}$ such that $$ \begin{align*} X = \bigcup_{i\in I} U_i. \end{align*} $$

Definition (compact) open_in_new

A topological space $(X,\tau)$ is said to be compact if every open cover of $(X,\tau)$ has a finite subcover.

Lemma (closed set in compact space is compact) open_in_new

Let $(X,\tau)$ be a compact topological space.

If $Y\subseteq X$ is closed, then $Y$ is also compact.

Proof

  • The converse is true if $X$ is Hausdorff.

Definition (sequential compactness) open_in_new

We say a topological space $(X,\tau)$ is sequentially compact if every sequence in $X$ has a convergent subsequence.

Proposition (sequentially compact and compact) open_in_new

A metric space is sequentially compact iff it is compact.

Proof

  • For a general topological space, both implications are not true: counterexamples exist.

  • In second countable topological spaces, they are equivalent.

Lemma (compact subset in Hausdorff space is closed) open_in_new

Let $X$ be a topological space.

If $X$ is Hausdorff and a subset $Y\subseteq X$ is compact, then $Y$ is closed.

Proposition (topological inverse function theorem) open_in_new

Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

If $f: X\to Y$ is a continuous bijection, $(X,\tau)$ is compact, and $(Y,\rho)$ is Hausdorff, then $f\inv$ is also continuous, and hence $f$ is a homeomorphism.

Proof

  • This also applies to metric spaces, in which case the Hausdorff condition can be dropped.

Proposition (continuous function on compact set attains its bounds) open_in_new

Let $(X,\tau)$ be a topological space and $X\neq\emptyset$.

If $f: X\to\R$ is continuous and $(X,\tau)$ is compact, then $f$ is bounded and there exists $p,q\in X$ such that $$ \begin{align*} f(p) &= \sup_{x\in X} f(x) &\text{and}&& f(q) = \inf_{x\in X} f(x). \end{align*} $$

Proof

  • Consequently, $C(X; Y) = (\set{\text{continuous functions }X\to Y}, \text{sup metric}) =$ $C_b(X; Y)$ is well-defined for any metric space $Y$.

  • In particular if $Y$ is complete, then so is $C(X; Y)$.

Connectedness open_in_new

Definition (disconnected, connected, separation) open_in_new

A topological space $(X,τ)$ is said to be disconnected if there exists open, non-empty, disjoint sets $U,V$ such that $X = U\cup V$.

We say $U,V$ are a separation of $X$.

$(X,τ)$ is said to be connected if there does not exist a separation.

  • Equivalently, $(X,τ)$ is connected iff the only subsets of $X$ which are both open and closed are $X$ and $\emptyset$.

Lemma (separation in subspace topology) open_in_new

Let $(X,τ)$ be a topological space, and $Y,U,V\subseteq X$ be subsets.

$U,V$ are a separation of $Y$ with respect to the subspace topology iff $U,V$ are non-empty, $U\cap{}$$\overline{V}$ $= \emptyset = \overline{U} \cap V$, and $Y = U\cup V$.

Proof

Corollary (connected set in R) open_in_new

With the Euclidean metric, a subset $Y \subseteq \R$ is connected iff $Y$ is an interval, i.e. if $x,y\in Y$ and $x<z<y$, then $z\in Y$.

Proof

Lemma (connected subset of a disconnected space) open_in_new

Let $(X,τ)$ be a disconnected topological space and $X=U\cup V$ is a separation.

If $Y\subseteq X$ is connected, then $Y\subseteq U$ or $Y\subseteq V$.

Proof

Lemma (closure of connected set is connected) open_in_new

Let $(X,τ)$ be a topological space.

If $Y\subseteq X$ is connected, then $\overline{Y}$ is also connected.

Proof

Lemma (union of connected subspaces sharing a point is connected) open_in_new

Let $(X,τ)$ be a topological space, and $\set{A_α}$ be a collection of connected subspaces of $X$.

If $\bigcap_{α} A_α\neq \emptyset$ (i.e. there exists a point in common), then $\bigcup_{α} A_α$ is connected.

Proof

Definition (connected components) open_in_new

Let $(X,τ)$ be a topological space.

Define an equivalence relation on $X$ by $x\sim y$ if there exists $Y\subseteq X$ which is connected such that $x,y\in Y$. The equivalence classes are called connected components.

Lemma (properties of connected components) open_in_new

Let $(X,τ)$ be a topological space and $Y\subseteq X$ be a connected component.

  1. $Y$ is connected. (Proof)

  2. If $Z$ is a connected set where $Y\subseteq Z\subseteq X$, then $Z = Y$.

  3. $Y$ is closed. (Proof)

Proposition (continuous image of connected set is connected) open_in_new

Let $(X,τ)$ and $(Y,ρ)$ be topological spaces.

If $f:X\to Y$ is continuous and $X$ is connected, then $f(X)\subseteq Y$ is connected.

Proof

  • This shows that connectedness is a topological invariant.

  • For $Y=\R$, since connected sets in $\R$ are precisely intervals, we have the intermediate value theorem: if $f(x_0) < 0$ and $f(x_1)>0$ for some $x_0,x_1\in X$, then there exists $x\in X$ such that $f(x) = 0$.

Proposition (locally constant function on connected domain is globally constant) open_in_new

Let $(X,τ)$ be a topological space, $Y$ be a set, and $f: X\to Y$ be a function.

If $X$ is connected and $f$ is locally constant (i.e. for all $x\in X$, there exists an open neighbourhood $U\subseteq X$ of $x$ such that $f(y) = f(x)$ for all $y\in U$), then $f$ is (globally) constant.

Proof

  • A consequence is that $X$ is connected iff all continuous functions $f: X\to\Z$ are constant.

Lemma (quotient of connected space is connected) open_in_new

Let $(X,τ)$ be a topological space and $\sim$ be an equivalence relation on $X$.

If $X$ is connected, then the quotient space $X/{\sim}$ is also connected with respect to the quotient topology.

Proof

Lemma (product of connected spaces is connected) open_in_new

Let $(X,τ)$ and $(Y,ρ)$ be topological spaces.

If $X$ and $Y$ are connected, then the product space $X\times Y$ is also connected with respect to the product topology.

Proof

Definition (path-connected) open_in_new

A topological space $(X,τ)$ is said to be path-connected if for all $x,y\in X$, there exists a path $γ$ connecting $x$ to $y$, i.e. a continuous function $γ: [0,1]\to X$ with $γ(0) = x$ and $γ(1) = y$.

Lemma (continuous image of path-connected set is path-connected) open_in_new

Let $(X,τ)$ and $(Y,ρ)$ be topological spaces.

If $f: X\to Y$ is continuous and $X$ is path-connected, then $f(X) \subseteq Y$ is path-connected.

Proof

  • This shows that path-connectedness is a topological invariant.

Lemma (path-connected implies connected) open_in_new

If a topological space is path-connected, then it is connected.

Proof

Definition (path-connected component) open_in_new

Let $(X,τ)$ be a topological space.

Define an equivalence relation on $X$ by $x\sim y$ if there exists a path connecting $x$ to $y$. The equivalence classes are called the path-connected components.
