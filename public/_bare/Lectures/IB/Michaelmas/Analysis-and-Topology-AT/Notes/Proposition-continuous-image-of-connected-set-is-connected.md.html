Let $(X,τ)$ and $(Y,ρ)$ be topological spaces.

If $f:X\to Y$ is continuous and $X$ is connected, then $f(X)\subseteq Y$ is connected.

Proof

  • This shows that connectedness is a topological invariant.

  • For $Y=\R$, since connected sets in $\R$ are precisely intervals, we have the intermediate value theorem: if $f(x_0) < 0$ and $f(x_1)>0$ for some $x_0,x_1\in X$, then there exists $x\in X$ such that $f(x) = 0$.
