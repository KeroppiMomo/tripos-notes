Connected

The set $$ \begin{align*} Y = \Big\{\big(x, \sin \frac{1}{x}\big)\;\Big|\; x>0 \Big\} \end{align*} $$ is path-connected and thus connected, so $X = \overline{Y}$ is connected.

Not path-connected

Let $f: [0,1] \to X$ be a continuous function with $f(0) = (0,0)$. Denote $f(t) = (f_1(t), f_2(t))$. We will show that $f_1\equiv 0$.

Suppose not. Let $t_0 = \sup\sb{t\in [0,1]}{f_1(t') = 0\, \forall t'\leq t}$. By continuity, $f_1(t_0) = 0$, and there exists some $δ>0$ such that $|f_2(t) - f_2(t_0)| < 1/2$ for all $|t-t_0| < δ$.

Let $t_1\in (t_0, t_0+δ)$ such that $f_1(t_1) > 0$. We can find $n,n'\in \N$ sufficiently large such that $$ \begin{align*} x = \frac{1}{2πn + π/2}, \quad x' = \frac{1}{2πn' + 3π/2} \end{align*} $$ are within $(0,f_1(t_1))$. By the intermediate value theorem, there exists $T,T'\in (t_0, t_1) \subseteq (t_0, t_0 + δ)$ such that $f_1(T) = x$ and $f_1(T') = x'$. Then $f_2(T) = \sin(1/f_1(T)) = 1$ and $f_2(T') = \sin(1/f_1(T')) = -1$, which contradicts with the definition of $δ$.
