Existence of $\tilde f$

$$ \begin{align*} \tilde f: Q &\to Y \\ [x] &\mapsto f(x), \end{align*} $$ is well-defined since if $[x]=[y]$, then $x\sim y$, and by hypothesis, $f(x) = f(y)$. This satisfies $f = \tilde f\circ q$.

Uniqueness of $\tilde f$

If $\tilde f': Q\to Y$ also satisfies $f=\tilde f'\circ q$, then $\tilde f'([x]) = f(x) = \tilde f([x])$, so $\tilde f$ is unique.

$f$ is continuous $\implies$ $\tilde f$ is continuous

Since $f=\tilde f\circ q$, the result follows from here.

$(f\inv(U)\in \tau \implies U\in \rho)\implies U\in $

For any open set $U\in \rho$, we have $q\inv(\tilde f\inv(U)) = (\tilde f \circ q)\inv(U) = f\inv(U) \in \tau$ by continuity of $f$. So $\tilde f\inv(U) \in \tau_\sim$.

Conditions for $\tilde f$ to be a homeomorphism

Note that if $\tilde f([x]) = \tilde f([y])$, then $f(x) = f(y)$, and so by the hypothesis, $x\sim y$ and thus $[x] = [y]$. Therefore $\tilde f$ is injective.

Since $f$ is surjective, so is $\tilde f$, since $\tilde f(Q) = f(X) = Y$.

Now that $\tilde f\inv$ exists, by the above, $\tilde f$ and $\tilde f\inv$ are continuous. Hence $\tilde f$ is a homeomorphism.
