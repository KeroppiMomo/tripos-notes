On $X = C([0,1])$, the $L^1$ metric $d_1(f,g) = \int_{0}^{1} |f(x)-g(x)| \d x$ and the $L^\infty$ metric $d_\infty(f,g) = \sup_{[0,1]}|f-g|$ are not equivalent. In particular the topologies $\tau_1 \subset \tau_\infty$.

$\tau_1\subseteq \tau_\infty$

Let $U\in\tau_1$. For all $f\in U$, there exists an $\epsilon>0$ such that $B_\epsilon^1(f) \subseteq U$. Then for all $g \in B_\epsilon^\infty(f)$, $$ \begin{align*} d_1(f,g) = \int_{0}^{1} |f - g| \d x \leq (1-0) \sup_{[0,1]} |f-g| = d_\infty(f,g) < \epsilon \end{align*} $$ so $g\in B_\epsilon^1(f)$. Hence $B_\epsilon^\infty(f) \subseteq B_\epsilon^1(f) \subseteq U$ and so $U\in \tau_\infty$.

$\tau_\infty \not\subseteq \tau_1$

We want to find some $U\in \tau_\infty \setminus \tau_1$. Consider $U = B_1^\infty(0)$ and this function for each $\epsilon>0$: $$ \begin{align*} f_\epsilon(x) = \begin{cases} 1 - \frac{x}{\epsilon}, &0\leq x\leq \epsilon, \\ 0, &\epsilon<x\leq 1. \end{cases} \end{align*} $$

Note that $f_\epsilon \in B_\epsilon^1(0)$ since $\int_{0}^{1} |f(x) - 0| \d x = \epsilon/2 < \epsilon$, but $f_\epsilon\not\in B_1^\infty(0)$ since $\sup_{[0,1]}|f - 0| = 1 \nless 1$.

Therefore $B_{\epsilon}^1(0) \not\subseteq B_1^\infty(0)$ for any $\epsilon>0$, and so $B_1^\infty(0) \not\in \tau_1$.

You can fit an $L^\infty$ ball (white curves) inside an $L^1$ ball (blue curves), but you can't fit an $L^1$ ball inside an $L^\infty$ ball.
