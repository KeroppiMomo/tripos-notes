Fix $x\in Y$ and $\epsilon>0$. By uniform convergence, there exists some $N\in\N$ such that for all $n\geq N$ and $y\in Y$, we have $|f_n - f|(y) < \epsilon$. Thus $|f_N - f|(y) < \epsilon$ for all $y\in Y$.

Since $f_N$ is continuous at $x$, there exists some $\delta>0$ such that for all $y\in Y$, if $|y-x|<\delta$, then we have $|f_N(y) - f_N(x)| < \epsilon$.

Therefore, for all $y\in Y$, if $|y-x|<\delta$, then $$ \begin{align*} |f(y) - f(x)| &= |f(y) - f_N(y) + f_N(y) - f_N(x) + f_N(x) - f(x)| \\ &\leq \underbrace{|f(y) - f_N(y)|}_{\text{uniform convergence}} + \underbrace{|f_N(y) - f_N(x)|}_{\text{continuity}} + \underbrace{|f_N(x) - f(x)|}_{\text{uniform convergence}} \\ &< \epsilon + \epsilon + \epsilon = 3\epsilon \end{align*} $$ so $f$ is continuous.
