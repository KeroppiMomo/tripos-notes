Closed set contains its accumulation points

Suppose $A$ is closed and let $x\in X\setminus A$. $X\setminus A$ is open and contains $x$, so it is a neighbourhood of $x$. Then $A\cap (X\setminus A) = \emptyset$ and so $(A\setminus \set{x})\cap(X\setminus A) = \emptyset$, which shows that $x$ cannot be an accumulation point.

Containing accumulation points implies closure

Suppose $A'\subseteq A$ and consider $x\in X\setminus A$. Since $x\not\in A$, $x\not\in A'$, so there exists a neighbourhood $N_x$ of $x$ such that $\emptyset = (A\setminus \set{x})\cap N_x$, and so $N\subseteq X\setminus A$. Take an open set $U_x$ such that $x\in U_x\subseteq N_x\subseteq X\setminus A$. Therefore $$ \begin{align*} X\setminus A = \bigcup_{x\in X\setminus A} U_x \end{align*} $$ is a union of open sets and is thus open.

$A\cup A'$ is closed

Let $x\in X\setminus (A\cup A')$. Since $x\not\in A'$, there exists a neighbourhood $N$ of $x$ such that $\emptyset = (A\setminus \set{x})\cap N = A\cap N$.

Let $U$ be an open set such that $x\in U\subseteq N$. If there exists $y\in A'\cap U$, then since $U$ is an open neighbourhood of $y$, we have $\emptyset \neq (A\setminus \set{y})\cap U \subseteq A\cap U \subseteq A\cap N = \emptyset$, which is a contradiction.

Therefore we have found an open set $U\subseteq X\setminus (A\cup A')$ that contains $x$ and so $A\cup A'$ is open.

Closed set containing $A$ also contains $A'$

Let $B\supseteq A$ be closed. From the above, $B'\subseteq B$. But from the definition of accumulation points, $B' \supseteq A'$. Therefore $A'\subseteq B$.
