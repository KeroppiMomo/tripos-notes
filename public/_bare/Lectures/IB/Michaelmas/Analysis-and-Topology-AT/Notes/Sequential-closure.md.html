Definition (sequentially closed) open_in_new

Let $(X,\tau)$ be a topological space.

We say $A\subseteq X$ is sequentially closed if for every convergent sequence $\set{a_n}_{n=1}^\infty$ in $A$, its limit is also in $A$.

Examples

Definition (sequential closure) open_in_new

Let $(X,\tau)$ be a topological space and $A\subseteq X$.

The sequential closure of $A$ is defined as $\scl(A) = \sb{x\in X}{\text{there exists } \set{x_n}_{n=1}^\infty \text{ in } A \text{ such that } x_n\to x}$.

  • By definition, $A$ is sequentially closed iff $A = \scl(A)$.

Theorem (closed and sequentially closed) open_in_new

Let $(X,\tau)$ be a topological space and $A\subseteq X$ be a subset.

  • $\scl(A) \subseteq \cl(A)$. This implies if $A$ is closed, then $A$ is sequentially closed.

  • If $X$ is second countable, then $\scl(A) = \cl(A)$. This implies closed iff sequentially closed. This applies to metric spaces.
