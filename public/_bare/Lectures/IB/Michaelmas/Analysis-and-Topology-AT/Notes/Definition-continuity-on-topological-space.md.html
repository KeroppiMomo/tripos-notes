Let $(X,\tau)$ and $(Y,\rho)$ be topological spaces.

We say a function $f: X\to Y$ is continuous at $x_0\in X$ if for all neighbourhood $V$ of $f(x_0)$, we have $f\inv(V)$ being a neighbourhood of $x$.

If $(X,d)$ and $(Y,d')$ are metric spaces, this is equivalent to any of the following:

  • for all $\epsilon>0$, there exists $\delta=\delta(\epsilon)>0$ such that for all $x\in X$, if $d(x,x_0) < \delta$, then $d'(f(x), f(x_0)) < \epsilon$;

  • for all $\epsilon>0$, there exists $\delta=\delta(\epsilon)>0$ such that for all $x\in$ $B_\delta(x_0)$, we have $f(x) \in B'_{\epsilon}(f(x_0))$;

  • for all $\epsilon>0$, there exists $\delta = \delta(\epsilon)>0$ such that $B_{\delta}(x_0) \subseteq f\inv(B'_\epsilon(f(x_0)))$;

We say $f$ is continuous if this holds for all $x_0\in X$.
