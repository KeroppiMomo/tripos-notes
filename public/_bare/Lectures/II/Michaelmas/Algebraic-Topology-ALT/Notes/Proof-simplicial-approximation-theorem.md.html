$\sb{\op{St}_L(w)}{w\in V_L}$ is an open cover of $L$, so $\sb{f\inv(\op{St}_L(w))}{w\in V_L}$ is an open cover of $|K|$, which is closed and bounded. Hence there exists a Lesbegue number $δ$.

Take $r$ sufficiently large so that $μ(K^{(r)}) < δ$. Define $g: V_{K^{(r)}} \to V_L$ as follows: for each $v\in V_{K^{(r)}}$, we have $$ \begin{align*} \op{St}_{K^{(r)}}(v) \subseteq B_{μ(K^{(r)})}(v) \subseteq B_{δ}(v) \subseteq f\inv(\op{St}_L(w)) \end{align*} $$ for some $w\in V_L$. Define $g(v) = w$. Then $g$ is a simplicial approximation.

For the addendum, note if $v\in V_N$, then $f(v)$ is a vertex of $L$, so $v\in f\inv(\op{St}_L(f(v)))$, which is an open set. Thus we can shrink $δ$ so that $B_δ(v) \subseteq f\inv(\op{St}_L(f(v)))$. Now choosing $g(v) = f(v)$ works.
