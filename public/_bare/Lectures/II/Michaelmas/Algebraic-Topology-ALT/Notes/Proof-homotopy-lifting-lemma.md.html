Given $y_0\in Y$, construct a lift $\tilde H_{y_0} : W_{y_0}\times [0,1] \to X$ for some neighbourhood $W_{y_0}$ of $y_0$

For each $t\in [0,1]$, take an open neighbourhood $U_t$ of $H(y_0, t)\in X$ which is evenly covered. Find some product open neighbourhood $N_t \times I_t \subseteq H\inv(U_t)$ of $(y_0, t)$. As $\set{N_t \times I_t}_{t\in [0,1]}$ is an open cover for the compact metric space $\set{y_0} \times [0,1]$, by the Lesbegue number lemma, there exists some $N\in \N$ such that each interval $[\frac{i}{N}, \frac{i+1}{N}]$ lies entirely inside $I_{t_i}$ for some $t_i$. Thus letting $W_{y_0} = N_{t_0} \cap \ldots \cap N_{t_{N-1}}$, we have that $H(W_{y_0} \times [\frac{i}{N}, \frac{i+1}{N}])$ lies entirely inside some $U_t$.

Define $\tilde H_{y_0}(y, 0) = \tilde f(y)$. Now construct the lift inductively: if $\tilde H_{y_0}$ has been constructed on $W_{y_0}\times [0, \frac{i}{N}]$, suppose $H(W_{y_0} \times [\frac{i}{N}, \frac{i+1}{N}])$ lies entirely inside an evenly covered set $U\subseteq X$. Let $V\subseteq \tilde X$ be an open set containing $\tilde H_{y_0}(y_0, \frac{i}{N})$ such that $p|_V: V \to U$ is a homeomorphism. Shrink $W_{y_0}$ so that $\tilde H_{y_0}(W_{y_0} \times \set{\frac{i}{N}}) \subseteq V$ (i.e. replace $W_{y_0}$ with $W_{y_0} \cap \tilde H_{y_0}|_{W_{y_0} \times \set{i/N}}\inv(V)$). Then we can let $$ \begin{align*} \tilde H_{y_0}|_{W_{y_0} \times [\frac{i}{N}, \frac{i+1}{N}]} := p|_{V}\inv \circ H|_{W_{y_0} \times [\frac{i}{N}, \frac{i+1}{N}]}: \quad W_{y_0} \times [\tfrac{i}{N}, \tfrac{i+1}{N}] \to V, \end{align*} $$ and $\tilde H_{y_0}|_{W_{y_0} \times [0, \frac{i+1}{N}]}$ is continuous by the gluing lemma.

$\tilde H$ agrees on $(W_{y_0} \cap W_{y_1}) \times [0,1]$

For each $y\in W_{y_0} \cap W_{y_1}$, we have two lifts $\tilde H_{y_0}(y, \cdot)$ and $\tilde H_{y_1}(y, \cdot)$ of $H(y, \cdot)$. Thus $S = \sb{y\in [0,1]}{\tilde H_{y_0}(y, t) = \tilde H_{y_1}(y,t)}$ is both open and closed in $[0,1]$. Since $\tilde H_{y_0}(y,0) = \tilde f_0(y) = \tilde H_{y_1}(y,0)$, $S$ is non-empty, so by the connectedness of $[0,1]$, we have $S = [0,1]$.

The same argument shows uniqueness of $\tilde H$.
