Define the map $$ \begin{align*} ϕ: \Z^{V_K} &\to \Z\set{\text{path components of $|K|$}} \\ v &\mapsto \text{path component containing $v$} \end{align*} $$

$ϕ$ is surjective

Any $x\in |K|$ lies in some simplex $σ\in K$ and is path-connected to a vertex of $σ$ via a straight line.

$B_0(K)\leq \ker ϕ$

Note $$B_0(K) = d_1(C_1(K)) = \Z\sb{d_1(σ)}{\text{oriented 1-simplex }σ}.$$ For any $σ = [u,v]$ oriented 1-simplex, $u,v$ are path-connected, so $ϕ(d_1(σ)) = ϕ(v) - ϕ(u) = 0$.

$\ker ϕ \leq B_0(K)$

We claim $$ \begin{align*} \ker ϕ = \Z\sb{v-w}{v,w\in V_K \text{ in the same path component in $|K|$}}. \end{align*} $$ Indeed, suppose $ϕ(\sum_{v\in V_K} n_v v) = 0$, i.e. for each path component $P$, say containing vertices $V_P$, we have $\sum_{v\in V_P} n_v = 0$. Choosing any representative $v_P\in V_P$, we then have $\sum_{v\in V_P} n_v v = \sum_{v\in V_P\setminus \set{v_P}} n_v(v - v_P)$, so summing over all $P$'s shows the claim.

Now it suffices to show if there is a path $γ: [0,1]\to |K|$ from $v$ to $w$, then $v-w\in B_0(K)$. $I := [0,1]$ is a 1-dimensional simplicial complex, so find a simplicial approximation $Γ: I^{(r)}\to K$ to $γ$ with $Γ(0) = u$ and $Γ(1) = v$. Then letting $0, \frac{1}{n}, \ldots, \frac{n-1}{n}, 1$ be the vertices of $I^{(r)}$, we get a list $v = v_0, v_1, \ldots, v_{n-1}, v_n = w$ such that $\langle v_i, v_{i+1}\rangle\in K$. Thus $$ \begin{align*} w - v = d_1([v_0, v_1] + [v_1, v_2] + \ldots + [v_{n-1}, v_n]) \in B_0(K). \end{align*} $$
