Define the map $$ \begin{align*} ϕ: \Z^{V_K} &\to \Z\set{\text{path components of $|K|$}} \\ v &\mapsto \text{path component containing $v$} \end{align*} $$

$ϕ$ is surjective

Any $x\in |K|$ lies in some simplex $σ\in K$ and is path-connected to a vertex of $σ$ via a straight line.

$B_1(K)\leq \ker ϕ$

If $v\neq w$ lie in the same homology class, then $[[w]] - [[v]] = d_1(x) = \sum_{i=1}^{m} ([[b_i]] - [[a_i]])$ for some $x = \sum_{i=1}^{m} [[a_i, b_i]]\in C_1(K)$. We claim that there is a sequence of vertices $$ \begin{align*} v = u_0, u_1, \ldots, u_{n-1}, u_n = w \end{align*} $$ such that each consecutive pair spans a 1-simplex of $K$. This defines a path from $v$ to $w$ on $|K|$.

Perform a graph walking algorithm:

  • Step 0: Start at $u_0=v.$

  • Step $i+1$: let $[[u_i, u_{i+1}]]$ be an unused edge in the expression of $x$. If $u_{i+1}=w$, we stop. Otherwise, mark this edge as used and go to the next step.

The algorithm terminates in at most $m$ steps, since an edge is taken at most once. For every vertex $u$, every used edge into $u$ is paired with an used edge out of $u$, except when the algorithm starts at $u$ or ends at $u$. This implies it is always possible to find an unused edge $[[u_i, u_{i+1}]]$: otherwise, if $u_i=v$, then the coefficient of $[[v]]$ in $d_1(x)$ would be even, and if $u_i\neq v$, then the coefficient of $[[u_i]]$ in $d_m(x)$ would be odd.

$\ker ϕ \leq B_1(K)$

Conversely suppose $v,w\in V_K$ lie in the same path component of $|K|$, meaning there is a path $γ: [0,1]\to |K|$ from $v$ to $w$. $\{$$\op{St}$$_K(u)\mid u\in V_K\}$ is an open cover of $|K|$, so by the compactness of $[0,1]$, let $n\in \N$ be such that $γ([\frac{i}{n}, \frac{i+1}{n}])$ lies entirely within $\op{St}_K(u_i)$ for some $u_i$. Since $γ(\frac{i}{n})\in \op{St}_K(u_i) \cap \op{St}_K(u_{i-1})$, there is a simplex $σ\in K$ whose interior contains $γ(\frac{i}{n})$ and has $u_i$ and $u_{i-1}$ as vertices. Thus $\langle u_{i-1}, u_{i}\rangle\in K$ as a face of $σ$. We obtain a sequence of vertices $$ \begin{align*} v = u_0, u_1, \ldots, u_{n-2}, u_{n-1} = w \end{align*} $$ where each consecutive pair spans a 1-simplex of $K$. Hence $$ \begin{align*} [[w]] - [[v]] = d_1([[u_0, u_1]] + [[u_1, u_2]] + \ldots + [[u_{n-2}, u_{n-1}]]) \in B_{1}(K). \end{align*} $$ Hence $\ker ϕ = B_1(K)$.
