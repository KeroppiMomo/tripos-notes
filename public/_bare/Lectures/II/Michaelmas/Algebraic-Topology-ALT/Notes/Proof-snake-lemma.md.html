A lot of diagram chasing!

Construction of $δ$

Let $x\in \ker c$.

  1. Since $g$ is surjective, let $y\in B$ such that $g(y) = x$.

  2. Let $y' = b(y)$.

  3. Since $g'(y') = g'(b(y)) = c(g(y)) = c(x) = 0$, we see that $y' \in \ker g'$. By exactness at $B'$, we have $z\in A'$ such that $f'(z) = y'$.

  4. Define $δ(x) = [z] \in A'/\im a$.

Well-definedness

In step 3, since $f$ is injective, $z$ is unique. Therefore the only choice we have made is in step 1.

Suppose $g(y) = x = g(\tilde y)$ for $y,\tilde y\in B$.

  1. Therefore $y-\tilde y \in \ker b$.

  2. Since $\im f = \ker g$, let $α\in A$ such that $f(α) = y-\tilde y$.

  3. Define $y', \tilde y'\in B'$ and $z,\tilde z\in A'$ as before.

  4. Because $f'(a(α)) = b(f(α)) = b(y-\tilde y) = y'-\tilde y = f'(z-\tilde z)$, by injectivity of $f'$, we have $a(α) = z-\tilde z$.

  5. Thus $z-\tilde z\in \im a$, and so $[z] = [\tilde z]$.

Homomorphism

For $x,\tilde x\in \ker c$, we can take $y+\tilde y$ as the lift of $x+\tilde x$ to $B$. Then $\partial(x+\tilde x) = [z+\tilde z]$.

Exactness of $\ker a \xrightarrow{f_\ast} \ker b \xrightarrow{g_\ast} \ker c$

$f_\ast$ and $g_\ast$ are restrictions of $f$ and $g$ to $\ker a$ and $\ker b$ respectively. We see $f(\ker a) \leq \ker b$ from the commutative square $b\circ f = f' \circ a$, and similarly for $g(\ker b) \leq \ker c$.

Since $g\circ f = 0$, the restriction $\ker a \to \ker b \to \ker c$ is still trivial. Thus $\im f_\ast \leq \ker g_\ast$.

Conversely, if $β \in \ker g_\ast = \ker b \cap \ker g = \ker b \cap \im f$, then for $α\in A$ such that $f(α) = β$, we have $f'(a(α)) = b(f(β)) = b(0) = 0$. By injectivity of $f'$, we have $a(α) = 0$. Hence $α\in \ker a$, and so $\ker g_\ast = \im f_\ast$.

Exactness of $A'/\im a \xrightarrow{f_\ast'} B'/\im b \xrightarrow{g_\ast'} C'/\im c$

$f': A'\to B'$ sends $\im a$ into $\im b$ due to the commutative square $b\circ f = f' \circ a$, so $f'$ induces $f_\ast': A'/\im a \to B'/\im b$. Similarly $g': B'\to C'$ induces $g_\ast': B'/\im b \to C'/\im c$.

Since $g' \circ f'$ is trivial, the induced map $g_\ast' \circ f_\ast'$ is also trivial. This shows $\im f_\ast' \subseteq \ker g_\ast'$.

Conversely suppose $g_\ast'([β]) = 0 \in C'/\im c$ for $β\in B'$. Since $[g'(β)] = g_\ast'([β]) = 0$, there exists $x\in C$ such that $g'(β) = c(x)$. Because $g$ is surjective, find some $y\in B$ such that $x = g(y)$. Now $g'(β - b(y)) = g'(β) - c(g(y)) = 0$, so exactness at $B'$ gives some $z\in A'$ such that $f'(z) = β - b(y)$. Hence $f_\ast'([z]) = [f'(z)] = [β]$.

Exactness of $\ker b \xrightarrow{g_\ast} \ker c \xrightarrow{δ} A'/\im a$

For $x = g_\ast(β)$, we can choose $y=β$ as the lift of $x$ to $B$. Then $y' = 0$, $z = 0$ and $[z]=0$. Hence $x\in \ker δ$.

Conversely, suppose $x\in \ker δ$. This means $z = a(α)$ for some $α\in A$. Note $$ \begin{align*} b(y - f(α)) = b(y) - b(f(α)) = y' - f'(a(α)) = y' - f'(z) = 0 \end{align*} $$ so $y-f(α)\in \ker b$. Finally $$ \begin{align*} g_\ast(y - f(α)) = g(y) - g(f(α)) = x - 0 \end{align*} $$ so $x\in \im g_\ast$.

Exactness of $\ker c \xrightarrow{δ} A'/\im a \xrightarrow{f_\ast'} B'/\im b$

For $[z] = δ(x)$, the commutative diagram gives $$ \begin{align*} f_\ast'([z]) = [f'(z)] = [y'] = [b(y)] = 0 \in B'/\im b \end{align*} $$ so $[z]\in \ker f_\ast'$.

Conversely if $f_\ast'([z]) = 0\in B/\im b$, then letting $y' = f'(z)$, we have $[y'] = 0\in B/\im b$, so $y' = b(y)$ for some $y\in B$. Then for $x=g(y)$, note $c(x) = g'(y') = g'(f'(z)) = 0$. Therefore $x\in \ker c$ and $δ(x) = [z]$.
