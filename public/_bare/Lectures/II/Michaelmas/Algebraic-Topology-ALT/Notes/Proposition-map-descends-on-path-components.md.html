For any map $f: X\to Y$, there is a well-defined associated function $$ \begin{align*} π_0(f) : π_0(X) &\to π_0(Y) \\ [x] &\mapsto [f(x)] \end{align*} $$ where $X\to{}$$π_0(X)$${}: x\mapsto [x]$ etc sends a point to its path component.

Proof

  • If $f$${}\simeq{}$$g$, then $π_0(f) = π_0(g)$. (Proof)

  • $π_0$ preserves composition: $π_0(g\circ f) = π_0(g) \circ π_0(f)$ for maps $f: X\to Y$ and $g: Y\to Z$.

  • $π_0(\id_X) = \id_{π_0(X)}$.

  • If $f$ is a homotopy equivalence, then $π_0(f)$ is a bijection. (Proof)
