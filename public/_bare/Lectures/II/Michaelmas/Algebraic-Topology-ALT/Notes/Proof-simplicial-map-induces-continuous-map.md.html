Suppose $K$ is a simplicial complex in $\R^m$ For each simplex $σ = \langle a_0, \ldots, a_p\rangle\in K$, let $$ \begin{align*} f_σ: σ &\to f(σ) \\ \sum_{i=0}^{p} t_i a_i &\mapsto \sum_{i=0}^{p} t_i f(a_i), \end{align*} $$ which is well-defined as barycentric coordinates are unique. $f_σ$ is linear in $t_i$, so it can be extended to an affine map on $\R^m$, This shows $f_σ$ is continuous.

Note if $τ\leq σ$, then $f_τ = f_σ|_τ$. Therefore if two simplices $σ,σ'$ are not disjoint, i.e. $σ\cap σ'$ is a face of both simplices, then $f_σ|_{σ\cap σ'} = f_{σ\cap σ'} = f_{σ'}|_{σ\cap σ'}$. Therefore the $f_σ$'s glue to a well-defined function $$ \begin{align*} |f|: |K| = \bigcup_{σ\in K} σ \to |L|, \end{align*} $$ continuous by the gluing lemma.
