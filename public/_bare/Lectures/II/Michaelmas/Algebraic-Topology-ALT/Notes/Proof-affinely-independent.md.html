If $a_0, \ldots, a_n \in \R_m$ are affinely independent and $\sum_{i=1}^{n} s_i(a_i - a_0) = 0$, then $-(\sum_{i=1}^{n} s_i) a_0 + \sum_{i=1}^{n} s_i a_i = 0$. The sum of all coefficients is 0, so all $s_i=0$.

Conversely if $a_1 - a_0, \ldots, a_n - a_0$ are linearly independent and $\sum_{i=0}^{n} t_ia_i = 0$ with $\sum_{i=0}^{n} t_i = 0$, then writing $t_0 = -\sum_{i=1}^{n} t_i$, we have $$ \begin{align*} 0 = -\left(\sum_{i=1}^{n} t_i\right) a_0 + \sum_{i=1}^{n} t_i a_i = \sum_{i=1}^{n} t_i (a_i - a_0) \end{align*} $$ so all $t_i = 0$.
