Assume not. Define a function $g: D^2 \to S^1$ by sending $x$ to the first point on $S^1$ hit by the ray from $f(x)$ through $x$. (This definition only makes sense because $f(x)\neq x$.)

Since $f$ is continuous, so is $g$. Moreover for $x\in S^1$, we have $g(x) = x$, so $g$ is a retraction of $D^2$ to $S^1$. But this is impossible.
