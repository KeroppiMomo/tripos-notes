Assume not. Define a function $g: D^n \to S^{n-1}$ by sending $x$ to the first point on $S^{n-1}$ hit by the ray from $f(x)$ through $x$. (This definition only makes sense because $f(x)\neq x$.)

Since $f$ is continuous, so is $g$. Moreover for $x\in S^1$, we have $g(x) = x$, so $g$ is a retraction of $D^2$ to $S^1$. But this is impossible.

Derivation using smooth retracts

Assume not again. Since $D^n$ is compact, there exists $ε>0$ such that $|f(x) - x| \geq ε$ for all $x\in D^n$. By convolving with an appropriate function, we obtain $\tilde f: D^n \to D^n$ which is smooth and $|\tilde f(x) - f(x)| < ε/2$. Then $\tilde f$ still has no fixed point. Construct $g$ as before, which is now smooth.
