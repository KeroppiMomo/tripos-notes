Firstly we want to show $C_i\in Z(\C[G])$. For any $h\in G$, since $\mathcal{C}_i \to \mathcal{C}_i: g \mapsto hgh\inv$ is a bijection, we have $e_h C_i e_h\inv = C_i$. This holds for all $h\in G$ so $C_i \in Z(\C[G])$.

Next, suppose $z = \sum_{g\in G} α_g g\in Z(\C[G])$. Now $hzh\inv = z$ so $α_{g} = α_{hgh\inv}$ for all $g,h\in G$, and hence $g\mapsto α_g$ is constant on conjugacy classes. Hence $z = \sum_{i=1}^{k} α_{g_i} C_i$ where $g_i\in \mathcal{C}_i$ is arbitrary. This shows $\set{C_1, \ldots, C_k}$ spans $Z(\C[G])$.

Moreover the $C_i$'s are linearly independent because conjugacy classes are disjoint. Therefore $\set{C_1, \ldots, C_k}$ is a basis for $Z(\C[G])$.

Finally $Z(\C[G])$ is a subalgebra of $\C[G]$ so $C_iC_j\in Z(\C[G])$. Since $\set{C_1, \ldots, C_k}$ spans, we have $C_i C_j = \sum_{l=1}^{k} a_{ijl} C_k$ for some $a_{ijl}\in \C$. But expanding, $$ \begin{align*} C_i C_j ={}& \sum_{g\in \mathcal{C}_i} \sum_{h\in \mathcal{C}_j} e_{gh} \\ ={}& \sum_{x\in G} \#\sb{(g,h)\in \mathcal{C}_i\times \mathcal{C}_j}{gh = x} \, e_x \end{align*} $$ so $a_{ijl} = \#\sb{(g,h)\in \mathcal{C}_i \times \mathcal{C}_j}{gh = x_l}\in \Z_{\geq 0}$ for any $x_l\in \mathcal{C}_l$.
