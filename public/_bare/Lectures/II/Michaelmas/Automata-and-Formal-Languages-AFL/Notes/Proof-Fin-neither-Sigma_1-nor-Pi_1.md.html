Rice's theorem implies $\N\setminus \mathbf{K} \leq_m \mathbf{Fin}$, so we already have $\mathbf{Fin}$ is not $Σ_1$. To show $\mathbf{Fin}$ is not $Π_1$, we show $\mathbf{K} \leq_m \mathbf{Fin}$, which will imply $\N\setminus \mathbf{K} \leq_m \N\setminus \mathbf{Fin}$ and use the fact that $\N\setminus \mathbf{K}$ is not $Σ_1$.

Define the computable function $$ \begin{align*} g(w,v) = \begin{cases} \uparrow &\text{if running program $w$ with one input $w$ halts within $v$ steps}, \\ 0 &\text{otherwise}. \end{cases} \end{align*} $$ By the s-m-n theorem, let $h$ be a total computable function such that $f_{h(w),1}(v) = g(w,v)$. We claim that $h$ reduces $\mathbf{K}$ to $\mathbf{Fin}$.

  • If $w\in \mathbf{K}$, then $f_{w,1}(w) \downarrow$. This means there exists some $v'$ such that running $w$ with input $w$ halts within $v$ steps for all $v>v'$, and hence $f_{h(w),1}(v)$ converges for only finitely $v$. Thus $\mathrm{W}_{h(w)}$ is finite.

  • If $w\not\in \mathbf{K}$, then $f_{w,1}(w)\uparrow$. This means running the $w$ with input $w$ never halts. Hence $\mathrm{W}_{h(w)} = \N$.
