Rice's theorem implies $\mathbb{W}\setminus \mathbf{K} \leq_m \mathbf{Fin}$, so we already have $\mathbf{Fin}$ is not $Σ_1$. To show $\mathbf{Fin}$ is not $Π_1$, we show $\mathbf{K} \leq_m \mathbf{Fin}$, which will imply $\mathbb{W}\setminus \mathbf{K} \leq_m \mathbb{W}\setminus \mathbf{Fin}$ and use the fact that $\mathbb{W}\setminus \mathbf{K}$ is not $Σ_1$.

Consider the total computable truncated computation function $t_{w,1}(u,v)$. Define the computable function $$ \begin{align*} g(w,v) = \begin{cases} \uparrow &\text{if }t_{w,1}(w,v) = a, \\ ε &\text{otherwise}. \end{cases} \end{align*} $$ By the s-m-n theorem, let $h$ be a total computable function such that $f_{h(w),1}(v) = g(w,v)$. We claim that $h$ reduces $\mathbf{K}$ to $\mathbf{Fin}$.

  • If $w\in \mathbf{K}$, then $f_{w,1}(w) \downarrow$. This means there exists some $v'$ such that $t_{w,1}(u,v) = a$ for all $v>v'$, and hence $f_{h(w),1}(v)$ converges for only finitely $v$. Thus $\mathrm{W}_{h(w)}$ is finite.

  • If $w\not\in \mathbf{K}$, then $f_{w,1}\uparrow$. This means $t_{w,1}(w,v) = ε$ for all $v$. Hence $\mathrm{W}_{h(w)} = \mathbb{W}$.
