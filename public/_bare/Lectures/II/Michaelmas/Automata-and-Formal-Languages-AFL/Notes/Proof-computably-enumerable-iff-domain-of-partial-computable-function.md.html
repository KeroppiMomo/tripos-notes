If $X$ is computably enumerable, it is the domain of the partial computable function $ψ_X$ that is its characteristic function.

Conversely if $X$ is the domain of $f: \N \dashrightarrow \N$ partial computable, this is a program for the characteristic function of $X$:

  • Run $f$.

  • If it halts, set $R_1$ to $1$.
