Fix some $e\in \mathbb{W}$ such that $\mathrm{W}_e = \emptyset$. Defining $f: w \mapsto (w,e)$ and letting $χ$ be the characteristic function of the equivalence problem $\sb{(w,v)}{\mathrm{W}_w = \mathrm{W}_v}$, we note that the characteristic function of the emptiness problem $\sb{w}{\mathrm{W}_w = \emptyset}$ is $χ\circ f$, which we know is not computable. Since $f$ can be performed by a register machine, $χ$ is not computable.
