Let $X\subseteq \mathbb{W}^k$.

Any total function $f: \mathbb{W}^k\to\mathbb{W}$ satisfying $f(\v w)\neq ε \iff \v w\in X$ is called a characteristic function of $X$. Fixing any $a\in Σ$, the characteristic function is $$ \begin{align*} χ_X(\v w) = \begin{cases} a, &\v w\in X, \\ ε, &\v w\not\in X. \end{cases} \end{align*} $$ $X$ is called computable if $χ_X$ is computable.

Any partial function $f: \mathbb{W}^k \dashrightarrow \mathbb{W}$ with $\mathrm{dom}(f) = X$ is called a pseudo-characteristic function of $X$, and the pseudo-characteristic function of $X$ is $$ \begin{align*} ψ_X(\v w) = \begin{cases} a, &\v w\in X, \\ \uparrow, &\v w\not\in X. \end{cases} \end{align*} $$ $X$ is called computably enumerable if $ψ_X$ is computable.

  • If $X$ is computable, then so is $\mathbb{W}^k \setminus X$. (Proof)

  • If $X$ is computable, then $X$ is computably enumerable. (Proof)
