A grammar $G$ over $Σ$ is a tuple $(Σ, V, P, S)$ where

  • $Σ$ is a non-empty finite set (the alphabet, containing terminal symbols or letters);

  • $V$ is a non-empty finite set (the non-terminal symbols or variables), disjoint from $Σ$;

  • $(Ω, P)$ is a rewrite system, where $Ω = Σ\cup V$; and

  • $S\in V$ (the start symbol).

We write $\mathbb{W} = Σ^\ast$ for the set of words over $Σ$, i.e. $Σ$-strings. Also write $\mathbb{W}^+ = \mathbb{W} \setminus \set{ε}$ for the set of non-empty words.

Any subset $L\subseteq \mathbb{W}$ is a language over $Σ$.

The language generated by $G$ is $$ \begin{align*} \mathcal{L}(G) = \mathbb{W} \cap \mathcal{D}(G, S) = \set{w\in \mathbb{W} \; | \; S\xrightarrow{G} w}. \end{align*} $$
