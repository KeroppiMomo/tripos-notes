Fix an alphabet $Σ$ and enlarge it by adding the following symbols to a larger alphabet $Σ'$: $$ \begin{align*} \mathbf{0} \quad \mathbf{1} \quad \mathbf{ε} \quad \mathbf{+} \quad \mathbf{?} \quad \mathbf{-} \quad \mathbf{(} \quad \mathbf{)} \quad \mathbf{,} \quad \mathbf{\mapsto} \quad \mathbf{\square} \end{align*} $$

We devise a coding: (write $\op{code}(k)$ for the encoding of $k$)

  • Natural number: encode in binary, e.g. $\op{code}(13) = \mathbf{1101}$.

  • State: since only the size of $Q$ matters, fix some listing $Q = \set{q_0, \ldots, q_k}$. Then say $\op{code}(q_i) = \op{code}(i)$.

  • Instruction: encode using $\mathbf{+}$, $\mathbf{?}$ and $\mathbf{-}$, e.g. $\op{code}(+(k,q,q')) = \mathbf{+(} \op{code}(k) \mathbf{,} \op{code}(q) \mathbf{,} \op{code}(q')\mathbf{)}$.

  • Program line: $\op{code}(q\mapsto P(q)) = \op{code}(q)\mathbf{\mapsto}\op{code}(P(q))$.

  • Register machine: $\op{code}(Σ, Q, P) = \op{code}(q_0 \mapsto P(q_0)) \mathbf{,} \ldots \mathbf{,}\op{code}(q_k\mapsto P(q_k))$.

  • Sequence of words: $\op{code}(\v w) = w_0\mathbf{\square}\ldots \mathbf{\square}w_n \mathbf{\square}$.

  • Configuration: $\op{code}(q,\v w) = \op{code}(q)\mathbf{\square}\op{code}(\v w)$.

A register machine can:

  • determine whether a word is a code about an instruction or a state etc.;

  • determine what state a given configuration is, what the instruction for a given state is etc;

  • perform the operation that assigns, to a configuration and an instruction's code, the code of the transformed configuration;

  • perform the operation $(\op{code}(M), \op{code}(\v w), v) \mapsto \op{code}($$C$$(\#(v), M, \v w))$ (by recursion of transforming configurations);

  • perform the operation $$ \begin{align*} t_{M,k}(\v w, v) = \begin{cases} a, &\text{$M$ has halted with input $\v w$ after at most $\#(v)$ steps}, \\ ε, &\text{otherwise} \end{cases} \end{align*} $$ called the truncated computation of $M$. (Algorithm)

  • The software principle: there is a universal register machine $U$ such that $$ \begin{align*} f_{U,2}(v,u) = \begin{cases} f_{M,k}(\v w), &\text{$v=\op{code}(M), u = \op{code}(\v w)$ for some} \\ &\text{register machine $M$ and sequence $\v w$ of words of length $k$}, \\ \uparrow, &\text{otherwise}. \end{cases} \end{align*} $$ (Proof)

    We can then extend notation: for arbitrary $v\in \mathbb{W}$, define $f_{v,k}(\v w) = f_{U,2}(v,\op{code}(\v w))$.
