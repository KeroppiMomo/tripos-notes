Forward direction

Given an essentially $\mathsf{Q}$ language $L$, witnessed by an essentially $\mathsf{Q}$ grammar $G$, notice since all rules are $ε$-adequate, no rule can introduce an instance of $S$, and the only instance of $S$ is rewritten into a string without $S$ in the first step of a derivation. Let $G'$ be the $\mathsf{Q}$ grammar obtained by removing the rule $S\to ε$ from $G$, producing a $\mathsf{Q}$ language $L'$.

The unique $G$-derivation that uses the rule $S\to ε$ is precisely $S \xrightarrow{G}_1 ε$. Then any other $G$-derivation is a $G'$-derivation. Thus $L=L'$ if $G$ does not contain $S\to ε$ and $L=L'\cup \set{ε}$ otherwise.

Backward direction

If $L'$ is a $\mathsf{Q}$ grammar, then it is produced by an $ε$-adequate and $\mathsf{Q}$ grammar $G$, so $L'$ is essentially $\mathsf{Q}$.

To produce $L'\cup \set{ε}$, add the rule $S\to ε$ to $G$.
