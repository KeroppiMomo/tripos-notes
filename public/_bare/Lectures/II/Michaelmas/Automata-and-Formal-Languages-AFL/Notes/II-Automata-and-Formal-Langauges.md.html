Definition (strings) open_in_new

Here the natural numbers are $\N = \set{0, 1, 2, \ldots}$ and we represent $n\in \N$ as $n=\set{0,1,\ldots,n-1}$.

Let $X$ be a set.

  • $X^n = \set{\text{functions }n\to X}$ is the set of $X$-strings of length $n$.

  • $X^0 = \set{ε}$ contains only the empty sequence $ε$.

  • $X^\ast = \bigcup_{n\in \N} X^n$ is the set of all $X$-strings.

  • $X^+ = X^\ast \setminus \set{0}$ is the set of non-empty strings.

  • For $α\in X^\ast$, its length $|α| = n$ if $α\in X^n$.

  • For $k\leq n$, $α\in X^n$, the unique initial segment of $α$ of length $k$ is denoted $α|_k$.

  • For $α,β\in X^\ast$, their concatenation $αβ \in X^{|α| + |β|}$ is defined as $αβ(k) = α(k)$ if $k\leq |α|$ and $αβ(k) = β(k-|α|)$ if $k>|α|$.

  • For $α\in X^\ast$, define $α^n$ as the concatenation of $n$ copies of $α$ (recursively as $α^0 = ε$, $α^{n+1} = α^n α$).

  • If $Y,Z\subseteq X^\ast$, write $YZ = \sb{αβ}{α\in Y, β\in Z}$.

  • Any function $f: X\to Y$ can be extended to $\hat f: X^\ast\to Y^\ast$ by $\hat f(ε) = ε$ and $\hat f(αx) = \hat f(α) f(x)$ for $α\in X^\ast$ and $x\in X$.

Definition (rewrite systems) open_in_new

A rewrite system $R$ is a pair $(Ω, P)$ where

  • $Ω$ is a non-empty finite set (of symbols); and

  • $P\subseteq$ $Ω^+$ $\times$ $Ω^\ast$ is a finite set (of rewrite rules or production rules).

We write $α\to β$ for an element $(α,β)\in P$.

For $σ,τ\in Ω^\ast$, we write $σ \xrightarrow{R}_1 τ$ if there exists $α,β,δ,γ\in Ω^\ast$ such that $σ = αβγ$, $τ = αδγ$ and $β\toδ\in P$. We say "$R$ produces $τ$ from $σ$ in one step" or "$R$ rewrites $σ$ into $τ$ in one step".

The relation $\xrightarrow{R}$ is the transitive and reflexive closure of $\xrightarrow{R}_1$, i.e. $σ\xrightarrow{R} τ$ if and only if $σ=τ$ or there exists a sequence $(σ_0, σ_1, \ldots, σ_n)$ such that $σ = σ_0 \xrightarrow{R}_1 σ_1 \xrightarrow{R}_1 \ldots\xrightarrow{R}_1 σ_n = τ$. We say "$R$ produces $τ$ from $σ$", "$R$ rewrites $σ$ into $τ$", or "$τ$ can be derived from $σ$ in $R$". We call such a sequence an "$R$-derivation of $τ$ from $σ$ using $R$ of length $n$".

If $α\in Ω^\times$, write $\mathcal{D}(R,α) = \set{β\in Ω^\times \; | \; α \xrightarrow{R} β}$ for the set of strings that can be derived from $α$.

Definition (grammar, language) open_in_new

A grammar $G$ over $Σ$ is a tuple $(Σ, V, P, S)$ where

  • $Σ$ is a non-empty finite set (the alphabet, containing terminal symbols or letters);

  • $V$ is a non-empty finite set (the non-terminal symbols or variables), disjoint from $Σ$;

  • $(Ω, P)$ is a rewrite system, where $Ω = Σ\cup V$; and

  • $S\in V$ (the start symbol).

We write $\mathbb{W} = Σ^\ast$ for the set of words over $Σ$, i.e. $Σ$-strings. Also write $\mathbb{W}^+ = \mathbb{W} \setminus \set{ε}$ for the set of non-empty words.

Any subset $L\subseteq \mathbb{W}$ is a language over $Σ$.

The language generated by $G$ is $$ \begin{align*} \mathcal{L}(G) = \mathbb{W} \cap \mathcal{D}(G, S) = \set{w\in \mathbb{W} \; | \; S\xrightarrow{G} w}. \end{align*} $$

Definition (isomorphic grammars) open_in_new

A function $f: Ω = Σ\cup V\to Ω' = Σ\cup V'$, extended to $Ω^\ast \to Ω'^\ast$, is an isomorphism between $G$ and $G'$ if

  1. $f|_Σ = \id_Σ$;

We say $G, G'$ are isomorphic if such an $f$ exists.

Definition (noncontracting, context-sensitive, context-free, regular, Chomsky hierarchy) open_in_new

Let $G = (Σ, V, P, S)$ be a grammar. A rewrite rule $α\to β$ is called

  • noncontracting if $|α| \leq |β|$;

  • context-sensitive if it is $γAδ \to γηδ$ for some $γ, δ, η\in Ω^\ast$, $A\in V$ and $η\neq ε$;

  • context-free if it is $A \to β$ for some $A\in V$ and $|β|\geq 1$;

  • regular if it is a terminal rule $A \to a$ or a nonterminal rule $A \to aB$ for some $A,B\in V$ and $a\in Σ$.

Let $\mathsf{Q}$ be one of these properties.

A grammar is called $\mathsf{Q}$ if all of its rewrite rules are $\mathsf{Q}$.

A language is called $\mathsf{Q}$ if it is produced by a grammar that is $\mathsf{Q}$. The Chomsky hierarchy is

  • type 0 language: language generated by any grammar;

  • type 1 language: context-sensitive language;

  • type 2 language: context-free language;

  • type 3 language: regular language;


  • Regular $\implies$ context-free $\implies$ context-sensitive $\implies$ noncontracting.

Definition (deterministic automaton) open_in_new

A deterministic automaton is a tuple $D = (Σ, Q, δ, q_0, F)$ where

  • $Σ$ is a non-empty finite set (the alphabet);

  • $Q$ is a non-empty finite set (of states);

  • $δ: Q\times Σ\to Q$ (the transition function);

  • $q_0 \in Q$ (the start state); and

  • $F\subseteq Q\setminus \set{q_0}$ a subset (of accepting states).

Extend $δ$ to $\hat δ: Q\times \mathbb{W}\to Q$ by $$ \begin{align*} \hat δ(q, ε) = q, \qquad \hat δ(q, wa) = δ(\hat δ(q, w), a). \end{align*} $$

For every word $w=a_0 a_1 \ldots a_n\in \mathbb{W}$, the state sequence of the computation is $$ \begin{alignat}{1} q_0 & &&= \hat δ(q_0, ε), \\ q_1 &= δ(q_0, a_0) &&= \hat δ(q_0, a_0), \\ q_2 &= δ(q_1, a_1) &&= \hat δ(q_0, a_0 a_1), \\ \vdots \\ q_{n+1} &= δ(q_n, a_n) &&= \hat δ(q_0, a_0 a_1 \ldots a_n) = \hat δ(q_0, w). \end{alignat} $$

The language accepted by $D$ is $$ \begin{align*} \mathcal{L}(D) = \sb{w\in \mathbb{W}}{\hat δ(q_0, w) \in F}. \end{align*} $$

Definition (homomorphic automata) open_in_new

Let $D = (Σ, Q, δ, q_0, F)$ and $D' = (Σ, Q', δ', q_0', F')$ be deterministic automata over the same alphabet $Σ$.

A map $f: Q \to Q'$ is a homomorphism from $D$ to $D'$ if

  • $f(δ(q, a)) = δ'(f(q), a)$ for all $q\in Q$ and $a\in Σ$;

  • $f(q_0) = q_0'$; and

  • for any $q\in Q,$ we have $q\in F$ iff $f(q) \in F'$.

$f: Q\to Q'$ is an isomorphism if $f$ is a bijective homomorphism.

  • By induction, we also have $f(\hat δ(q), w) = \hat δ'(f(q), w)$ for any $q\in Q$, $w\in \mathbb{W}$.

Definition (nondeterministic automata) open_in_new

Definition (finitely branching tree) open_in_new

A subset $T\subseteq \mathbb{N}$$^\ast$ is said to be a finitely branching tree if

  • $T$ is closed under initial segments, i.e. if $t\in T$ and $s\subseteq t$, then $s\in T$; and

  • for each $t\in T$, there exists some $n\in \N$ such that $tk\in T$ iff $k<n$.


  • We say $t$ has $n$ successors or is $n$-branching.

  • An element $t\in T$ is a leaf or terminal node if it has no successors.

  • $ε$ is contained in every non-empty tree, and is called the root.

  • The $k$-th level of $T$ is all elements of length $k$.

  • The height of $T$ is the maximal $k\in \N$ such that $T$ has an element on the $k$-th level. This exists if $T$ is a finite tree.

  • For $t\in T$ on the $k$-th level, the corresponding branch through $T$ is the sequence $\sb{t|_m}{m\leq k}$, which is a sequence of nodes of $T$ of length $k+1$.

Define the left-to-right order $<$ as $$ \begin{align*} s<t\iff s\neq t \text{ and if $k$ is least such that $s(k)\neq t(k)$, then $s(k) < t(k)$}. \end{align*} $$

  • This defines a partial order on $T$.

  • $<$ is a total order on the set of nodes on the same level.

  • $<$ is a total order on the set of leaves of $T$.

Definition (parse tree) open_in_new

Let $G = (Σ, V, P, S)$ be a context-free grammar, and $A\in V$ be a variable.

A pair $\mathbf{T} = (T,l)$ is a $G$-parse tree starting from $A$ if $T$ is a finite finitely branching tree and $l: T \to Ω$ satisfying

  • $l(ε) = A$;

  • if $l(t) \in Σ$, then $t$ is a leaf in $T$; and

  • if $l(t) \in V$ and $t$ is $n+1$-branching ($n\in \N$, i.e. $t$ is not a leaf), then there is a rule $l(t) \to x_0 x_1 \ldots x_n \in P$ such that $l(tk) = x_k$ for all $k=0,1,\ldots,n$.

Write $σ_\mathbf{T} = l(t_0) \ldots l(t_m)$ for the string parsed by $\mathbf{T}$, where $l_0 < t_1 < \ldots < t_m$ are the leaves of $\mathbf{T}$ totally-ordered by the left-to-right order.

For $t\in T$ not a leaf, define the subtree at $t$ by $\mathbf{T}_t = (T_t, l_t)$ where $T_t = \sb{s\in \N^\ast}{ts\in T}$ and $l_t(s) = l(ts)$.

  • $\mathbf{T}_t$ is a $G$-parse tree starting from $l(t).$

  • Under the left-to-right ordering, the leaves of $\mathbf{T}_t$ are a consecutive sequence of the leaves of $\mathbf{T}$. Therefore $σ_\mathbf{T} = u σ_{\mathbf{T}_t} v$, where $u\in \mathbb{W}$ corresponds to all leaves of $\mathbf{T}$ to the left of leaves of $\mathbf{T}_t$, and $w\in \mathbb{W}$ corresponds to all leaves of $\mathbf{T}$ to the right of leaves of $\mathbf{T}_t$.

If $\mathbf{T}$ and $\mathbf{T}'$ are $G$-parse trees, $t\in T$ with $l(t) = A$ and $\mathbf{T}'$ starts from $A$, then we can graft $\mathbf{T}'$ into $\mathbf{T}$: define $\mathrm{graft}(\mathbf{T}, t, \mathbf{T}') = (T^\star, l^\star)$ where $T^\star = \sb{s\in T}{t\not\subseteq s} \cup \sb{ts}{s\in T'}$ and $$ \begin{align*} l^\star(s) = \begin{cases} l(s), &\text{if } t\not\subseteq s, \\ l'(u), &\text{if } s = tu \text{ for some $u\in T'$}. \end{cases} \end{align*} $$

  • Grafting corresponds to removing the subword $σ_{\mathbf{T}_t}$ from $σ_{\mathbf{T}}$ and replacing it with $σ_{\mathbf{T}'}$.

Definition (register machine) open_in_new

A $Σ$-register machine is a tuple $M = (Σ, Q, P)$ where

  • $Σ$ is a non-empty finite set (the alphabet);

  • $Q$ is a finite set (of states) with two special elements $q_\mathrm{S} \neq q_\mathrm{H}$ (the start state and the halt state); and

  • $P$ is a function with domain $Q$ (the program), such that each $P(q)$ is a $(Σ, Q)$-instruction, i.e. tuple of one of the following forms: ($k\in \N$, $a\in Σ$, $q\in Q$, $q'\in Q$)

Instruction

Interpretation

$+(k,a,q):=(0,k,a,q)$

Add the letter $a$ to the content of register $k$;
then go to state $q$.

$?(k,a,q,q'):=(1,k,a,q,q')$

If the last letter in register $k$ is $a$:
 go to state $q$;
otherwise:
 go to state $q'$.

$?(k,ε,q,q'):=(2,k,q,q')$

If register $k$ is empty:
 go to state $q$;
otherwise:
 go to state $q'$.

$-(k,q,q'):=(3,k,q,q')$

If register $k$ is empty:
 go to state $q$;
otherwise:
 remove the final letter of its content;
 and go to state $q'$.

$q\mapsto P(q)$ is called a program line.

Definition (computation on register machine) open_in_new

Let $M = (Σ, Q, P)$ be a register machine.

  • The upper register index $n$ of $M$ is the maximal register number that appears in any of the (finite) instructions in the range of $P$.

  • A configuration or snapshot of length $m$ is a sequence $C = (q, w_0, \ldots, w_{m-1}) \in Q \in \mathbb{W}^{m}$. The first entry $q$ is the state and the rest is the register content of the configuration.

  • If $m\geq n+1$, we say $M$ transforms $C$ into $C'$ if any of the following is true: (we perform the action according to $P(q)$)

    • $P(q) = +(k,a,q')$ and $C' = (q', w_0, \ldots , w_{k-1}, w_k a, w_{k+1}, \ldots, w_{m-1})$;

    • $P(q) = {?}(k,a,q',q'')$ and either

      • $w_k = va$ for some $v\in \mathbb{W}$ and $C' = (q', w_0, \ldots, w_{m-1})$, or

      • $w_k \neq va$ for all $v\in \mathbb{W}$ and $C' = (q'', w_0, \ldots, w_{m-1})$;

    • $P(q) = {?}(k,ε,q',q'')$ and either

      • $w_k = ε$ and $C' = (q', w_0, \ldots, w_{m-1})$, or

      • $w_k \neq ε$ and $C' = (q'', w_0, \ldots, w_{m-1})$;

    • $P(q) = -(k,q',q'')$ and either

      • $w_k = ε$ and $C' = (q', w_0, \ldots, w_{m-1})$, or

      • $w_k = va$ for some $v\in \mathbb{W}, a\in Σ$ and $C' = (q'', w_0, \ldots, w_{k-1}, v, w_{k+1}, \ldots, w_{m-1})$.

  • For some $\v w = (w_0, \ldots, w_n)\in \mathbb{W}^{n+1}$, the computation sequence of $M$ with input $w$ is defined recursively as $C(0, M, \mathbb{W}) = (q_\mathrm{S}, \v w)$ and $M$ transforms $C(k,M,\v w)$ to $C(k+1,M,\v w)$.

    If $\v v = (v_0, \ldots, v_k)$ is a shorter input sequence ($k<n$), interpret as $\v w = (v_0, \ldots, v_k, ε, \ldots, ε)\in \mathbb{W}^{n+1}$.

  • Say a computation sequence halts if there exists some element of the form $(q_H, \v v)$ in the sequence.

  • Say $M$ halts on input $\v w$ in $k$ steps if the computation sequence of $M$ with input $\v w$ halts and $k$ is the least number such that $C(k,M,\v w) = (q_H, \v v)$ for some $\v v\in \mathbb{W}$, called the register content at the time of halting. We also say $M$ converges on input $\v w$. If the computation sequence does not halt, we say $M$ diverges on input $\v w$.

  • For any partial function $F: \mathbb{W}^{n+1} \dashrightarrow \mathbb{W}^{n+1}$, we say $M$ performs the operation $F$ whenever upon input $\v w$, if $F(\v w)\uparrow$, then $M$ diverges on input $\v w$; and if $F(\v w)\downarrow$, then $M$ converges on input $\v w$ with register content $F(\v w)$ at the time of halting.

    If $F$ is a total function, we also say $M$ performs the total operation $F$.

Definition (computable set, computably enumerable set) open_in_new

Let $X\subseteq \mathbb{W}^k$.

Any total function $f: \mathbb{W}^k\to\mathbb{W}$ satisfying $f(\v w)\neq ε \iff \v w\in X$ is called a characteristic function of $X$. Definition (shortlex order) open_in_new

Suppose the finite alphabet $Σ$ comes with some ordering $<$.

The shortlex order is an order relation on $\mathbb{W}$ defined so that if $w = b_0 \ldots b_k, v = c_0 \ldots c_l\in \mathbb{W}$, $w<v$ iff $|w|<|v|$, or $|w| = |v|$ and $w\neq v$ and for $i$ minimal such that $b_i\neq c_i$, we have $b_i < c_i$.

  • It is a total order: irreflexive (no $w$ satisfies $w<w$), transitive (if $u<v<w$, then $u<w$) and trichotomous (either $v<w$ or $w<v$ or $v=w$).

  • $ε$ is the minimal element.

Proof

Definition (Church's recursive functions) open_in_new

The basic functions are

  • projection functions $π_{k,i}: \mathbb{W}^k \to \mathbb{W}: \v w\mapsto w_i$;

  • constant functions $\mathrm{c}_{k,ε}: \mathbb{W}^k \to \mathbb{W}: \v w\mapsto ε$; and

  • the successor function $s: \mathbb{W}\to\mathbb{W}$ of shortlex ordering.

Given $f: \mathbb{W}^m\dashrightarrow \mathbb{W}$ and $g_1, \ldots, g_m: \mathbb{W}^k\dashrightarrow \mathbb{W}$, the composition of $f$ with $(g1, \ldots, gm)$ is $$ \begin{align*} \mathbb{W}^k &\dashrightarrow \mathbb{W} \\ \v w &\mapsto f(g_1(\v w), \ldots, g_m(\v w)). \end{align*} $$

Given $f: \mathbb{W}^k\dashrightarrow \mathbb{W}$ and $g: \mathbb{W}^{k+2}\dashrightarrow \mathbb{W}$, the recursion result of $f$ and $g$ is $$ \begin{align*} h: \mathbb{W}^{k+1} &\dashrightarrow \mathbb{W} \\ (\v w, ε) &\to f(\v w), \\ (\v w, s(v)) &\to g(\v w, s, h(\v w, s)). \end{align*} $$

Given $f: \mathbb{W}^{k+1} \dashrightarrow \mathbb{W}$, the minimisation result of $f$ is $$ \begin{align*} \mathbb{W}^k &\dashrightarrow \mathbb{W} \\ \v w &\mapsto \begin{cases} v, &\text{$v$ is $<$-minimal such that $f(\v w, v)=ε$ and $\forall u\leq v, f(\v w, u)\downarrow$}, \\ \uparrow, &\text{otherwise}. \end{cases} \end{align*} $$

The class of primitive recursive (partial) functions is the smallest class of partial functions containing all basic functions that is closed under composition and recursion.

The class of recursive (partial) functions is the smallest class of partial functions containing all basic functions that is closed under composition, recursion and minimisation.

Merging and splitting words open_in_new

Since addition, multiplication etc are recursive, they are computable. Thus we have access to arithmetics.

Consider the Cantor zigzag bijection $$ \begin{align*} z: (i,j) \mapsto \frac{(i+j)(i+j+1)}{2} + j. \end{align*} $$

The bijection $\mathbb{W}^2\to \mathbb{W}: (v,w)\mapsto u$ where $\#(u) = z(\#(v), \#(w))$ is computable. Thus we can merge $v$ and $w$ into a single word $u = v*w$.

Its inverse $\cdot_{(0)}$, $\cdot_{(1)}$ is also computable: search all possible values of $v,w\leq u$ and check if $u = v*w$. This is called splitting $u$ into two words.

We devise a coding: (write $\op{code}(k)$ for the encoding of $k$)

  • Natural number: encode in binary, e.g. $\op{code}(13) = \mathbf{1101}$.

Definition (many-one reducible, equivalent) open_in_new

Let $L, L'\subseteq \mathbb{W}$ be languages.

A total computable function $f: \mathbb{W}\to \mathbb{W}$ is called a reduction of $L$ to $L'$ if for all $w\in \mathbb{W}$, $$ \begin{align*} w\in L \iff f(w) \in L'. \end{align*} $$

We say $L$ is many-one reducible to $L'$ (denoted as $L\leq_m L'$) if there is a reduction from $L$ to $L'$.

We say $L$ is many-one equivalent to $L'$ (denoted as $L\equiv_m L'$) if $L\leq_m L'$ and $L'\leq_m L$.

  • $\leq_m$ is a partial preorder, i.e. it is reflexive ($L\leq_m L$ via $f=\id_\mathbb{W}$) and transitive (if $L_1 \leq_m L_2$ and $L_2 \leq_m L_3$, then $L_1 \leq_m L_3$ by concatenation of reductions).

  • $\equiv_m$ is an equivalence relation.

  • Note $L\leq_m L'\iff \mathbb{W}\setminus L \leq_m \mathbb{W}\setminus L'$. Thus $L$ and $\mathbb{W}\setminus L$ is either many-one equivalent or incomparable by $\leq_m$.

Definition (index set) open_in_new

A set $I\subseteq \mathbb{W}$ is called an index set if it is closed under weak equivalence, i.e. if $w\in I, v\in \mathbb{W}$ and $\mathrm{W}_w = \mathrm{W}_v$, then $v\in I$.

  • Any non-empty index set is infinite by the padding lemma.

Theorem (Rice) open_in_new

If an index set $I$ is not trivial ($I\neq \emptyset$ and $I\neq \mathbb{W}$), then $I$ is not computable.

In particular, let $e\in \mathbb{W}$ such that $\mathrm{W}_e = \emptyset$.

  • If $e\in I$, then $\mathbb{W}\setminus \mathbf{K}\leq_m I$;

  • If $e\not\in I$, then $\mathbf{K}\leq_m I$.

Decision problems as computability of sets open_in_new

Consider an encoding of grammars as words in $\mathbb{W}$: for every word $w$, there is a grammar $G_w$, and all grammars are of this form.

Then we can recast the decision problems:

  • the word problem: $\sb{(u,v)}{u\in \mathcal{L}(G_v)}$;

  • the emptiness problem: $\sb{u}{\mathcal{L}(G_u) = \emptyset}$;

  • the equivalence problem: $\sb{(u,v)}{\mathcal{L}(G_u) = \mathcal{L}(G_v)}$,

and we say a decision problem is solvable if the set is computable.

It can be shown that there are total computable functions that translate between codes of grammars and register machines and vice versa. They then witness the many-one equivalences $$ \begin{alignat}{1} \mathbf{K}_0 &= \sb{(w,v)}{w\in \mathrm{W}_v} &&\equiv_m \sb{(u,v)}{u\in \mathcal{L}(G_v)}, \\ \mathbf{Emp} &:= \sb{u}{\mathrm{W}_u = \emptyset} &&\equiv_m \sb{u}{\mathcal{L}(G_u) = \emptyset}, \\ \mathbf{Fin} &:= \sb{u}{\mathrm{W}_u \text{ is finite}} &&\equiv_m \sb{u}{\mathcal{L}(G_u) \text{ is finite}}, \\ \mathbf{Inf} &:= \sb{u}{\mathrm{W}_u \text{ is infinite}} &&\equiv_m \sb{u}{\mathcal{L}(G_u) \text{ is infinite}}, \\ \mathbf{Tot} &:= \sb{u}{\mathrm{W}_u = \mathbb{W}} &&\equiv_m \sb{u}{\mathcal{L}(G_u) = \mathbb{W}}, \\ \end{alignat} $$

$\mathbf{Emp}, \mathbf{Fin}, \mathbf{Inf}, \mathbf{Tot}$ are non-trivial index sets. By Rice's theorem, we obtain $\mathbb{W}\setminus \mathbf{K} \leq_m \mathbf{Emp}, \mathbf{Fin}$ and $\mathbf{K}\leq_m \mathbf{Inf}, \mathbf{Tot}$. This shows the emptiness problem for type 0 languages is not solvable.
