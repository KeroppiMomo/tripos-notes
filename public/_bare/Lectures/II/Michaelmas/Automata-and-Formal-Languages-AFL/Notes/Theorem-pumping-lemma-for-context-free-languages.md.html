For any context-free language $L\subseteq Σ^\ast$, there exists $n\in \N$ such that for all $u\in L$, if $|u|\geq n$, then there are subwords $v,w,x,y,z\in Σ^\ast$ such that

  1. $u = vwxyz$;

  2. $w$ and $y$ are not both $ε$;

  3. $|wxy|\leq n$;

  4. $vw^k xy^k z\in L$ for all $k=0,1,2,\ldots$.
