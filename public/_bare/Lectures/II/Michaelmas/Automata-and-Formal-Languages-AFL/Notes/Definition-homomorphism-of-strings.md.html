Let $Σ$ and $Π$ be alphabets.

A homomorphism $h:{}$$Σ^\ast$$\to Π^\ast$ is a function satisfying $h(αβ) = h(α)h(β)$ for all $α,β\in Σ^\ast$.

Given any function $f: Σ\to Π^\ast$, there is a unique homomorphism $\hat f: Σ^\ast\to Π^\ast$ extending $f$, given by $\hat f(ε) = ε$ and $\hat f(αx) = \hat f(α) f(x)$ for $α\in Σ^\ast$ and $x\in Σ$.
