Suppose $I = (Σ, Q, δ, q_0, F)$ and $I' = (Σ, Q', δ', q_0', F')$ are irreducible and accept the same language. WLOG assume $Q$ and $Q'$ are disjoint.

Indistinguishability is an equivalence relation $\sim$ on both $Q$ and $Q'$. Extend it to $Q\cup Q'$: for $q\in Q$ and $q'\in Q'$, say $q\sim q'$ if for all word $w\in \mathbb{W}$, we have $\hat δ(q, w) \in F\iff \hat δ'(q', w) \in F'$.

Since $\sb{w\in \mathbb{W}}{\hat δ(q_0, w)\in F} = \mathcal{L}(I) = \mathcal{L}(I') = \sb{w\in \mathbb{W}}{\hat δ'(q_0', w)\in F}$, we know $q_0 \sim q_0'$.

Every state in $Q$ is indistiguishable from some state in $Q'$

All states in $Q$ are accessible, so let $\mathrm{sp}(q)$ denote the length of the shortest path from $q_0$ to $q\in Q$. We prove by induction on $\mathrm{sp}(q)$.

For $\mathrm{sp}(q) = 0$, we know $q = q_0 \sim q_0'$.

Suppose $\mathrm{sp}(q) = k+1$ and write $q = δ(p,a)$ for some $p\in Q, q\in Σ$ with $\mathrm{sp}(p) = k$. By induction hypothesis, $p \sim p'$ for some $p'\in Q'$. Let $q' = δ(p',a)$, If $w$ distinguishes $q$ and $q'$, then $aw$ distinguishes $p$ and $p'$, which is not true. Thus $q\sim q'$.

No two states in $Q'$ are indistinguishable from the same state in $Q$

Transitivity of $\sim$ means $p'\sim q\sim q'$ implies $p'\sim q'$, but $Q'$ has no indistinguishable states, so $p' = q'$.

Homomorphism

Define $f: Q \to Q'$ by letting $f(q)$ be the unique $q'\in Q'$ such that $q \sim q'$. Swapping $Q$ and $Q'$, we know no two states in $Q$ are indistinguishable from the same state in $Q$, which gives injectivity of $f$.

Check that it is a homomorphism:

  • $f(δ(p,a)) = δ'(f(p), a)$: we need to show if $p \sim p'$, then $δ(p,a) \sim δ'(p',a)$. If $w$ distinguishes $δ(p,a) \sim δ'(p', a)$, then $aw$ distinguishes $p$ and $p'$, which is impossible.

  • $q_0 \sim q_0'$.

  • If $q\in F$ and $q'\not\in F'$, then $ε$ distinguishes between them, so $q \not\sim q'$.

Since $I$ and $I'$ are irreducible, $f$ is bijective.
