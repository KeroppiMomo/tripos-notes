Suppose $I = (Σ, Q, δ, q_0, F)$ and $I' = (Σ, Q', δ', q_0', F')$ are irreducible and accept the same language. WLOG assume $Q$ and $Q'$ are disjoint.

Indistinguishability is an equivalence relation $\sim$ on both $Q$ and $Q'$. Extend it to $Q\cup Q'$: for $q\in Q$ and $q'\in Q'$, say $q\sim q'$ if for all word $w\in Σ^\ast$, we have $\hat δ(q, w) \in F\iff \hat δ'(q', w) \in F'$.

Since $Q$ has no indistinguishable states, no distinct $q_1, q_2\in Q$ lie in the same $\sim$-equivalence class. Same for $Q'$. Hence each equivalence class of $\sim$ contains at most one element of $Q$ and at most one element of $Q'$.

On the other hand, since $\sb{w\in Σ^\ast}{\hat δ(q_0, w)\in F} = \mathcal{L}(I) = \mathcal{L}(I') = \sb{w\in Σ^\ast}{\hat δ'(q_0', w)\in F}$, we know $q_0 \sim q_0'$. Therefore $\hat δ(q_0, w) \sim {\hat δ}'(q_0', w)$ for all $w\in Σ^\ast$ (otherwise if $u\in Σ^\ast$ distinguishes them, then $wu$ distinguishes $q_0$ and $q_0'$). Since all states in $Q$, $Q'$ are accessible, for each $q\in Q$ there is some $q'\in Q'$ such that $q\sim q'$, and vice versa. Thus each $\sim$-equivalent class has exactly one element of $Q$ and exactly one element of $Q'$

Homomorphism

Define $f: Q \to Q'$ by letting $f(q)$ be the unique $q'\in Q'$ such that $q \sim q'$.

Check that it is a homomorphism:

  • $f(δ(p,a)) = δ'(f(p), a)$: we need to show if $p \sim p'$, then $δ(p,a) \sim δ'(p',a)$. If $w$ distinguishes $δ(p,a) \sim δ'(p', a)$, then $aw$ distinguishes $p$ and $p'$, which is impossible.

  • $q_0 \sim q_0'$.

  • If $q\in F$ and $q'\not\in F'$, then $ε$ distinguishes between them, so $q \not\sim q'$.

Since $I$ and $I'$ are irreducible, $f$ is bijective.
