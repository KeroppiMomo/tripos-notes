A set $X\subseteq \N^k$ is called $Σ_n$ if there exists a computable set $Y\subseteq \N^{k+n}$ such that for all $\v x\in \N^k$, $$ \begin{align*} \v x\in X \iff \exists y_1 \forall y_2 \exists y_3 \forall y_4 \ldots m_n: (\v x, y_1, \ldots, y_m)\in Y. \end{align*} $$

$X$ is called $Π_n$ if $\mathbb{N}^k \setminus X$ is $Σ_n$, i.e. there exists a computable set $Y\subseteq \N^{k+n}$ such that $$ \begin{align*} \v x\in X \iff \forall y_1 \exists y_2 \forall y_3 \exists y_4 \ldots m_n: (\v x, y_1, \ldots, y_m)\in Y. \end{align*} $$

$X$ is called $Δ_1$ if $X$ is both $Σ_1$ and $Π_1$.
