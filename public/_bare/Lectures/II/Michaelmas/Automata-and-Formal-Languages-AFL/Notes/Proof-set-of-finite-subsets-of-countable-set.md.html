We know that $X^\ast$ is countable, so it suffices to show there is a surjection $f: X^\ast\to \mathrm{Fin}(X)$. For any string $α\in X^\ast$, take $f(α)$ to be the range of $α$.

To show surjectivity, let $π:\N\to X$ be a surjection. Fix some finite subset $F\subseteq X$. For $x\in F$, let $n_x\in \N$ be minimal such that $π(n_x) = x$. $\sb{n_x }{x\in F} \subseteq F$ has the same size as $F$. Order by size $\set{n_0 < n_1 <\ldots < n_k} = \sb{n_x}{x\in F}$ and define $α\in X^k$ by $α(i) = π(n_i)$. Then $f(α) = F$.
