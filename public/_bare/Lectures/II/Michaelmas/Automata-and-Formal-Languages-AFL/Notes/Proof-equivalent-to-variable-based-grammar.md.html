Constructing a variable-based grammar

Let $G = (Σ, V, P, S)$ be a $\mathsf{Q}$ grammar. If $\mathsf{Q}$ is "regular", $G$ is already variable-based so we're done.

For each letter $a\in Σ$, we allocate a new variable $X_a$ (not contained in $Σ$ or $V$), and define a new set of variables $$V' = V \cup \sb{X_a}{a\in Σ}.$$

Define the map $X: Ω \to Ω$ by $$ \begin{align*} X(a) &= X_a && \text{if }a\in Σ,\\ X(A) &= A && \text{if }A\in V, \end{align*} $$ which extends to a map $X: Ω^\ast \to Ω^\ast$.

Define a new set of rewrite rules $$ \begin{align*} P' = \sb{X(α)\to X(β)}{α\to β\in P} \cup \sb{X_a \to a}{a\in Σ}, \end{align*} $$ and let $G' = (Σ, V', P', S = X(S))$, which is variable-based.

Notice $G'$ preserves any noncontracting, context-sensitive or context-free property. It suffices to show that $G$ and $G'$ are equivalent.

$w\in \mathcal{L}(G) \iff X(w) \in \mathcal{D}(G', S)$

If $w\in \mathcal{L}(G)$, let $S = σ_0 \xrightarrow{G}_1 σ_1 \xrightarrow{G}_1 \ldots \xrightarrow{G}_1 σ_n = w$ be a $G$-derivation. Then $S = X(S) = X(σ_0) \xrightarrow{G'}_1 X(σ_1) \xrightarrow{G'}_1 \ldots \xrightarrow{G'}_1 X(σ_n) = X(w)$ is a $G'$-derivation, so $X(w)\in \mathcal{D}(G', S)$.

Conversely $X(w)\in \mathcal{D}(G', S)$ contains no letters. Notice that the number of letters after any rewrite rule in $P'$ is non-decreasing, so the $G'$-derivation $S = τ_0 \xrightarrow{G'}_1 τ_1 \xrightarrow{G'}_1 \ldots \xrightarrow{G'}_1 τ_n = X(w)$ cannot contains any letters. This means all strings are of the form $τ_i = X(σ_i)$ for some $σ_i\in Ω^\ast$, and each $τ_i \xrightarrow{G'}_1 τ_{i+1}$ is an application of a rule of the form $X(α)\to X(β)$. Hence $S = σ_0 \xrightarrow{G}_1 σ_1 \xrightarrow{G}_1 \ldots \xrightarrow{G}_1 σ_n = w$ is a $G$-derivation.

$w\in Σ^\ast$ and $X(w)\in \mathcal{D}(G', S) \iff w\in \mathcal{L}(G')$

If $X(w)\in \mathcal{D}(G', S)$ and $w\in Σ^\ast$, then $w$ can be derived from $X(w)$ in $G'$ by applying rules of the form $X_a \to a$.

Conversely, suppose $w\in \mathcal{L}(G')$ and let $S = σ_0 \xrightarrow{G'}_1 σ_1 \xrightarrow{G'}_1 \ldots \xrightarrow{G'}_1 σ_n = w$ be a $G'$-derivation of $w$. Let $τ_i = X(σ_i)$.

  • If $σ_i \xrightarrow{G'}_1 σ_{i+1}$ is an application of a rule of the form $X(α)\to X(β)$, then the same rule will warrant $τ_i = X(σ_i)\xrightarrow{G'}_1 X(σ_{i+1}) = τ_{i+1}$.

  • If $σ_i \xrightarrow{G'}_1 σ_{i+1}$ is an application of a rule of the form $X_a\to a$, then $τ_{i} = X(σ_i) = X(σ_{i+1}) = τ_{i+1}$. Since for each letter $a$ in $w$ there is only one rewrite rule that produces $a$, we know exactly $|w|$ many steps of the derivation must be of this form.

Removing these $|w|$ many steps will make the remainder of the sequence a $G'$-derivation of length $n - |w|$ of $X(w)$.
