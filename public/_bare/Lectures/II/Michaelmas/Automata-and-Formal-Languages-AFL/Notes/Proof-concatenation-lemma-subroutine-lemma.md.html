Let $M=(Σ, Q, P)$ performs $F$ and $M'=(Σ, Q', P')$ performs $F'$. WLOG rename the state sets so that $Q\cap Q' = \emptyset$.

Since we only care about whether a machine performs an operation, the program line $P(q_\mathrm{H})$ at a halting state does not matter: if $q_\mathrm{H}$ is reached, the tail of the computation sequence afterwards is irrelevant for the output of the computation. So we can alter this instruction without affecting that $M$ performs $F$.

Define $\bar P$ by taking $P$, excluding $q_\mathrm{H}$ from its domain, and replacing all instances of $q_\mathrm{H}$ in the instructions by $q_\mathrm{S}'$. Then $\hat M = (Σ, Q\cup Q' \setminus \set{q_\mathrm{H}}, \bar P\cup P')$ is a register machine that performs the operation $F\circ F'.$
