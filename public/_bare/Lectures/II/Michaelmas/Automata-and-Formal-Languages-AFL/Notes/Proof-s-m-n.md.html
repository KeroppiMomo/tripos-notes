If such $τ$ exists, given $\v a$ and $\v x$, compute $τ(\v a)$, and check if it encodes a program (else loop forever). Then run the program with input $\v x$. This shows $h$ is partial computable.

Conversely, we have a program $P$ that compute $h$ on $m+k$ variables. To construct $τ$, given $\v a$, insert instructions that set register $R_1$ to $a_1$, ..., register $R_k$ to $a_k$ before $P$. Then compute the code of the new program and return.
