For a fixed $V$, there is only countably many rewrite systems on $Ω = Σ\cup V$. Therefore the set of grammars with this fixed $V$ is $$ \begin{align*} \mathcal{G}_V = \bigcup_{S\in V} \sb{(G, V, P, S)}{\text{rewrite system } (Ω, P)} \end{align*} $$ a finite union of countable sets so countable.

We know that the set of all languages produced by a grammar with $n$ variables is independent of the choice of the set of variables. Therefore fixing a countable set of variables $X_1, X_2, X_3, \ldots$ disjoint from $Σ$, every grammar is equivalent to a grammar with $V = \set{X_1, X_2, \ldots, X_n}$. Therefore the set of all languages produced by a grammar is $$ \begin{align*} \bigcup_{n\in \N} \mathcal{G}_{\set{X_1, \ldots, X_n}} \end{align*} $$ a countable union of countable sets, so countable.
