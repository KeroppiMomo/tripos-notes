Let $D = (Σ, Q, δ, q_0, F)$. If $q$ is accessible, then $δ(q,a)$ for all $a\in Σ$ are accessible. Thus letting $A\subseteq Q$ denote the set of accessible states, we can define $δ^\ast = δ|_{A\times Σ}: A\times Σ \to A$. Hence $D^\ast = (Σ, A, δ^\ast, q_0, A\cap F)$ is a deterministic automaton. Moreover we have $w\in \mathcal{L}(D^\ast) \iff \hat δ^\ast(q_0, w) \in A\cup F \iff \hat δ(q_0, w)\in F \iff w\in \mathcal{L}(D)$.

Now consider its quotient automaton $I = D^\ast/{\sim}$, which has no distinct indistinguishable states. We know $\mathcal{L}(D) = \mathcal{L}(D^\ast) = \mathcal{L}(I)$. Furthermore $I$ has no inaccessible states: all $q\in D^\ast$ can be written as $q = \hat δ(q_0, w)$, so $[q] = \widehat{[δ]}([q_0], w)$ is accessible. Hence $I$ is irreducible.
