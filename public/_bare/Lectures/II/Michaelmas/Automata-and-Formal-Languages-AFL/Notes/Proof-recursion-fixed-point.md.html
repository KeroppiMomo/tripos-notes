Define $$ \begin{align*} h(x,y) := f_{g(f_{x,1}(x)),1}(y). \end{align*} $$ This is computable as it is a composition using the universal machine $$ \begin{align*} h(x,y) = u(g(u(x, 1, 2^x)), 1, 2^y). \end{align*} $$

Apply s-m-n to obtain a total computable function $τ: \N\to \N$, say computable using machine $m$, such that $$ \begin{align*} f_{f_{m,1}(x),1}(y) = f_{τ(x), 1}(y) = h(x,y) = f_{g(f_{x,1}(x)),1}(y). \end{align*} $$

Then $n_0 = f_{m,1}(m) = τ(m)$ is the required fixed point.
