A set $X\subseteq \mathbb{W}^k$ is called $Σ_1$ if there exists a computable set $Y\subseteq \mathbb{W}^{k+1}$ such that for all $\v w\in \mathbb{W}^k$, $$ \begin{align*} \v w\in X \iff \exists v\in \mathbb{W} ((\v w,v)\in Y). \end{align*} $$

$X$ is called $Π_1$ if $\mathbb{W}^k \setminus X$ is $Σ_1$.

$X$ is called $Δ_1$ if $X$ is both $Σ_1$ and $Π_1$.
