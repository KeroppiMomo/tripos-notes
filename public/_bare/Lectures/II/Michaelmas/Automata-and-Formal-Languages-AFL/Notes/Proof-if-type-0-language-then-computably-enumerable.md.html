Let $G = (Σ, V, P, S)$ be a grammar such that $\mathcal{L}(G) = L$. Enlarge our alphabet to $Σ' = Σ \cup \set{⮕}$.

Given $σ_0, \ldots, σ_n\in Ω^\ast$, call a string of the form $$ \begin{align*} σ_0\ ⮕\ σ_1\ ⮕\ \ldots\ ⮕\ σ_n \end{align*} $$ a derivation code with start string $σ_0$ and result string $σ_n$ if $(σ_0, \ldots, σ_n)$ is a $G$-derivation.

Define $$ \begin{align*} Y = \sb{(w,v)\in \mathbb{W} \times \mathbb{W}'}{ \text{$v$ is a $G$-derivation code with start string $S$ and result string $w$}}. \end{align*} $$ A register machine can check whether a $\mathbb{W}' = (Σ')^\ast$ word is a derivation code and whether the result string coincides with $w$. Thus $Y$ is computable. By construction $$ \begin{align*} w\in \mathcal{L}(G) \iff \exists v(w,v)\in Y \end{align*} $$ so $L$ is $Σ_1$ and thus computably enumerable.
