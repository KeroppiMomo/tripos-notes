Induct on the height of the corresponding recursion tree.

Basic functions

Projection and constant functions are computable by these examples. The successor function is already proven to be computable.

Composition

See subroutine lemma.

Recursion

Fix two computable partial functions $f,g$ and inputs $\v w, v$.

  1. Empty two unused registers $k,l$.

  2. Compute $f(\v w)$.

  3. Write into register $l$.

  4. If $v$ equals the content of register $k$:

    1. Output the content of register $l$.

  5. Otherwise:

    1. Compute $g(\v w, v_0, v_1)$ where $v_0$ is the content of register $k$ and $v_1$ is the content of register $l$.

    2. Write into register $l$.

    3. Apply the successor function to the content of register $k$.

    4. Go to 4.

Minimisation

Fix a computable partial function $f$ and input $\v w$.

  1. Empty an unused register $k$.

  2. Compute $f(\v w, u)$, where $u$ is the content of register $k$.

  3. If the result is $ε$:

    1. Output the content of register $k$.

  4. Otherwise:

    1. Apply the successor function to the content of register $k$.

    2. Go to 2.
