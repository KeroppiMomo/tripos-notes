Only $|Q|$ matters up to strong equivalence.

Fixing $|Q| = n$ and $k$ is the upper register number, there are only finitely many instructions (precisely $k\cdot |Σ|\cdot n + k\cdot |Σ| \cdot n^2 + k\cdot n^2 + k\cdot n^2)$ and so only finitely many register machines up to strong equivalence. Thus the set of all $Σ$-register machines up to strong equivalence is a countable union of finite sets, thus countable.
