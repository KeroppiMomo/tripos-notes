Let $M = (Q, P)$ be a register machine.

  • The upper register index $m=\op{upper}(P)$ of $M$ is the maximal register number that appears in any of the (finite) instructions in the range of $P$.

  • Given an input $(n_1, \ldots, n_k)\in \N^k$, initialise the content of the registers $R_1,\ldots, R_k$ to be $(n_1, \ldots, n_k)$. Start at state $S_1$ and keep following the instructions. Stop if we reach $S_0$.

  • Say $M$ halts on input $(n1, \ldots, nk)\in \N^k$ we reach $S_0$ (at some finite time). We write $P(n_1, \ldots, n_k)\downarrow$. If it does not halt, we write $P(n_1, \ldots, n_k)\uparrow$.
