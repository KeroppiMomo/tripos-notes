Suppose $X\neq \emptyset$ is computably enumerable. If $X = \set{e_1, \ldots, e_k}$ is finite, then $$ \begin{align*} f(n) = \begin{cases} e_n, &n\leq k, \\ e_k, &n>k \end{cases} \end{align*} $$ works.

If $X$ is infinite, we make a total computable function $f:\N\to \N$ as follows: run a zig-zag to compute $ψ_X(i)$ for all $i\in \N$ in parallel. Define $f(m)$ to be the $(m+1)$-th $i$ for which the computation of $ψ_X(i)$ halts. ($f(0), f(1), \ldots$ is not necessarily in increasing order.)
