Each recursive function is represented by some recursion tree

All basic functions are represented by recursion trees, and the class of partial functions represented by recursion trees is closed under composition, recursion and minimisation. Since the recursive functions are the smallest class with these properties, all recursive functions are represented by a recursion tree.

All recursion trees represent some recursive function

Suppose there is a function represented by a recursion tree $Π$ that is not recursive. Assume $Π$ has minimal height.

All recursive trees of height 0 represent basic functions and thus recursive functions, so the height of $Π$ is at least 1, and hence the label of $ε$ is either a $\mathsf{C}$, $\mathsf{R}$, $\mathsf{M}$ label.

However by minimality of $Π$, the functions represented by the immediate successors of $ε$ are all recursive. Hence $Π$ represents the composition, recursion or minimisation results of those functions, which is recursive. This is a contradiction.
