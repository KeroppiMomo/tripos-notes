A set $I\subseteq \N$ is called an index set if it is closed under weak equivalence, i.e. if $w\in I, v\in \N$ and $\mathrm{W}_w = \mathrm{W}_v$, then $v\in I$.

  • Any non-empty index set is infinite by the padding lemma: adding arbitrarily many unreachable instructions results in a distinct program but same partial function.
