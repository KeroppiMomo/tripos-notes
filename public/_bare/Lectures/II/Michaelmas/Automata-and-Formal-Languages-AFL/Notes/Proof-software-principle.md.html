Input $v,u$.

  1. Ensure $v = \op{code}(M)$ for some $M$ and $u = \op{code}(\v w)$ for some $\v w$.

    1. Otherwise, diverge.

  2. Empty scratch register $i$.

  3. Compute $(q, \v w') = C(\#(u), M, \v w)$ where $u$ is the content of register $i$.

  4. If $q = q_\mathrm{H}$:

    1. Write $w_0$ into register 0 and halt.

  5. Otherwise:

    1. Apply the successor function to register $i$.

    2. Go to 3.
