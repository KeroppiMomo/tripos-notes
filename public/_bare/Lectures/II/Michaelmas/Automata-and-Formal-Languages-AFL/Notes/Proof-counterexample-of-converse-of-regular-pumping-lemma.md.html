Consider $Σ = \set{0,1}$, and if $w\in \mathbb{W}$ contains at least one $0$, write $\mathrm{tail}(w)$ for the number of $1$s in $w$ that follow the last occurring $0$ (e.g. $\mathrm{tail}(0101111) = 4$).

For any subset $X \subseteq \N$, define a language $L_X \subseteq \mathbb{W}$ by $w \in L_X$ iff either $w$ has no $0$, or $\mathrm{tail}(w) \in X$.

$L_X$ satisfies the pumping lemma with pumping number 2

Consider $w\in L_X$ with $|w|\geq 2$. Let $x = ε$, $y\in \set{0,1}$ be the first symbol of $w$, and $z$ such that $w = xyz$.

Two cases:

  • $y = 0$. Then $w$ contains a $0$ so $\mathrm{tail}(w) \in X$. Pumping up, $\mathrm{tail}(0^k z) = \mathrm{tail}(0z) \in X$ for all $k\geq 1$. Pumping down, if $z$ contains no $0$, then $z\in L_X$ immediately; otherwise $\mathrm{tail}(z) = \mathrm{tail}(0z) \in X$ so $z\in L_X$ as well.

  • $y = 1$. If $z$ contains no $0$, then $1^k z$ has no $0$ for all $k$; otherwise $\mathrm{tail}(1^k z) = \mathrm{tail}(1z)$ so $1^k z\in L_X$.

Exists non-regular language satisfying the pumping lemma

If $X,Y\subseteq \N$ are distinct, then $L_X \neq L_Y$. To see this, suppose $n\in X\setminus Y$. Then $10^n \in L_X \setminus L_Y$. Similarly for $n\in Y\setminus X$. Hence since there is uncountably many $X\subseteq \N$, there is uncountably many languages of the form $L_X$. However there are only countably many regular languages.
