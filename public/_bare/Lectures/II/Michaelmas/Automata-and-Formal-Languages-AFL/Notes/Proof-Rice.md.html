For a fixed $w\in \mathbb{W}$, consider the function $$ \begin{align*} g_w(u,v) = \begin{cases} f_{w,1}(v) &\text{if $u\in \mathbf{K}$}, \\ \uparrow &\text{otherwise}, \end{cases} \end{align*} $$ which is computable: first compute $f_{u,1}(u)$. If this diverges, we obtain the correct result. Otherwise, compute $f_{w,1}(v)$ and output the result (if there is one). Thus by the s-m-n theorem, there exists a total computable $h_w: \N\to \N$ such that $f_{h_w(u),1}(v) = g_w(u,v)$. This has the property that

  • if $u\in \mathbf{K}$, then $f_{h_w(u),1}(v) = f_{w,1}(v)$ so $\mathrm{W}_{h_w(u)} = \mathrm{W}_w$;

  • if $u\not\in \mathbf{K}$, then $f_{h_w(u),1}(v) \uparrow$, so $\mathrm{W}_{h_w(u)} = \emptyset$.

Let $I$ be our index set. By hypothesis, pick some $w_1 \in I$ and $w_0\in \N\setminus I$. Fix some $e$ such that $\mathrm{W}_e = \emptyset$. We have two cases:

  • $e\in I$: we claim that $h_{w_0}$ is a reduction of $\N\setminus \mathbf{K}$ to $I$.

    • If $u\in \mathbf{K}$, then $\mathrm{W}_{h_{w_0}(u)} = \mathrm{W}_{w_0}$, so by closure, $h_{w_0}(u) \not\in I$.

    • If $u\not\in \mathbf{K}$, then $\mathrm{W}_{h_{w_0}(u)} = \emptyset = \mathrm{W}_{e}$, so by closure, $h_{w_0}(u) \in I$.

  • $e\not\in I$: we claim that $h_{w_1}$ is a reduction of $\mathbf{K}$ to $I$.

    • If $u\in \mathbf{K}$, then $\mathrm{W}_{h_{w_1}(u)} = \mathrm{W}_{w_1}$, so by closure, $h_{w_1}(u) \in I$.

    • If $u\not\in \mathbf{K}$, then $\mathrm{W}_{h_{w_0}(u)} = \emptyset = \mathrm{W}_{e}$, so by closure, $h_{w_0}(u) \not\in I$.

Thus either $\mathbb{W}\setminus \mathbf{K}\leq_m I$ or $\mathbf{K}\leq_m I$. Since neither $\mathbb{W}\setminus \mathbf{K}$ nor $\mathbf{K}$ is computable, $I$ is not computable.
