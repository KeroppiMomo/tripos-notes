Let $Q = \sb{A_i}{i\leq k}$ be a question with $k+1$ answers and $f_i: \mathbb{W}^{n+1}\dashrightarrow \mathbb{W}^{n+1}$ for $i\leq k$.

If $Q$ is answered by a register machine $M$ and $f_i$ is performed by $M_i$ for each $i\leq k$, then we can construct a register machine that performs the operation defined by $g(\v w) = f_i(\v w)$ iff $\v w\in M_i$.
