For a $Σ$-register machine $M$ and some $k\in \N$, define a partial function $f_{M,k}: \mathbb{W}^k \dashrightarrow \mathbb{W}$ by

  • $f_{M,k}\uparrow$ if $M$ does not halt on input $\v w$; and

  • $f_{M,k}=v_0$ if $M$ halts on input $\v w$ with register content $\v v$ at the time of halting.

Write $\mathrm{W}_M = \op{dom}(f_{M,1})$. Two machines $M,M'$ are called weakly equivalent if $\mathrm{W}_M = \mathrm{W}_{M'}$.

A partial function $f: \mathbb{W}^k \dashrightarrow \mathbb{W}$ is called computable if there exists a $Σ$-register machine such that $f_{M,k} = f$.

  • Strong equivalence $\implies f_{M,k} = f_{M',k} \implies$ weak equivalence.
