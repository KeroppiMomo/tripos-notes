Let $M = (Σ, Q, P)$ be a register machine with an upper register number $n$.

A question with $k+1$ answers is a partition of $\mathbb{W}^{n+1}$ into $k+1$ disjoint sets $A_0, \ldots, A_k$.

Say $M$ answers the question $\set{A_0, \ldots, A_k}$ if

  • it has $k+1$ designated answer states $\hat q_0, \ldots, \hat q_k\in Q$; and

  • for each $\v w\in \mathbb{W}^{n+1}$, the computation of $M$ with input $\v w$ produces a configuration $(\hat q_i, \v w)$ (in finitely many steps) iff $\v w\in A_i$.
