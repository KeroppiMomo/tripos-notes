$\mathcal{L}(G)\cup \mathcal{L}(G') \subseteq \mathcal{L}(H)$

If $S\xrightarrow{G} v$, then $T \xrightarrow{H} v$ by using the rule $T\to S$. Similarly if $S'\xrightarrow{G'} w$, then $T\xrightarrow{H} w$.

$\mathcal{L}(H) \subseteq \mathcal{L}(G) \cup \mathcal{L}(G')$ when $V\cap V' = \emptyset$ and $G,G'$ are variable-based

Since $V\cap V'=\emptyset$ and $G,G'$ are variable-based, no rules from $P$ can apply to a string that contains no variables from $V$, and no rules from $P'$ can apply to a string that contains no variables from $V'$. Thus by induction, any $H$-derivation starting from $S$ only uses rules from $P$, and any $H$-derivation starting from $S'$ only uses rules from $P'$.

The only two rules involving $T$ are $T\to S$ and $T\to S'$, so any $H$-derivation $(σ_0, σ_1, \ldots, σ_n)$ starting from $σ_0 = T$ will have $σ_1 = S$ or $σ_1 = S'$. Thus $T\xrightarrow{H} v$ implies either $S\xrightarrow{G} v$ or $S'\xrightarrow{G'} v$.
