If an index set $I$ is not trivial ($I\neq \emptyset$ and $I\neq \mathbb{W}$), then $I$ is not computable.

In particular, let $e\in \mathbb{W}$ such that $\mathrm{W}_e = \emptyset$.

  • If $e\in I$, then $\mathbb{W}\setminus \mathbf{K}\leq_m I$;

  • If $e\not\in I$, then $\mathbf{K}\leq_m I$.
