We have shown $\mathbf{K}$ is $Σ_1$, so it suffices to show $X\leq_m \mathbf{K}$ for any computably enumerable language $X$.

Let $X = \mathrm{dom}(f)$ for some partial computable function $f$. Define $$ \begin{align*} g: \mathbb{W}^2 &\dashrightarrow \mathbb{W} \\ (w, u) &\mapsto f(w), \end{align*} $$ which is computable (ignore $u$ and compute $f(w)$). Apply the s-m-n theorem to $g$ to obtain a total computable function $h: \mathbb{W}\to \mathbb{W}$ such that $f_{h(w), 1}(v) = g(w,u) = f(w)$ for all $w\in \mathbb{W}$. Notice

  • if $w\in X$, then $f_{h(w),1}$ is everywhere defined and constant $f(w)$, so in particular $f_{h(w),1}(h(w)) \downarrow$; and

  • if $w\not\in X$, then $f_{h(w),1}$ is nowhere defined, so in particular $f_{h(w),1}(h(w))\uparrow$.

This implies $$ \begin{align*} w\in X \iff h(w)\in \mathbf{K}, \end{align*} $$ showing that $h$ is a reduction of $X$ to $\mathbf{K}$.
