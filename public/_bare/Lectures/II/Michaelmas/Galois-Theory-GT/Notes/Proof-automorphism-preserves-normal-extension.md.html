For any $α\in L$, let $f\in K[X]$ be its minimal polynomial over $K$. Since $σ|_K = \id_K$, $$ \begin{align*} 0 = σ(f(α)) = f(σ(α)) \end{align*} $$ so $σ(α)$ is a root of $f$. But $f$ splits into linear factors in $L$, so $σ(α) \in L$. Hence $σ(L) \subseteq L$.

Applying the same argument to $σ\inv$ shows $σ\inv(L) \subseteq L$, so $σ(L) = L$.
