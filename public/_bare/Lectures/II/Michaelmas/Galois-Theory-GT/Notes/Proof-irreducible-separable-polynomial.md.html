If $\op{char} K = p>0$ and $f(X) = g(X^p)$, then $f'(X) = p X^{p-1} g'(X^p) = 0$ as $p=0$ in $K$. Therefore $\op{gcd}(f, f') = f$, which is not 1. Hence $f$ is inseparable.

Conversely, if $f$ is inseparable, then $\op{gcd}(f,f') \neq 1$. Since $f$ is irreducible, $f\mid f'$, but because $\deg f' < \deg f$, we have $f' = 0$.

Therefore if $f(X) = \sum_{i=0}^{d} c_i X^i$, then $0 = f'(X) = \sum_{i=0}^{d} ic_i X^{i-1}$, so $ic_i = 0$ for all $i$. Thus when $i\neq 0$ in $K$, we have $c_i = 0$. If $\op{char} K = 0$, then $f$ is constant, which cannot be irreducible. So $\op{char} K =: p >0$, and $c_i = 0$ when $p\not\mid i$. Thus $f(X) = g(X^p)$ where $g(X) = \sum_{i} c_{pi}X^i$.
