Let $L/K$ be a field extension.

A polynomial $f\in k[X]$ is separable if it splits into distinct linear factors over some (equivalently all) splitting fields of $f$.

An element $α\in L$ is separable over $K$ if $α$ is algebraic over $K$, and its minimal polynomial is separable over $K$.

$L/K$ is separable if every $α\in L$ is separable over $K$.

If $L/K$ is separable, then $L/K$ is algebraic.

$f$ is separable iff $\op{gcd}$$(f,f') = 1$. Note $\op{gcd}$ is independent of which base field you take. (Proof)

If $f$ is irreducible, then $f$ is separable iff $\op{char}K =: p >0$ and $f(X) = g(X^p)$ for some $g\in k[X]$. (Proof)
