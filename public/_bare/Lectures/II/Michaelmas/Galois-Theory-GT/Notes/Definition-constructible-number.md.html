For a finite set of points $S \subseteq \R^2$, consider the three operations:

  1. draw a straight line through two distinct points $P,Q\in S$;

  2. draw a circle centred at some $P\in S$ through some $Q\in S$;

  3. enlarge $S$ by adjoining any point of intersection of two distinct lines or circles constructed using 1 and 2.

A point $(x,y)\in \R^2$ is constructible from $S$ if we can enlarge $S$ to include $(x,y)$ using a finite sequence of operations 1, 2, 3.

A number $x\in \R$ is constructible if $(x,0)$ is constructible from $\set{(0,0), (1,0)}$.
