Fix $y\in B_Y$. Perform successive approximation:

  1. Let $x_0\in MB_X$ such that $\|y - Tx_0\| \leq δ$.

  2. $(y-Tx_0)/δ\in B_Y$, so let $x_1\in MB_X$ such that $\|(y-Tx_0)/δ - Tx_1\| \leq δ$.

  3. $(y - Tx_0 - δTx_1)/δ^2\in B_Y$, so let $x_2\in MB_X$ such that $\|(y-Tx_0-δTx_1)/δ^2 - Tx_2\| \leq δ$.

And so on. We obtain a sequence $(x_n)$ in $MB_X$ such that $$ \begin{align*} \left\|y - T(x_0 + δx_1 + \ldots + δ^n x_n)\right\| \leq δ^{n+1}. \end{align*} $$

Now $\|\sum_{k=0}^{n} δ^k x_k\| \leq \sum_{k=0}^{n} δ^k M \leq M/(1-δ)$, so $\sum_{k=0}^{n} δ^kx_k\in \frac{M}{1-δ}B_{X}$, which is closed. Since $X$ is complete, $\sum_{n=0}^{\infty} δ^n x_n$ converges to say $x\in \frac{M}{1-δ} B_X$.

As $T$ is continuous, $$ \begin{align*} \|y - Tx\| = \lim_{n\to \infty} \|y - T(x_0 + δx_1 + \ldots + δ^n x_n)\| = 0 \end{align*} $$ so $Tx = y$, as required.
