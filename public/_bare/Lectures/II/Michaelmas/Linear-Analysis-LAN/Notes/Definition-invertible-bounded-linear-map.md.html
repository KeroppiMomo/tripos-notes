Let $X$ be a normed space.

$T\in{}$$\mathcal{B}(X)$ is said to be invertible if equivalently

  1. $T$ is invertible in the unital algebra $\mathcal{B}(X)$;

  2. there exists $S\in \mathcal{B}(X)$ such that $TS = ST = \id_X$;

  3. $T$ is a linear bijection and $T\inv$ is bounded, i.e. $T$ is an isomorphism of normed spaces.

Write $\mathcal{G}(X)$ for the group of invertible bounded linear operators $X\to X$.

  • If $X$ is a Banach space, then the inversion theorem says $T$ is invertible iff $T$ is a linear bijection.

  • Interaction with compact and finite-rank operators:

    • If $\dim X < \infty$, then $\mathcal{G}(X) = \mathcal{F}(K) = \mathcal{K}(K)$.

    • If $\dim X = \infty$, then $\mathcal{G}(X) \cap \mathcal{K}(K) = \emptyset$. (Proof)
