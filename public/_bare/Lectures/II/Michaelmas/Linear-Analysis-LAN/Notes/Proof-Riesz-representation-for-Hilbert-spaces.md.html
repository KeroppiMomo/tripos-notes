Well-defined and isometric

$θ_x: y \mapsto \langle y,x\rangle$ is clearly linear.

By Cauchy-Schwarz, $|θ_x(y)| = |\langle y,x\rangle| \leq \|y\| \|x\|$ so $θ_x$ is bounded with $\|θ_x\| \leq \|x\|$.

Moreover $|θ_x(\frac{x}{\|x\|})| = \|x\|$ with $\frac{x}{\|x\|}\in B_H$ so $\|θ_x\| = \|x\|$.

Conjugate-linear

$$ \begin{align*} θ_{λx + μx'}(y) = \langle y, λx + μx'\rangle = \bar λ \langle y,x\rangle + \overline{μ} \langle y,x'\rangle = (\overline{λ}θ_x + \overline{μ}θ_{x'})(y) \end{align*} $$ so $θ_{λx + μx'} = \bar λ θ_x + \bar μ θ_{x'}$.

Surjectivity

Fix $f\in H^\ast$. We want to find $x\in H$ such that $f = θ_x$.

Let $Y = \ker f$, which is a closed subspace, so $H = Y \oplus Y^\perp$. Note $Y^\perp$ is at most one-dimensional, for if $y,z\in Y^\perp$, $$ \begin{align*} f\bigl(f(y) z - f(z) y\bigr) = 0 \end{align*} $$ so $f(y) z - f(z) y \in Y \cap Y^\perp$ and hence $f(y) z - f(z) y = 0$. (Or $Y^\perp \isom H/Y \isom \im f\leq \mathbb{F}$ by the first isomorphism theorem.)

If $f = 0$ this is clear. By scaling, find $x\in Y^\perp \setminus \set{0}$ such that $f(x) = \|x\|^2$. Then for any $z \in H$, writing $z = y + λx$ where $y\in Y$ and $λ\in \mathbb{F}$, $$ \begin{align*} \langle z,x\rangle = \underbrace{\langle x,y\rangle}_{0} + λ\|x\|^2 = \underbrace{f(y)}_{0} + λ f(x) = f(z) \end{align*} $$ so $f = θ_x$.
