Let $X$ be a topological space.

A subset $A \subseteq X$ is said to be dense if equivalently

  1. $\overline{A}$${}= X$;

  2. for any open set $U\subseteq X$, we have $A \cap U\neq \emptyset$;

  3. for any open set $U\subseteq X$, we have $U \subseteq \overline{A \cap U}$.

$X$ is said to be separable if it has a countable dense set.
