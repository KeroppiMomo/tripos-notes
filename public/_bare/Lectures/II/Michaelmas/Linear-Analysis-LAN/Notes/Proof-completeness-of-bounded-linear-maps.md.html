Let $(T_n)$ be a Cauchy sequence in $\mathcal{B}(X,Y)$.

For each $x\in X$, we obtain a Cauchy sequence $(T_n x)$ in $Y$, because $\|T_n x - T_m x\| = \|(T_n - T_m)(x)\| \leq \|T_n - T_m\|\|x\| \to 0$ as $m,n\to \infty$. Since $Y$ is complete, $T_nx$ converges.

Define $T: X \to Y$ by $$ \begin{align*} Tx = \lim_{n\to \infty} T_n x. \end{align*} $$

Check $T_n \to T$ in $\mathcal{B}(X,Y)$:

  1. $T$ is linear by linearity of limits: $$ \begin{align*} T(x + λy) = \lim_{n\to \infty} T_n(x + λy) = \lim_{n\to \infty} (T_nx + λ T_n y) = \lim_{n\to \infty} T_n x + λ \lim_{n\to \infty} T_ny = Tx + λ Ty. \end{align*} $$

  2. $T$ is bounded: since $(T_n)$ is Cauchy, it is bounded, so let $M\geq 0$ such that $\|T_n\| \leq M$. Then for each $x\in X$, $\|T_n x\| \leq M \|x\|$, so taking the limit as $n\to \infty$, and noting $x \mapsto \|x\|$ is continuous, we get $\|Tx\| \leq M\|x\|$.

  3. $T_n \to T$ in operator norm: fix $ε>0$. As $(T_n)$ is Cauchy, find $N\in \N$ such that $\|T_n - T_m\| < ε$ for all $n,m\geq N$. For any $x\in X$, we get $\|T_n x - T_m x\| < ε \|x\|$. In the limit $m\to \infty$, we have $\|T_n x - Tx\| < ε\|x\|$. This holds for all $x$, so $\|T_n - T\| < ε$ for all $n\geq N$.
