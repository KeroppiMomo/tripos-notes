Since $X = \bigcup_{n\in \N} nB_X$, $Y = TX = \bigcup_{n\in \N} T(nB_X)$. $Y$ is non-empty and complete, so by Baire category, there exists $n\in \N$ such that $\op{int} \overline{T(nB_X)} \neq \emptyset$.

Let $B_r(y)\subseteq \overline{T(nB_X)}$ for some $y\in X$, $r>0$. $B_X$ is symmetric and convex, and hence so is $\overline{T(nB_X)}$. Therefore for all $z\in B_Y$, we have $y + rz\in B_r(y)\subseteq \overline{T(nB_X)}$ and $-y+rz\in -B_r(y)\subseteq \overline{T(nB_X)}$, so $rz = \frac{1}{2}(y + rz) + \frac{1}{2}(-y + rz)\in \overline{T(nB_X)}$. Hence $rB_Y \subseteq \overline{T(nB_X)}$, or equivalently $B_Y \subseteq \overline{T(\frac{n}{r} B_X)}$.

By the open mapping lemma, $B_Y \subseteq T(\frac{2n}{r} B_X)$. This proves the second formulation of the theorem.

For the first formulation, let $U$ be an open set in $X$ and $y\in T(U)$. Finding $x\in X$ and $ε>0$ such that $Tx = y$ and $x + εB_X = B_ε(x) \subseteq U$, we have $$ \begin{align*} T(U) \supseteq Tx + εT(B_X) \supseteq y + \frac{εr}{2n}B_Y = B_{εr/2n}(y) \end{align*} $$ so $T(U)$ is open.
