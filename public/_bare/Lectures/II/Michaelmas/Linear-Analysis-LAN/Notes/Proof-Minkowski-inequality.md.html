$x \mapsto x^p$ is convex on $(0,\infty)$

$\dd{x} x^p = p(p-1)x^{p-2} \geq 0$ for all $x>0$, so done by the second-order condition.

Alternatively, fix $y>0$ and $λ\in [0,1]$. It suffices to show $$ \begin{align*} g(x) = ((1-λ)x + λy)^p - (1-λ)x^p - λy^p. \end{align*} $$ is non-positive for $x>0$.

Compute $$ \begin{align*} g'(x) ={}& p(1-λ)((1-λ)x + λy)^{p-1} - p(1-λ)x^{p-1} \\ ={}& p(1-λ)\left(((1-λ)x + λy)^{p-1} - x^{p-1}\right). \end{align*} $$ If $x<y$, then $(1-λ)x + λy > x$, so $g'(x) \geq 0$. Similarly if $x>y$, hen $g'(x) \leq 0$. By the mean value theorem, $g$ achieves a maximum at $x=y$, so $g(x) \leq g(y) = 0$.

$B$${}= \sb{x\in l_p}{\|x\|_p\leq 1}$ is convex

For $x,y\in B$ and $λ\in [0,1]$, we want to show $(1-λ)x + λy\in B$.

The convexity of $x\mapsto x^p$ gives $$ \begin{align*} |(1-λ)x_i + λy_i|^p \leq \bigl|(1-λ)|x_i| + λ |y_i|\bigr|^p \leq (1-λ) |x_i|^p + λ |y_i|^p. \end{align*} $$ Therefore for any $n\in \N$, $$ \begin{align*} \sum_{i=1}^{n} |(1-λ)x_i + λy_i|^p \leq (1-λ) \sum_{i=1}^{n} |x_i|^p + λ \sum_{i=1}^{n} |y|^p. \end{align*} $$ Taking $n\to \infty$ yields $$ \begin{align*} \|(1-λ)x + λy\|_p \leq (1-λ) \underbrace{\|x\|_p}_{\leq 1} + λ \underbrace{\|y\|_p}_{\leq 1} \leq 1 \end{align*} $$ so $(1-λ)x + λy\in B$.

$\|x + y\|_p \leq \|x\|_p + \|y\|_p$

If either $x,y,x+y$ is zero, then the inequality is clear.

Assume not. Then using convexity of $B$, $$ \begin{align*} \frac{x + y}{\|x\|_p + \|y\|_p} = \frac{\|x\|_p}{\|x\|_p + \|y\|_p} \underbrace{\frac{x}{\|x\|_p}}_{\in B} + \frac{\|y\|_p}{\|x\|_p + \|y\|_p} \underbrace{\frac{y}{\|y\|_p}}_{\in B} \in B \end{align*} $$ and hence $\|x + y\|_p \leq \|x\|_p + \|y\|_p$.
