Definition (nowhere dense set) open_in_new

Let $X$ be a topological space.

A subset $A\subseteq X$ is said to be nowhere dense if equivalently

  1. $\op{int} \overline{A} = \emptyset$;

  2. for any non-empty open set $U\subseteq X$, we have $U \not\subseteq \overline{U \cap A}$.

Definition (meagre, first category, second category) open_in_new

Let $X$ be a topological space.

A subset $A\subseteq X$ is said to be meagre in $X$ or is of first category in $X$ if $A = \bigcup_{n\in \N} A_n$ where $A_n$ is nowhere dense for all $n\in \N$.

Say $A$ is of second category in $X$ if $A$ is not of first category of $X$.

Theorem (Baire category) open_in_new

Let $X$ be a metric space.

If $X$ is complete, then equivalently

  1. if $(U_n)_{n\in \N}$ is a countable family of open dense subsets of $X$, then the intersection $\bigcap_{n} U_n$ is dense (in particular non-empty);

  2. if $(A_n)_{n\in \N}$ is a countable family of nowhere dense subsets of $X$, then the union $\bigcup_{n} A_n$ has empty interior (in particular cannot be $X$ if $X$ is non-empty).

Proof

Theorem (principle of uniform boundedness) open_in_new

Let $X,Y$ be normed spaces, and $\mathcal{T}\subseteq{}$$\mathcal{B}(X,Y)$.

Assume $X$ is complete. If $\mathcal{T}$ is pointwise bounded (i.e. for all $x\in X$, $\sup_{T\in \mathcal{T}} \|Tx\| < \infty$), then $\mathcal{T}$ is uniformly bounded (i.e. $\sup_{T\in \mathcal{T}} \|T\| < \infty$).

Proof

Corollary (pointwise limit of bounded linear maps) open_in_new

Let $X,Y$ be a normed space, and $(T_n)_{n\in \N}$ is a sequence in $\mathcal{B}(X,Y)$.

If $X$ is a Banach space and there is a map $T: X\to Y$ such that $T_n x \to Tx$ for all $x\in X$, then $\sup_{n\in \N} \|T_n\| < \infty$, $T\in \mathcal{B}(X,Y)$ and $\|T\| \leq \liminf_{n\to \infty} \|T_n\|$.

Proof

Lemma (open mapping lemma) open_in_new

Let $X,Y$ be normed spaces and $T\in{}$$\mathcal{B}(X,Y)$.

If $X$ is Banach and $T(MB_X)$ is $δ$-dense in $B_Y$ for some $M>0$, $0<δ<1$ (i.e. for all $y\in B_Y$, there exists $x\in B_X$ such that $\|T(Mx) - y\| \leq δ$), then $T(\frac{M}{1-δ} B_X)\supseteq B_Y$.

Proof

Theorem (open mapping theorem for bounded linear maps) open_in_new

Let $X,Y$ be Banach spaces.

If $T\in{}$$\mathcal{B}(X,Y)$ is surjective, then $T$ is an open map.

Equivalently, if $Tx = y$ has a solution for $x\in X$ for all $y\in Y$, then there exists $M>0$ such that $T(MB_X) \supseteq B_Y$, i.e. $Tx = y$ has a solution for $x\in X$ with $\|x\| \leq M\|y\|$ for all $y\in Y$.

Proof

Theorem (inversion theorem) open_in_new

Let $X,Y$ be Banach spaces. If $T: X\to Y$ is a continuous linear bijection, then $T\inv$ is also continuous, so $T$ is an isomorphism.

Proof

  • Given two complete norms $\|\cdot\|, \|\cdot\|'$ on $X$, applying this theorem to $\id: (X, \|\cdot\|)\to (X, \|\cdot\|')$ shows that if there is some $b>0$ such that $\|x\|' \leq b\|x\|$ for all $x\in X$, then $\|\cdot\|$ and $\|\cdot\|'$ are equivalent.

Theorem (closed graph theorem) open_in_new

Let $X,Y$ be Banach space and $T: X\to Y$ be a linear map.

If the graph $Γ(T) := \sb{(x,y)\in X\oplus Y}{y = f(x)}$ is a closed subspace of $X \oplus Y$, then $T$ is continuous.

Equivalently, suppose if $(x_n)_{n\in \N}$ is a sequence in $X$ such that $x_n \to 0$ and $Tx_n \to y$ as $n\to \infty$, then $y = 0$. Then $T$ is continuous.

Proof
