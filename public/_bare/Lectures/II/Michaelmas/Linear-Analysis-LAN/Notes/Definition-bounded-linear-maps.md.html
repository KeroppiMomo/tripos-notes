Let $X, Y$ be normed spaces, and $T: X\to Y$ be a linear map.

$T$ is said to be bounded if there exists $C\geq 0$ such that $$\|Tx\| \leq C \|x\| \qquad \text{for all }x\in X.$$

Its operator norm is $$ \begin{align*} \|T\| = \sup \sb{\|Tx\|}{x\in B_X}. \end{align*} $$

Write $\mathcal{B}(X,Y)$ for the set of bounded linear maps $X\to Y$.

  • $(\mathcal{B}(X,Y), \|\cdot\|)$ is a normed space.

  • If $X \neq \{0\}$, then $(\mathcal{B}(X), \|\cdot\|)$ is a (non-commutative) unital normed algebra with multiplication being composition.
