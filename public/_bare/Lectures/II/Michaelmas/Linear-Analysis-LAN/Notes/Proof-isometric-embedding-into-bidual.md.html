Fix $x\in X$. Clearly $\hat x$ is linear. It is bounded since $|\hat x(f)| = |f(x)| \leq \|f\|\, \|x\|$ so $\hat x\in X^{\ast \ast}$.

$\hat{\ }$ is linear because $\widehat{λx + μy}(f) = f(λx + μy) = λ f(x) + μ f(y) = λ\hat x(f) + μ\hat y(f) = (λ \hat x + μ \hat y)(f)$ for all $f\in X^\ast$. It is bounded as $\|\hat x\| \leq \|x\|$.

To show $\hat{\ }$ is isometric, for each $x\in X$, find its norming functional, i.e. $f\in X^\ast$ such that $f(x) = \|x\|$ and $\|f\| = 1$. Then $\hat x(f) = \|x\|$ and thus $\|\hat x\| \geq \|x\|$. This shows $\|\hat x\| = \|x\|$.
