Open mapping theorem says $T$ is open, so for any open set $U\subseteq X$, $(T\inv)\inv(U) = T(U)$ is open. Hence $T\inv$ is continuous.

Alternatively, open mapping theorem says there exists $M>0$ such that for all $y\in Y$, there exists $x\in X$ such that $\|x\|\leq M\|y\|$ and $Tx = y$. But $x = T\inv y$, so $\|T\inv\| \leq M$.
