Let $X,Y$ be normed spaces.

  • An isomorphism is a bijective linear map $T: X\to Y$ such that $T$ and $T\inv$ are bounded.

    Equivalently, $T$ is a surjective linear map satisfying that $$ \begin{align*} a\|x\|\leq \|Tx\|\leq b\|x\| \qquad \text{for all }x\in X \end{align*} $$ for some $a,b>0$.

    If such $T$ exists, we say $X,Y$ are isomorphic, and we write $X\sim Y$.

  • An isometric isomorphism is a linear bijection $T: X\to Y$ such that for every $x\in X$, $\|Tx\| = \|x\|$ (so $a=b=1$).

    If such $T$ exists, then say that $X,Y$ are isometrically isomorphic and write $X\cong Y$.

  • An isomorphic embedding $X\to Y$ is a linear map $T: X\to Y$ such that $T: X\to TX = \im T$ is an isomorphism.

    If such $T$ exists, we say $X$ (isomorphically) embeds into $Y$ and write $X\hookrightarrow Y$.

If $X\sim Y$, then $X$ is complete iff $Y$ is complete.
