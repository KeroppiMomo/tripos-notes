To show $T$ is well-defined, we need to show $Tf$ is continuous. Since $K$ is continuous on the compact set $[0,1]\times [0,1]$, $K$ is uniformly continuous, so for all $ε>0$, there exists $δ>0$ such that $|K(u) - K(v)| < ε$ whenever $\|u - v\|<δ$. Therefore if $|y-z|<δ$, then $$ \begin{align*} |Tf(y) - Tf(z)| ={}& \left|\int_{0}^{1} f(x)(K(y,x) - K(z,x)) \d x\right| \\ \leq{} & \int_{0}^{1} |f(x)| |K(y,x) - K(z,x)| \d x \\ \leq{}& ε \|f\|_\infty \end{align*} $$ so $Tf$ is uniformly continuous, hence continuous.

We need to show $TB_{C[0,1]}$ is relatively compact in $C[0,1]$. Apply Arzelà-Ascoli:

  1. Uniformly bounded: for any $f\in B_{C[0,1]}$, $$ \begin{align*} \|Tf\|_\infty \leq \|f\|_\infty \|K\|_\infty \leq \|K\|_\infty. \end{align*} $$

  2. Equicontinuous: the argument above shows that for all $f\in B_{C[0,1]}$, if $|y - z|<δ$, then $$ \begin{align*} |Tf(y) - Tf(z)| \leq ε\|f\|_\infty \leq ε. \end{align*} $$
