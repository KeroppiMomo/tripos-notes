Definition (compact operator) open_in_new

Let $X,Y$ be Banach spaces.

A linear map $T: X\to Y$ is said to be compact if equivalently

  1. $\overline{T(B_X)}$ is compact;

  2. $T(B_X)$ is totally bounded (by Heine-Borel);

  3. for all bounded sequence $(x_n)_{n\in \N}$ in $X$, $(Tx_n)_{n\in \N}$ has a subsequence that converges in $Y$ (by sequential compactness).

Write $\mathcal{K}(X,Y)$ for the set of all linear compact operators $X\to Y$.

$\mathcal{K}(X,Y)$ is a closed subspace of $\mathcal{B}(X,Y)$. (Proof)

Ideal property: given bounded linear maps $W \xrightarrow{B} X \xrightarrow{T} Y \xrightarrow{A} Z$ between Banach spaces, if $T$ is compact, then so is $ATB$. (Proof)

Examples of compact operators open_in_new

Let $X,Y$ be Banach spaces.

  1. Every finite-rank operator is compact, i.e. for $$ \begin{align*} \mathcal{F} := \sb{T\in \mathcal{B}(X,Y)}{\dim TX<\infty}, \end{align*} $$ we have $\overline{F} \subseteq \mathcal{K}(X,Y)$. (Proof)

  2. If $T\in \mathcal{B}(X,Y)$ is surjective and $\dim Y = \infty$, then $T$ is not compact. (Proof)

  3. For any continuous function $K: [0,1]\times [0,1]\to \R$, $$ \begin{align*} T: C[0,1] &\to C[0,1] \\ f &\mapsto \left(x \mapsto \int_{0}^{1} f(y) K(x,y) \d y\right) \end{align*} $$ is compact. (Proof)
