Finite measures

Consider $$ \begin{align*} \mathcal{G} = \sb{A\in \mathcal{A}}{μ(A) = ν(A)}. \end{align*} $$

$\mathcal{G}$ is a monotone class:

  1. $E \in \mathcal{A}$.

  2. If $A\subseteq B$ with $A,B\in \mathcal{G}$, then $μ(B\setminus A) = μ(B) - μ(A) = ν(B)-ν(A) = ν(B\setminus A)$ because the measures are finite.

  3. If $(A_n)_{n\in \N}$ is an increasing sequence in $\mathcal{G}$, then by continuity, $μ(\bigcup_{n\in \N} A_n) = \lim_{n\to \infty} μ(A_n) = \lim_{n\to \infty} ν(A_n) = ν(\bigcup_{n\in \N} A_n)$.

By assumption $\mathcal{C}\subseteq \mathcal{G}$, which is stable by finite intersection. Thus by the monotone class lemma, $\mathcal{A} = \mathcal{G}$.

Increasing sequence

Define on $\mathcal{A}$ $$ \begin{align*} μ_n(A) = μ(A \cap E_n), \qquad ν_n(A) = ν(A \cap E_n). \end{align*} $$

Since $\mathcal{C}$ is stable by finite intersections, $C \cap E_n \in \mathcal{C}$ for all $C\in \mathcal{C}$, so $μ_n(C) = ν_n(C)$. Also $μ_n(E) = ν_n(E)<\infty$, so the above result shows that $μ_n = ν_n$.

Then apply continuity to get for any $A\in \mathcal{A}$, $$ \begin{align*} μ(A) = μ\biggl(\bigcup_{n\in \N} (A\cap E_n)\biggr) = \lim_{n\to \infty} μ_n(A) = \lim_{n\to \infty} ν_n(A) = ν\biggl(\bigcup_{n\in \N} (A\cap E_n)\biggr) = ν(A). \end{align*} $$
