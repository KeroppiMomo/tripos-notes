If $f$ is measurable, then $f\inv(C) \in \mathcal{A}$ for all $C\in \mathcal{C}$ since $\mathcal{C}\subseteq \mathcal{B}$.

Conversely, define $$ \begin{align*} \mathcal{G} := \sb{B\in \mathcal{B}}{f\inv(B) \in \mathcal{A}} \subseteq \mathcal{B}. \end{align*} $$

$\mathcal{G}$ is a $σ$-algebra:

  1. $f\inv(F) = E\in \mathcal{G}$ so $F\in \mathcal{G}$.

  2. If $B\in \mathcal{G}$, then $f\inv(B^\complement) = f\inv(B)^\complement \in \mathcal{A}$ so $B^\complement \in \mathcal{G}$.

  3. If $(B_n)_{n\in \N}$ is a sequence in $\mathcal{G}$, then $f\inv(\bigcup_{n\in \N} B_n) = \bigcup_{n\in \N} f\inv(B_n) \in \mathcal{A}$ so $\bigcup_{n\in \N} B_n \in \mathcal{G}$.

Moreover by assumption $\mathcal{C} \subseteq \mathcal{G}$, so by minimality $\mathcal{G} = σ(\mathcal{C}) = \mathcal{B}$. Thus $f$ is measurable.
