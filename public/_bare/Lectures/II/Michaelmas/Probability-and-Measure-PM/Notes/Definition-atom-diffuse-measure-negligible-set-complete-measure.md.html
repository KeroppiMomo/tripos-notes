Let $(E, \mathcal{A}, μ)$ be a measure space.

  • A point $x\in E$ is called an atom if $\set{x}\in \mathcal{A}$ and $μ(\set{x}) >0$.

  • $μ$ is called diffuse if it has no atom.

  • A subset $B\subseteq E$ is negligible if there exists some $A\in \mathcal{A}$ with $μ(A) = 0$ such that $B\subseteq A$.

  • Say a property holds almost everywhere, almost surely etc if it holds outside a negligible set.

  • $μ$ is called complete if every negligible set is measurable.
