The key idea is to define, for each $A\in \mathcal{M}(\mathcal{C})$, $$ \begin{align*} \mathcal{M}_A := \sb{B\in \mathcal{M}(\mathcal{C})}{A\cap B\in \mathcal{M}(\mathcal{C})}. \end{align*} $$

$\mathcal{M}_A$ is a monotone class

It's just set theory and definition chasing:

  1. $A\cap E = A \in \mathcal{M}(\mathcal{C})$ so $E\in \mathcal{M}_A$.

  2. If $B\subseteq B'$ and $B,B'\in \mathcal{M}_A$, then $A\cap B \subseteq A \cap B'$ and both belong to $\mathcal{M}(\mathcal{C})$. So $A \cap (B'\setminus B) = (A \cap B') \setminus (A \setminus B)\in \mathcal{M}(\mathcal{C})$, and thus $B'\setminus B\in \mathcal{M}_A$.

  3. Let $(B_n)_{n\in \N}$ be an increasing sequence in $\mathcal{M}_A$. Then $(A \cap B_n)_{n\in \N}$ is an increasing sequence in $\mathcal{M}(\mathcal{C})$, so $A \cap \bigcup_{n} B_n = \bigcup_{n} (A\cap B_n) \in \mathcal{M}(\mathcal{C})$. Therefore $\bigcup_{n} B_n \in \mathcal{M}_A$.

$\mathcal{M}(\mathcal{C})$ is stable by finite interseciton

For any $A \in \mathcal{C}$, since $\mathcal{C}$ is stable by finite intersection, $\mathcal{C}\subseteq \mathcal{M}_A$. But $\mathcal{M}_A\subseteq \mathcal{M}(\mathcal{C})$ and $\mathcal{M}(\mathcal{C})$ is minimal, so $\mathcal{M}_A = \mathcal{M}(\mathcal{C})$. This shows that for all $A\in \mathcal{C}, B\in \mathcal{M}(\mathcal{C})$, we have $A\cap B\in \mathcal{M}(\mathcal{C})$.

This statement then shows that $\mathcal{C}\subseteq \mathcal{M}_A$ for all $A\in \mathcal{M}(\mathcal{C})$. Argue similarly to conclude that for all $A,B\in \mathcal{M}(\mathcal{C})$, we have $A\cap B\in \mathcal{M}(\mathcal{C})$.

Finally since $σ(\mathcal{C})$ is a monotone class, we have $\mathcal{C} \subseteq \mathcal{M}(\mathcal{C}) \subseteq σ(\mathcal{C})$. Invoke this lemma to see that $\mathcal{M}(\mathcal{C})$ is a $σ$-algebra. Thus $\mathcal{M}(\mathcal{C}) = σ(\mathcal{C})$.
