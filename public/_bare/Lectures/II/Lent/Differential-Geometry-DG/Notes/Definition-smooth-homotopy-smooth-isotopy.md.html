Let $f,g: X\to Y$ be smooth maps between manifolds ($X$ cannot have boundary but $Y$ can).

A smooth homotopy $H: X\times [0,1]\to Y$ is a smooth map between manifolds which is a homotopy from $f$ to $g$, i.e. $H(x, 0) = f(x)$ and $H(x,1) = g(x)$ for all $x\in X$. If such $H$ exists, we say $f$ and $g$ are smoothly homotopic.

If $f,g$ are diffeomorphisms, a smooth isotopy $H: X \times [0,1]\to Y$ is a smooth homotopy with $x\mapsto H(x,t)$ is a diffeomorphism for each $t\in [0,1]$. If such $H$ exists, we say $f$ and $g$ are smoothly isotopic.

"Smooth homotopic" and "Smooth isotopic" are equivalence relations.
