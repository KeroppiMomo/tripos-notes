Let $f: X\to Y$ be a smooth map between manifolds.

$x\in X$ is a critical point of $f$ if $\d f_x$${}: T_x X\to T_{f(x)} Y$ is not surjective.

$y\in Y$ is a critical value of $f$ if there exists some critical point $x\in X$ such that $y = f(x)$.

$y\in Y$ is a regular value of $f$ if it is not a critical value.

If $y\not\in f(X)$, then $y$ is a regular value.

If $\dim Y > \dim X$, all points in $Y$ are critical values as $T_x X \to T_{f(x)} Y$ can never be surjective.
