Let $(E, \mathcal{B}, μ)$ be a signed measure space.

$A \in \mathcal{B}$ is a positive set (with respect to $μ$) if $μ(B)\geq 0$ for all measurable $B \subseteq A$.

$A$ is a negative set if $μ(B) \leq 0$ for all measurable $B \subseteq A$.

A countable union of positive sets is positive; ditto for negative sets. (Proof)
