Existence of $f$, $ν_a$, $ν_s$

Using the previous result, there exists $A\in \mathcal{B}$ and $f\in L^1(E, \mathcal{B}, μ)$ such that $μ(E \setminus A) = 0$ and $ν(B) = \int_{B} f \d μ$ for all $B \subseteq A$ measurable.

If $ν \ll μ$, then $ν(E \setminus A) = 0$. Therefore for any $B\in \mathcal{B}$, $$ \begin{align*} ν(B) = ν(B\cap A) + \underbrace{ν(B \setminus A)}_{\leq ν(E \setminus A) = 0} = \int_{B\cap A} f \d μ = \int_{B} f \d μ. \end{align*} $$

$f\inv(\infty)$ is negligible with respect to $μ$ as $\int_{E} f \d μ = ν(E) < \infty$, so by replacing the value of $f$ on $f\inv(\infty)$, we can assume $f\inv(\infty) = \emptyset$.

For a general $ν$, define $$ \begin{align*} ν_a(B) = ν(B \cap A), \quad ν_s(B) = ν(B \setminus A). \end{align*} $$ Clear that $ν = ν_a + ν_s$ as $B = (B\cap A) \sqcup (B \setminus A)$. $ν_a \ll μ$ because $\int_{B\cap A} f \d μ = 0$ if $μ(B \cap A) = μ(B) = 0$. $ν_s \perp μ$ because $ν_s$ is concentrated on $E\setminus A$ and $μ(E \setminus A) = 0$.

Uniqueness of $f$

Suppose $f,g$ are two Radon-Nikodym derivatives. Let $$ \begin{align*} A_ε = \sb{x\in E}{f(x) - g(x) > ε}. \end{align*} $$ Then by definition $$ \begin{align*} 0 = ν(A_ε) - ν(A_ε) = \int_{A_ε} f - g \d μ \geq ε \, μ(A_ε). \end{align*} $$ so $μ(A_ε) = 0$. Similarly $μ(B_ε) = 0$ for $B_ε = \sb{x\in E}{g(x) - f(x) > ε}$, so $μ(\sb{x\in E}{f(x) \neq g(x)}) = μ(\bigcup_{n\in \Z_{>0}} A_ε \cup \bigcup_{n\in \Z_{>0}} B_ε) = 0$.

Uniqueness of $ν_a, ν_s$

Suppose $ν = ν_a + ν_s$ with $ν_a \ll μ$ and $ν_a \perp μ$, and take any $B\in \mathcal{B}$.

If $μ(B)=0$, then $ν_a(B) = 0$, so $ν_s(B) = ν(B)$.

If $μ(B)>0$, then $ν_s(B) = 0$, so $ν_a(B) = ν(B)$.
