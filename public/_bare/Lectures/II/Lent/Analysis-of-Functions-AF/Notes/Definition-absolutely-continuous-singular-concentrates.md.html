Let $μ, ν$ be positive measures on $(E, \mathcal{B})$.

  • Say $μ$ concentrates on a set $A \subseteq E$ if $μ(E \setminus A) = 0$.

  • Say $ν$ is absolutely continuous with respect to $μ$ (denoted $ν \ll μ$) if whenever $μ(A) = 0$ we have $ν(A) = 0$ for all $A\in \mathcal{B}$.

  • Say $ν$ is singular with respect to $μ$ (denoted $ν \perp μ$) if there exists $A, B\in \mathcal{B}$ such that $E = A \sqcup B$, $μ(A) = 0$ and $ν(B) = 0$.
