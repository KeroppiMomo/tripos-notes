From a finite set which generate $L/K$, extract a maximally algebraically independent set $x_1, \ldots, x_n$. Then $L/K(x_1, \ldots, x_n)$ is finite, so $x_1, \ldots, x_n$ is a transcendence basis.

We will show that two transcendence bases $\set{x_1, \ldots, x_n}$ and $\set{y_1, \ldots, y_m}$ of $L/K$ have the same length. WLOG suppose $m\geq n$. Let $K_0 := K(x_1, \ldots, x_n)$.

  • $y_1\in L$ is algebraic over $K_0$, so there exists a minimal polynomial $f_1$ over $K$ such that $f_1(x_1, \ldots, x_n, y_1) = 0$. $f_1$ involves some $x_i$, WLOG say $x_1$, so $\{y_1, x_2, \ldots, x_n\}$ is algebraically independent. As $x_1$ is algebraic over $K_1 := K(y_1, x_2, \ldots, x_n)$ (because of $f_1$), $L/K_0(y_1)/K_1$ is a tower of finite extensions, so $L/K_1$ is finite.

  • By induction assume $\{y_1, \ldots, y_{i-1}, x_{i}, \ldots, x_n\}$ is a transcendence basis for $L/K$. $y_{i}$ is algebraic over $K_{i-1} := K(y_1, \ldots, y_{i-1}, x_{i}, \ldots, x_n)$, so it has a minimal polynomial $f_i$. $f_i$ must involve some $x_j$, because otherwise $f_i(y_1, \ldots, y_{i-1}, x_{i}, \ldots, x_n, y_i)=0$ is a non-trivial algebraic relation involving only the $y_j$'s, which contradicts algebraic independence of $\{y_1, \ldots, y_m\}$. WLOG say $f_i$ involves $x_i$, so $\set{y_1, \ldots, y_{i-1}, y_i, x_{i+1}, \ldots, x_n}$ is a transcendence basis.

In the end we find a transcendence basis $\set{y_1, \ldots, y_n}$, which by algebraic independence implies $n=m$.
