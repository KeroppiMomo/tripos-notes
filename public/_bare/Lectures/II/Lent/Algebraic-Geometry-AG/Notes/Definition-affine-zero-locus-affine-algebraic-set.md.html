Let $S \subseteq k[x_1, \ldots, x_n]$ a subset of polynomials in $n$ variables.

The zero locus or vanishing set of $S$ in $\mathbb A^n$ is $$ \begin{align*} Z(S) = \sb{p\in \mathbb{A}^n}{f(p) = 0 \; \forall f\in S} \end{align*} $$ a subset of the affine $n$-space $\mathbb{A}^n$.

An affine algebraic set or affine variety is any set of the form $Z(S)$.

If $f\in k[x_1, \ldots, x_n]$ is non-constant, $Z(f)$ is called a hypersurface. If $f$ is linear, $Z(f)$ is called a hyperplane.

If $I\lhd k[x_1, \ldots, x_n]$ is the ideal generated by $S$, then $Z(S) = Z(I)$.

For any $S \subseteq k[x_1, \ldots, x_n]$, there exists $f_1, \ldots, f_r\in S$ such that $Z(S) = Z(f_1, \ldots, f_r)$. (Proof)

$\emptyset = Z(1)$ and $\mathbb{A}^n = Z(0)$ are affine algebraic sets.

$Z$ is inclusion-reversing: if $S\subseteq T \subseteq k[x_1, \ldots, x_n]$, then $Z(T) \subseteq Z(S)$.

$\bigcap_{i} Z(S_i) = Z(\bigcup_{i} S_i)$ for any collection $\set{S_i\subseteq k[x_1, \ldots, x_n]}_{i}$.

$Z(S) \cup Z(T) = Z(S\cdot T)$ for $S, T\subseteq k[x_1, \ldots, x_n]$, where $S\cdot T = \sb{f\cdot g}{f\in S, g\in T}$. (Proof)
