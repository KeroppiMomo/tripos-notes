Let $X\subseteq \mathbb{A}^n$, $Y\subseteq \mathbb{A}^m$ be affine algebraic sets.

A morphism is a function $f: X\to Y$ of the form $f = (f_1, \ldots, f_m)$ where $f_1, \ldots, f_m\in{}$$A(X)$.

Write $\mathrm{Mor}(X,Y)$ for the set of morphisms $X\to Y$.

An isomorphism is a morphism with a two-sided inverse which is also a morphism.

Composition of morphisms is a morphism.

A morphism is a continuous function with respect to the Zariski topology: if $Z = Z(g_1, \ldots, g_r) \subseteq Y$, then $$ \begin{align*} f\inv(Z) = Z(f^\ast g_1, \ldots, f^\ast g_r) \end{align*} $$ where $f^\ast$ is the pullback.

A bijective morphism is not necessarily an isomorphism. (Example)
