For a non-zero rational function $f$, define a rational map $ϕ = (1: f) : X \dashrightarrow \mathbb{P}^1$, which extends to a morphism $X\to \mathbb{P}^1$ of curves.

Note $$ \begin{align*} ν_P(f) > 0 &\iff f\in \mathfrak{m}_P \iff ϕ(P) = (1:0), \\ ν_P(f) < 0 &\iff \frac{1}{f}\in \mathfrak{m}_P \iff ϕ(P) = (0:1), \end{align*} $$ so $\sb{f\in P}{ν_P(f)\neq 0} = ϕ\inv(\set{(1:0), (0:1)})$ is finite.

For $\mathbb{P}^1$, $x_1/x_0$ is a local parameter at $(1:0)$ and $x_0/x_1$ is a local parameter at $(0:1)$. Therefore $$ \begin{align*} \sum_{P\in V} ν_P(f) ={}& \sum_{P\in ϕ\inv((1:0))} ν_P(f) - \sum_{P\in ϕ\inv((0:1))} ν_P(1/f) \\ ={}& \sum_{P\in ϕ\inv((1:0))} e_P - \sum_{P\in ϕ\inv((0:1))} e_P \\ ={}& \deg ϕ - \deg ϕ = 0. \end{align*} $$
