$X$ reducible $\implies$ $C(X)$ reducible

If $X = V_1 \cup V_2$ for proper closed sets in $\mathbb{P}^n$, then $C(X) = C(V_1) \cup C(V_2)$ where $C(V_1)$ and $C(V_2)$ are proper closed sets in $\mathbb{A}^{n+1}$.

$C(X)$ reducible $\implies$ $X$ reducible

Suppose $C(X) = V_1 \cup V_2$ for proper closed sets in $\mathbb{A}^{n+1}$. Let for $i=1,2$ $$ \begin{align*} J_i = \sb{f(λx_0, \ldots, λx_n)}{f\in I(V_i), λ\in k^\times}, \quad U_i = Z_a(J_i) \subseteq \mathbb{A}^{n+1}. \end{align*} $$ $U_i \subseteq V_i$ since $J_i \supseteq I(V_i)$, so $U_i$ is proper closed.

For any line $L$ (image of an embedding $\mathbb{A}^1 \hookrightarrow \mathbb{A}^{n+1}$) through the origin, $L \cap V_i$ is an algebraic set in $\mathbb{A}^1$, so is either $L$ or a finite set of points. If $C(X)$ contains $L$, then $L \cap V_i = L$ for some $i=1,2$, in which case $L \subseteq U_i$.

Therefore $C(X) = U_1 \cup U_2$. Then $X = q(C(X) \setminus \set{0}) = q(U_1 \setminus \set{0}) \cup q(U_2 \setminus \set{0})$ is a decomposition of $X\subseteq \mathbb{P}^n$.
