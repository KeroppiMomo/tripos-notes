The Zariski topology on $\mathbb{A}^n$ is the set of the complements of all affine algebraic sets.

For a non-constant $f\in k[x_1, \ldots, x_n]$, the distinguished open set of $f$ is $$ \begin{align*} D(f) = \mathbb{A}^n \setminus Z(f). \end{align*} $$

This is a topology due to these remarks.

$\sb{D(f)}{f\in k[x_1, \ldots, x_n] \text{ non-constant}}$ is a base for the Zariski topology.
