It is clear that $σ_{n,m}(\mathbb{P}^n \times \mathbb{P}^m) \subseteq Σ_{n,m}$.

Given some $a=(a_{00}: \ldots: a_{0m}: \ldots: a_{n0}, \ldots, a_{nm})\in Σ_{n,m}$, there exists some $i,j$ such that $a_{ij}\neq 0$, WLOG $a_{ij} = 1$. Take $x = (a_{0j} : \ldots : a_{nj})\in \mathbb{P}^n$, $y = (a_{i0} : \ldots : a_{im})\in \mathbb{P}^m$. Then $$ \begin{align*} a_{pq} = a_{pq} a_{ij} = a_{pj} a_{iq} = x_p y_q \end{align*} $$ so $a = σ_{n,m}(x,y)$. This describes an inverse of $σ_{n,m}$, so $σ_{n,m}$ is bijective.

To see $Σ_{n,m}$ is irreducible, note the $k$-algebra homomorphism between integral domains $$ \begin{align*} k[z_{00}, \ldots, z_{0m}, \ldots, z_{n0}, \ldots, z_{nm}] &\to k[x_0, \ldots, x_m, y_0, \ldots, y_n] \\ z_{ij} &\mapsto x_iy_j \end{align*} $$ has kernel $(z_{ij} z_{pq} - z_{iq} z_{pj}\mid 0\leq i,p\leq n, \; 0\leq j,q\leq m)$, which has to be prime.
