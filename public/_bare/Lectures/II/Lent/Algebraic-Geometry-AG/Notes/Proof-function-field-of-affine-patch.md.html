Check this is well-defined:

  • We claim the dehomogenisation $g_\ast(x_1, \ldots, x_n) = g(1, x_1, \ldots, x_n)\not\in I(X_0)$ if $g\not\in I(X)$. We showed $X$ is the projective closure of $X_0$, so $I(X_0)^\ast\subseteq I(X)$. Therefore if $g_\ast\in I(X_0)$, then $g = x_0^r (g_\ast)^\ast\in I(X)$.

  • If $f/g = f'/g'\in k(X)$, then $fg' - gf'\in I(X)$. Dehomogenising, $f_\ast g'_\ast - g_\ast f'_\ast \in I(X_0)$, so $f_\ast/g_\ast = f'_\ast/g'_\ast\in k(X_0)$.

$ϕ$ is clearly a ring homomorphism.

For surjectivity, suppose $F/G\in k(X_0)$ where $F$ has degree $d$ and $G\not\in I(X_0)$ has degree $e$. Note $G^\ast\not\in I(X)$ (since $G = (G^\ast)_\ast\not\in I(X_0)$) so $x_0^{e-d} F^\ast/G^\ast$ is an element of $k(X)$. Dehomogenising this gives $F/G$ as required.

The statement on local rings is clear: if $g(P)\neq 0$, then $g_\ast(P)\neq 0$.
