If $D\in \op{Div}^0(\mathbb{P}^1)$, $D = \sum n_P P$, then $n_\infty = -\sum_{P\in \mathbb{A}^1} n_P$ as $D \in \op{Div}^0(\mathbb{P}^1)$. So it suffices to find $f\in k(\mathbb{P}^1)^\times$ with $ν_P(f) = n_P$ for all $P\in \mathbb{A}^1$.

Let $t:= x_1/x_0$ be the affine coordinate on $\mathbb{A}^1\subseteq \mathbb{P}^1$, so for all $P\in \mathbb{A}^1$, $t-P$ is a local parameter at $P$. Then $$ \begin{align*} f := \prod_{P\in \mathbb{A}^1} (t-P)^{n_P} \end{align*} $$ has $ν_P(f) = n_P$, and $\op{deg}(\op{div}(f)) = \deg(D) = 0$ implies $ν_\infty(f) = n_\infty$, so $\op{div}(f) = D$ as needed.

Conversely if $\op{Cl}^0(V)$ is trivial, then for all $P,Q\in V$, $P-Q$ is a degree 0 divisor, so there exists $f\in k(V)^\ast$ such that $\op{div}(f) = P-Q$. Then $f$ has a unique simple pole at $Q$, and hence $f$ is a isomorphism $V \to \mathbb{P}^1$.
