Any degree 1 divisor class meets a point

By Riemann-Roch, any degree 1 divisor $D$ has $l(D) = 1$, so $L(D)$ is spanned by some $f\in k(E)$. Therefore the unique effective divisor linearly equivalent to $D$ is $\op{div}(f) + D$. It is effective and of degree 1, so is a point.

$E\to \op{Cl}^0(E)$ is bijective

For injectivity, if $P-P_0 \sim Q - P_0$, then $P\sim Q$. As there is only one point in the divisor class $[P]$, we must have $P = Q$.

For surjectivity, for any degree 0 divisor $D$, as $D+P_0$ has degree 1, it is linearly equivalent to a point $P$. Therefore $P-P_0 \sim D$.

Group structure

Calling $β: E\to \op{Cl}^0(E)$, the induced group structure is $$ \begin{align*} P + Q :={}& β\inv(β(P) + β(Q)) \\ ={}& β\inv([P-P_0] + [Q-P_0]) \\ ={}& β\inv([P+Q-2P_0]) \end{align*} $$ which is the unique point in the divisor class $[P+Q-P_0]$.
