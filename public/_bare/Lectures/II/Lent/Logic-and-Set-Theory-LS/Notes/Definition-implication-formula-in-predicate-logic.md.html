In predicate logic, an implication formula is a formula which does not contain the symbols $\wedge$, $\vee$, $\neg$, $\top$, $\exists$.

Write $\mathsf{IFml}^a$ for the set of implicative $a$-formulas.

As before define recursively the surjection $$ \begin{align*} s: \mathrm{Fml} &\to \mathrm{IFml} \\ \exists x ϕ &\mapsto \forall x(s(ϕ) \Rightarrow \bot)\Rightarrow \bot. \end{align*} $$
