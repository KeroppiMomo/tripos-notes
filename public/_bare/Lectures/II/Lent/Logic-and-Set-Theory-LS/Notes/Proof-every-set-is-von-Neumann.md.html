Apply $\in$-induction. We need to show for all $x$, if $y$ is von Neumann for all $y\in x$, then $x$ is von Neumann.

For all such $y$, $ρ(y)$ is defined, so by replacement, the set $\sb{ρ(y)}{y\in x}$ exists. Then consider $$ \begin{align*} α := \bigcup \sb{ρ(y)}{y\in x}, \end{align*} $$ a transitive set of ordinals so an ordinal. Since $ρ(y)\leq α$, we have $y\in V_{α+1}$. Therefore $x\in \mathcal{P}(V_{α+1}) = V_{α+2}$.
