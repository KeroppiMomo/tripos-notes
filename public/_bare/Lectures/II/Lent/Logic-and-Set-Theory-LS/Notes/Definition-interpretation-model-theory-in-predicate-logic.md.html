Let $a$ be a signature, $V$ be an infinite set of variables, and $\mathbf{X}$ be an $a$-structure.

An $\mathbf{X}$-interpretation or $\mathbf{X}$-assignment is any function $\mathfrak{I}: V\to X$. Extent to $\mathrm{Term}^a$ by recursion: $$ \begin{align*} \mathfrak{I}(s_i t_0 \ldots t_{n-1}) := s_i^\mathbf{X}(\mathfrak{I}(t_0), \ldots, \mathfrak{I}(t_{n-1})) \end{align*} $$ where $s_i^\mathbf{X}$ is the operation in $\mathbf{X}$ indexed $i$.

Given an $\mathbf{X}$-interpretation $\mathfrak{I}$, define for $x\in X$, $v\in V$ another $\mathbf{X}$-interpretation $$ \begin{align*} \mathfrak{I}\tfrac{x}{v}(w) = \begin{cases} \mathfrak{I}(w), &\text{if }w\neq v, \\ x, &\text{if }w = v. \end{cases} \end{align*} $$

Now interpret $a$-formulas in $\mathbf{X}$ using $\mathfrak{I}$ according to Tarski's recursive definition of truth:

  • $\mathbf{X}, \mathfrak{I} \vDash \top$ always holds.

  • $\mathbf{X}, \mathfrak{I} \vDash \top$ never holds.

  • $\mathbf{X}, \mathfrak{I} \vDash t = t'$ iff $\mathfrak{I}(t) = \mathfrak{I}(t')$.

  • $\mathbf{X}, \mathfrak{I} \vDash r_j t_0 \ldots t_{n-1}$ iff $a(j) = n$ and $(\mathfrak{I}(t_0), \ldots, \mathfrak{I}(t_{n-1})) \in r_j^\mathbf{X}$, where $r_j^\mathbf{X}$ is the relation in $\mathbf{X}$ indexed $j$.

  • $\mathbf{X}, \mathfrak{I}\vDash (ϕ \wedge ψ)$ iff $\mathbf{X}, \mathfrak{I}\vDash ϕ$ and $\mathbf{X}, \mathfrak{J} \vDash ψ$, etc.

  • $\mathbf{X}, \mathfrak{I}\vDash \exists v ϕ$ iff there exists some $x\in X$ such that $\mathbf{X}, \mathfrak{I}\tfrac{x}{v} \vDash ϕ$.

  • $\mathbf{X}, \mathfrak{I}\vDash \forall v ϕ$ iff for all $x\in X$, there holds $\mathbf{X}, \mathfrak{I}\tfrac{x}{v} \vDash ϕ$.

If $ϕ$ is an $a$-sentence, write $\mathbf{X}\vDash ϕ$ if for all (equivalently some) $\mathbf{X}$-interpretation $\mathfrak{I}$, we have $\mathbf{X}, \mathfrak{I}\vDash ϕ$. In this case we say $ϕ$ is true in $\mathbf{X}$; otherwise say $ϕ$ is false in $\mathbf{X}$.

Let $T\subseteq \mathrm{Fml}^a$. Write $\mathbf{X}\vDash T$ if $\mathbf{X}\vDash ϕ$ for all $ϕ\in T$. In this case, say $\mathbf{X}$ is a model of $T$. Say $T$ is satisfiable if $T$ has a model.

Let $T,S$ be sets of $a$-sentences. Write $T\vDash S$ for whenever $\mathbf{X}\vDash T$, we have $\mathbf{X} \vDash S$.

The theory $\op{Th}(\mathbf{X})$ of $\mathbf{X}$ is the set of $a$-sentences which are true in $\mathbf{X}$. Call two $a$-structures $\mathbf{X}$ and $\mathbf{Y}$ elementarily equivalent if $\op{Th}(\mathbf{X}) = \op{Th}(\mathbf{Y})$.

Note the duality of $\forall$ and $\exists$: $\mathbf{X}, \mathfrak{I} \vDash \exists v\ \neg ϕ$ iff $\mathbf{X}, \mathfrak{I} \vDash \neg \forall v\ ϕ$.
