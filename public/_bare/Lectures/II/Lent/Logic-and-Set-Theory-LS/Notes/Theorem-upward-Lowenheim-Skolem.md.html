Let $T$ be a set of $a$-sentences.

If $T$ has a model of cardinality $\geq n$ for all $n\in \N$ (such as having an infinite model), then $T$ has a model of cardinality $\geq |K|$ for all set $K$.

Proof

Therefore the class of finite $a$-structures is not axiomatisable: there is an $a$-structure of arbitrary finite cardinality with all operations being constant and all relations being empty.

Such $T$ is not categorical.
