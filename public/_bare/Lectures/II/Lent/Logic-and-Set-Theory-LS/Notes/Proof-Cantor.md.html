It suffices to show there is no surjection $f: X\twoheadrightarrow \mathcal{P}(X)$.

For any function $f: X\to \mathcal{P}(X)$, define the set $$ \begin{align*} A := \sb{x\in X}{x\not\in f(x)}. \end{align*} $$ If $y\in X$ is such that $f(y)=A$, then $$ \begin{align*} y\in A \iff y\not\in f(x) = A \end{align*} $$ which is a contradiction, so $A\not\in \op{ran}(f)$.
