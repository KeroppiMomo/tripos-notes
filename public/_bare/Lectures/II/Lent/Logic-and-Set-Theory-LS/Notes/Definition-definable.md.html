Let $\mathbb{X}$ be an $a$-structure.

An operation $f: X^n\to X$ is definable over $\mathbf{X}$ if there is a formula $ϕ$ with $n+1$ free variables such that $f(\v x) = x$ iff $\mathbf{X}$${}\vDash{}$$ϕ(\v x, x)$.

A relation $R\subseteq X^n$ is definable over $\mathbf{X}$ if there is a formula $ϕ$ with $n$ free variables such that $\v x\in R$ iff $\mathbf{X}\vDash ϕ(\v x)$.
