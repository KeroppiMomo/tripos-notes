A signature is any function $a: I \sqcup J \to \N$ where $I$ and $J$ are disjoint (index) sets.

An $a$-structure is a tuple $\mathbf{X} = (X, S_0, S_1)$ where

  1. $X$ is a set called the underlying set,

  2. $S_0 = \sb{f_i}{i\in I}$ is a family of operations $f_i: X^{a(i)} \to X$, and

  3. $S_1 = \sb{R_j}{j\in J}$ is a family of relations $R_j \subseteq X^{a(j)}$.

If $\mathbf{X} = (X, \sb{f_i}{i\in I}, \sb{R_j}{j\in J})$ and $\mathbf{Y}= (Y, \sb{g_i}{i\in I}, \sb{Q_j}{j\in J})$ are $a$-structures, say $\mathbf{X}$ is a substructure of $\mathbf{Y}$ if

  1. $X \subseteq Y$;

  2. $f_i = g_i|_{X^{a(i)}}$ for all $i\in I$; and

  3. $R_j = Q_j \cap X^{a(j)}$ for all $j\in J$.

Given $I_\ast \subseteq I$ and $J_\ast\subseteq J$, define a signature $a_\ast = a|_{I_\ast \cup J_\ast}$. The $a_\ast$-reduct of $\mathbf{X}$ is $$ \begin{align*} \mathbf{X}_\ast = (X, \sb{f_i}{i\in I_\ast}, \sb{R_j}{j\in J_\ast}). \end{align*} $$
