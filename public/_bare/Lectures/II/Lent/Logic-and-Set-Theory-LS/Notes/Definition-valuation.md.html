A function $v: \mathrm{Fml}\to 2$ is a valuation if it is a homomorphism from $\mathbf{Fml}$ to $\mathbf{2}$.

$v(\top) = 1$ and $v(\bot) = 0$.

For any function $f: P \to 2$, there exists a unique extension to a valuation by induction.

Coincidence lemma: let $\op{occ}(ϕ)\subseteq P$ be the (finite) set of propositional letters that occur in $ϕ$. If $v,w$ are valuations such that $v|_{\op{occ}(ϕ)} = w|_{\op{occ}(ϕ)}$, then $v(ϕ) = w(ϕ)$.
