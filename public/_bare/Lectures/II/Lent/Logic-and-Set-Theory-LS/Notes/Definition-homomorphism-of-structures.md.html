Let $\mathbf{X} = (X, \sb{f_i}{i\in I}, \sb{R_j}{j\in J})$ and $\mathbf{Y} = (Y, \sb{g_i}{i\in I}, \sb{Q_j}{j\in J})$ be $a$-structures.

A function $h: X\to Y$ is a homomorphism from $\mathbf{X}$ to $\mathbf{Y}$ if

  1. $h(f_i(x)) = g_i(h(x))$ for all $x\in X^{a(i)}$, $i\in I$; and

  2. $x\in R_j$ iff $h(x) \in Q_j$ for all $x\in X^{a(j)}$, $j\in J$.
