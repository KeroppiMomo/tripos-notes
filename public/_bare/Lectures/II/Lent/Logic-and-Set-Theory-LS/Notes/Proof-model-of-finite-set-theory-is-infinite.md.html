We work in a model $\mathbf{X}$ of $\mathsf{FST}$.

By $\mathsf{Emp}$, there is some $\emptyset\in X$ such that no $z\in X$ satisfies $z\in \emptyset$. Define $$ \begin{align*} x_0 := \emptyset, \quad x_{n+1} = \set{x_n} \end{align*} $$ using $\mathsf{Pair}$.

We claim $n\mapsto x_n$ is an injection $\N\hookrightarrow X$, i.e. if $i<j$, then $x_i \neq x_j$. Suppose not. Then by induction find the minimal $j$ such that there is $i<j$ with $x_i= x_j$. As $j\neq 0$, $j = l + 1$ for some $l\in \N$, so $x_i = x_j = \set{x_l}$. Since $x_l \in x_i$, we have $i\neq 0$, so $i = k+1$ for some $k\in \N$. Then $\set{x_k} = x_i = x_j = \set{x_l}$, so $x_k = x_l$. But this contradicts minimality of $j$.
