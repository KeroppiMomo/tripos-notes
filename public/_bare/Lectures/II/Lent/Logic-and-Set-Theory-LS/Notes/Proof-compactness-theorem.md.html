$T$ satisfiable $\implies$ any finite subset satisfiable

Any model of $T$ is a model of any of its subsets.

$T$ not satisfiable $\implies$ there is an unsatisfiable finite subset

If $T$ is not satisfiable, then $T$ is not consistent, so $T \vdash \bot$. (Alternatively as $T$ has no model, it is vacuously true that $T \vDash \bot$, so using completeness $T \vdash \bot$.) By finiteness, there is a finite subset $T_0\subseteq T$ such that $T_0 \vdash \bot$, so by soundness, $T_0$ is not satisfiable.
