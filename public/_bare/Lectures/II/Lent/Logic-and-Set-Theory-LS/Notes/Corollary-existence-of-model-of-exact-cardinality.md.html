Work in $\mathsf{ZFC}$. Let $T$ be a set of $a$-sentences.

If $T$ has a model of cardinality $\geq n$ for all $n\in \N$ (such as having an infinite model), then $T$ has a model of cardinality exactly $κ$ for all $κ \geq |\mathrm{Fml}^a|$.

Proof

Therefore if $\mathrm{Fml}^a$ is countable, then $T$ has a countable model. > Hence $\mathrm{Th}(\R,+,\cdot,0,1,<)$ and $\mathsf{ZFC}$ has a countable model.
