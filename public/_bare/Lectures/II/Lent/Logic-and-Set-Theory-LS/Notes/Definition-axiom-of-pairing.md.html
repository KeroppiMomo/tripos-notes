The axiom of pairing is the $\in$-formula $$ \begin{align*} \mathsf{Pair} := \forall x\forall y \ \exists p \ \forall z(z\in p \Leftrightarrow (z=x \vee z=y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x,y\in X$ this defines a unique object in a model $X$, denoted $\set{x,y}$, or $\set{x}$ if $x=y$.
