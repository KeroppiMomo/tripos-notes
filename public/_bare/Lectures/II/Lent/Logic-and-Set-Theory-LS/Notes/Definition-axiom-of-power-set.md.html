The axiom of power set is the $\in$-formula $$ \begin{align*} \mathsf{Powerset} :={}& \forall x\ \exists p\ \forall z(z\in p \Leftrightarrow \forall y(y\in z \Rightarrow y\in x)) \\ \equiv{}& \forall x\ \exists p\ \forall z(z\in p\Leftrightarrow z\subseteq x). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\mathcal{P}(x)$.
