Let $T\subseteq{}$$\mathrm{Fml}^a$. We require the following properties of $\vdash$ in predicate logic:

  1. Finiteness: if $T \vdash ϕ$, then there is a finite $T_0\subseteq T$ such that $T_0\vdash ϕ$.

  2. Soundness: if $T \vdash ϕ$, then $T \vDash ϕ$.

  3. Assumption: if $ϕ\in T$, then $T \vdash ϕ$.

  4. Strengthening: if $T \subseteq T'$ and $T \vdash ϕ$, then $T'\vdash ϕ$.

  5. Deduction theorem: $T \vdash (ϕ \implies ψ)$ iff $T \cup \set{ϕ} \vdash ψ$.

  6. Modus ponens: $T \vdash (ϕ \implies ψ)$ and $T \vdash ϕ$, then $T\vdash ψ$.

  7. Propositional tautologies: let $χ$ be a propositional tautology with propositional variables $p_1, \ldots, p_n$. For any predicate formulas $ϕ_1, \ldots, ϕ_n$, let $ϕ$ be the predicate formula obtained from replacing $p_i$ with $ϕ_i$. Then $T \vdash ϕ$.

  8. Implicativity: $T \vdash ϕ$ iff $T \vdash s(ϕ)$ where $s: \mathrm{Fml}^a \to \mathrm{IFml}^a$ is defined here.

  9. Equality: the relation on $a$-terms $$ \begin{align*} t\sim t' :\iff T \vdash t = t' \end{align*} $$ is an equivalence relation.

  10. Congruence: relations and operations respect equality, i.e.

    • If $r$ is an $n$-ary relation symbol, and $t_0, \ldots, t_{n-1}$ and $t_{0}', \ldots, t_{n-1}'$ are $a$-terms such that $T \vdash t_i = t_i'$ for all $i<n$, then $T \vdash r t_0 \ldots t_{n-1}$ iff $T \vdash r t_0' \ldots t_{n-1}'$.

    • If $s$ is a $n$-ary function symbol, and $t_0, \ldots, t_{n-1}$ and $t_{0}', \ldots, t_{n-1}'$ are $a$-terms such that $T \vdash t_i = t_i'$ for all $i<n$, then $T \vdash s t_0 \ldots t_{n-1} = s t_{0}' \ldots t_{n-1}'$.

  11. Universality: if $T \vdash \forall xϕ$, we have $T \vdash ϕ\frac{t}{x}$ for all $a$-terms $t$.
