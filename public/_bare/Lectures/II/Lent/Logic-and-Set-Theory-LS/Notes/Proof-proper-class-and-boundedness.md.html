Coextensional with set $\implies$ bounded

If $A\subseteq X$ is coextensional with $x\in X$, since all sets are von Neumann, $\mathbf{X}\vDash x\in V_α$ for some ordinal $α$, so by transitivity, $\mathbf{X} \vDash y\in V_α$ for all $\mathbf{X} \vDash y\in x$. Therefore $A = \sb{y\in x}{\mathbf{X}\vDash y\in x} \subseteq V_α^\mathbf{X}$.

Bounded and definable $\implies$ coextensional with set

Suppose $A = \sb{y\in X}{\mathbf{X}\vDash ϕ(y)}$ and contained in $V^\mathbf{X}_α$. Then apply separation to $V_α$ and $ϕ$ to obtain $x\in X$ which is coextensional with $A$.
