Definition (axiom of extensionality) open_in_new

The axiom of extensionality is the $\in$-formula $$ \begin{align*} \mathsf{Ext} := \forall x\forall y (x = y \Leftrightarrow \forall z(z\in x\Leftrightarrow z\in y)). \end{align*} $$

"Two sets are equal iff they have the same elements."

Definition (axiom schema of comprehension) open_in_new

For any $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, z}$, define $$ \begin{align*} \mathsf{Compr}_ϕ := \forall v_0 \ldots\forall v_{n-1} \exists c \forall z(z\in c \Leftrightarrow ϕ). \end{align*} $$ The collection of all $\mathsf{Compr}_ϕ$ is $\mathsf{Compr}$, the axiom schema of comprehension.

Proposition (Russell's paradox) open_in_new

For any $\in$-structure $\mathbf{X}$, $\mathsf{Compr}_ϕ$ is false in $\mathbf{X}$ where $$ϕ = \neg z \in z.$$ In particular $\mathsf{Compr}$ does not hold in $\mathbf{X}$.

Proof

Therefore $X$ is a proper class.

Definition (axiom of empty set) open_in_new

The axiom of empty set is the $\in$-formula $$ \begin{align*} \mathsf{Emp} := \exists c \ \forall z (z\in c \Leftrightarrow \bot). \end{align*} $$

By $\mathsf{Ext}$, this defines a unique object in the model, denoted $\emptyset$.

Definition (axiom of pairing) open_in_new

The axiom of pairing is the $\in$-formula $$ \begin{align*} \mathsf{Pair} := \forall x\forall y \ \exists p \ \forall z(z\in p \Leftrightarrow (z=x \vee z=y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x,y\in X$ this defines a unique object in a model $X$, denoted $\set{x,y}$, or $\set{x}$ if $x=y$.

Definition (axiom of union) open_in_new

The axiom of union is the $\in$-formula $$ \begin{align*} \mathsf{Union} := \forall x\ \exists u\ \forall z(z\in u \Leftrightarrow \exists y(y\in x \wedge z\in y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\bigcup x$.

Definition (axiom of power set) open_in_new

The axiom of power set is the $\in$-formula $$ \begin{align*} \mathsf{Powerset} :={}& \forall x\ \exists p\ \forall z(z\in p \Leftrightarrow \forall y(y\in z \Rightarrow y\in x)) \\ \equiv{}& \forall x\ \exists p\ \forall z(z\in p\Leftrightarrow z\subseteq x). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\mathcal{P}(x)$.

Definition (axiom of separation) open_in_new

For each $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, z}$, define $$ \begin{align*} \mathsf{Sep}_ϕ := \forall v_0 \ldots \forall v_{n-1} \ \forall x\ \exists s\ \forall z(z\in s \Leftrightarrow (z\in x\wedge ϕ)). \end{align*} $$

The collection of all $\mathsf{Sep}_ϕ$ is $\mathsf{Sep}$, the axiom schema of separation.

By $\mathsf{Ext}$, for each $ϕ\in \op{Fml}^\in$, $x\in X$, $\v v\in X^n$ this defines a unique object in a model $X$, denoted $\sb{z\in x}{ϕ}$.

Definition (finite set theory) open_in_new

Finite set theory $\mathsf{FST}$ is the axiom system consisting of $\mathsf{Ext}$, $\mathsf{Emp}$, $\mathsf{Pair}$, $\mathsf{Union}$, $\mathsf{Powerset}$, and $\mathsf{Sep}$.

Definition (successor, inductive set, axiom of infinity) open_in_new

Work in finite set theory.

For any set $x$, the successor of $x$ is $s(x) := x \cup \set{x}$.

A set $a$ is inductive if it satisfies the formula $$ \begin{align*} \op{ind}(a) := \emptyset \in a \ \wedge \ \forall x(x\in a \Rightarrow s(x) \in a). \end{align*} $$

The axiom of infinity is the formula $$ \begin{align*} \mathsf{Inf} := \exists a \ \op{ind}(a). \end{align*} $$

Definition (axiom of replacement) open_in_new

For each $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, v, w}$, write $ϕ \tfrac{x}{v} \tfrac{y}{w}$ for the formula where we replace all $v$ and $w$ in $ϕ$ with $x$ and $y$ respectively. Define $$ \begin{align*} \mathsf{Repl}_ϕ :={} \quad &\forall v_0 \ldots \forall v_{n-1}\ \forall x \forall y \forall y' (ϕ \tfrac{x}{v} \tfrac{y}{w} \wedge ϕ \tfrac{x}{v} \tfrac{y'}{w} \Rightarrow y = y') \\ \Rightarrow{}& \forall v_0 \ldots \forall v_{n-1}\ \forall d \exists r \ \forall y(y\in r \Leftrightarrow \exists x(x\in d \wedge \phi \tfrac{x}{v} \tfrac{y}{w})). \end{align*} $$ $ϕ$ is said to be functional if the premise holds.

The collection of all $\mathsf{Repl}_ϕ$ is $\mathsf{Repl}$, the axiom schema of replacement.

Definition (axiom of choice) open_in_new

In the language of set theory, let $x$ be a set. $f$ is a choice function for $x$ if it satisfies $$ \begin{align*} \op{cf}(f, x) := \bigl(f: x\to \bigcup x\bigr) \wedge \forall y \bigl(y\in x \wedge y\neq \emptyset \Rightarrow f(y) \in y\bigr). \end{align*} $$

The axiom of choice is the $\in$-formula $$ \begin{align*} \mathsf{AC} := \forall x \exists f\ \op{cf}(f,x). \end{align*} $$

Definition (axiom of foundation) open_in_new

The axiom of foundation is the $\in$-formula $$ \begin{align*} \mathsf{Found} := \forall x (x \neq \emptyset \Rightarrow \exists m (m\in x \wedge m \cap x = \emptyset)). \end{align*} $$

$m \cap x = \emptyset$ iff $m$ is $\in$-minimal in $x$.

Definition (Zermelo–Fraenkel set theory) open_in_new

Define the following axiom systems:

  • $\mathsf{Z} :={}$$\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Found}$, the Zermelo set theory.

  • $\mathsf{ZC} := \mathsf{Z}$ + $\mathsf{AC}$, the Zermelo set theory with choice.

  • $\mathsf{ZF} := \mathsf{Z}$ + $\mathsf{Repl}$, the Zermelo-Fraenkel set theory.

  • $\mathsf{ZFC} := \mathsf{ZF}$ + $\mathsf{AC}$, the Zermelo-Fraenkel set theory with choice.
