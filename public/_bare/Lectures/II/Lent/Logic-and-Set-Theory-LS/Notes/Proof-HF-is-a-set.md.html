$V_ω \subseteq \mathbf{HF}$

If $x\in V_ω$, there is some $n\in \N$ such that $x\in V_n$. Since $V_n$ is transitive, $\op{tcl}(x) \subseteq V_n$. As $V_n$ is finite, so is $\op{tcl}(x)$.

$\mathbf{HF} \subseteq V_ω$

By $\in$-induction. We will show if $\op{tcl}(x)$ is finite and all elements of $x$ are in $V_ω$, then $x\in V_ω$.

Use replacement to form $\sb{ρ(y)}{y\in x}$, and let $$ \begin{align*} N = \bigcup \sb{ρ(y)}{y\in x}. \end{align*} $$ Since $x$ is finite, this is a finite union of finite ordinals, so $N$ is finite. As $ρ(y) \leq N$, we have $y\in V_{N+1}$. Therefore $x\subseteq V_{N+1}$ so $x\in V_{N+2} \subseteq V_ω$.
