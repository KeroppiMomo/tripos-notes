Definition (signature, structure, substructure, reduct) open_in_new

A signature is any function $a: I \sqcup J \to \N$ where $I$ and $J$ are disjoint (index) sets.

An $a$-structure is a tuple $\mathbf{X} = (X, S_0, S_1)$ where

  1. $X$ is a set called the underlying set,

  2. $S_0 = \sb{f_i}{i\in I}$ is a family of operations $f_i: X^{a(i)} \to X$, and

  3. $S_1 = \sb{R_j}{j\in J}$ is a family of relations $R_j \subseteq X^{a(j)}$.

If $\mathbf{X} = (X, \sb{f_i}{i\in I}, \sb{R_j}{j\in J})$ and $\mathbf{Y}= (Y, \sb{g_i}{i\in I}, \sb{Q_j}{j\in J})$ are $a$-structures, say $\mathbf{X}$ is a substructure of $\mathbf{Y}$ if

  1. $X \subseteq Y$;

  2. $f_i = g_i|_{X^{a(i)}}$ for all $i\in I$; and

  3. $R_j = Q_j \cap X^{a(j)}$ for all $j\in J$.

Given $I_\ast \subseteq I$ and $J_\ast\subseteq J$, define a signature $a_\ast = a|_{I_\ast \cup J_\ast}$. The $a_\ast$-reduct of $\mathbf{X}$ is $$ \begin{align*} \mathbf{X}_\ast = (X, \sb{f_i}{i\in I_\ast}, \sb{R_j}{j\in J_\ast}). \end{align*} $$

Definition (homomorphism of structures) open_in_new

Let $\mathbf{X} = (X, \sb{f_i}{i\in I}, \sb{R_j}{j\in J})$ and $\mathbf{Y} = (Y, \sb{g_i}{i\in I}, \sb{Q_j}{j\in J})$ be $a$-structures.

A function $h: X\to Y$ is a homomorphism from $\mathbf{X}$ to $\mathbf{Y}$ if

  1. $h(f_i(x)) = g_i(h(x))$ for all $x\in X^{a(i)}$, $i\in I$; and

  2. $x\in R_j$ iff $h(x) \in Q_j$ for all $x\in X^{a(j)}$, $j\in J$.

Definition (equationally definable) open_in_new

Let $\mathbf{X} = (X, S_0, S_1)$ be an $a$-structure, $S \subseteq S_0$ be a subset of operations and $f: X^n \to X$ be a function.

Say $f$ is $S$-equationally definable over $\mathbf{X}$ if there exists an expression $t(x)$ using only the operations in $X$ such that $f(x) = t(x)$ for all $x\in X^n$.

Definition (reasoning algebra, Boolean algebra) open_in_new

A reasoning algebra is a structure $$ \begin{align*} \mathbf{X} = (X, +, \cdot, \to, -, 0,1) \end{align*} $$ where $X$ is a set, $+, \cdot , \to$ are binary operations, $-$ is a unary operation, and $0\neq 1\in X$ are nullary operations on $X$.

$\mathbf{X}$ is Boolean if the following Boolean laws hold: for all $x,y,z\in X$,

  1. associativity: $x + (y + z) = (x + y) + z$ and $x \cdot (y \cdot z) = (x \cdot y) \cdot z$;

  2. commutativity: $x+y = y+x$ and $x\cdot y = y\cdot x$;

  3. distributivity: $x+(y\cdot z) = (x+y) \cdot (x+z)$ and $x\cdot (y+z) = x\cdot y + x\cdot z$;

  4. neutrality: $x+0 = x$ and $x\cdot 1 = x$;

  5. annihilation: $x+1 = 1$ and $x\cdot 0 = 0$;

  6. idempotence: $x+x = x$ and $x\cdot x = x$;

  7. absorption: $x+(x\cdot y) = x$ and $x\cdot (x+y) = x$;

  8. double negation: $-(-x) = x$;

  9. contradiction: $x\cdot (-x) = 0$;

  10. excluded middle: $x + (-x) = 1$;

  11. De Morgan's laws: $-(x+y) = (-x)\cdot (-y)$ and $-(x\cdot y) = (-x) + (-y)$;

  12. implication: $x\to y = (-x) + y$.

$\mathbf{2} = (\set{0,1}, +, \cdot ,\to, -, 0,1)$ with the usual truth table is a Boolean algebra.

Definition (formula in propositional logic) open_in_new

Given a countable set $P$ of propositional letters, the alphabet of propositional logic is $$ \begin{align*} Σ = P \cup \set{\wedge, \vee, \Rightarrow, \neg, \bot, \top, ), (}. \end{align*} $$

The set of formulas (denoted $\mathrm{Fml}$) is the smallest subset of $Σ^\ast$ containing

  • all elements of $P$,

  • $\bot$ and $\top$,

and such that if $ϕ, ψ\in \mathrm{Fml}$, then so are

  • $(ϕ \wedge ψ)$,

  • $(ϕ\vee ψ)$,

  • $(ϕ\Rightarrow ψ)$, and

  • $\neg ϕ$.

Then we obtain a reasoning algebra $\mathbf{Fml} = (\mathrm{Fml}, +, \cdot, \to, -, 1, 0)$ by iteratively defining $ϕ + ψ := (ϕ \vee ψ)$, $ϕ\cdot ψ := (ϕ\wedge ψ)$, $ϕ\to ψ := (ϕ \Rightarrow ψ)$, $-ϕ := \neg ϕ$, $1 = \top$, and $0 = \bot$.

We drop parentheses in informal settings.

Definition (valuation) open_in_new

A function $v: \mathrm{Fml}\to 2$ is a valuation if it is a homomorphism from $\mathbf{Fml}$ to $\mathbf{2}$.

$v(\top) = 1$ and $v(\bot) = 0$.

For any function $f: P \to 2$, there exists a unique extension to a valuation by induction.

Coincidence lemma: let $\op{occ}(ϕ)\subseteq P$ be the (finite) set of propositional letters that occur in $ϕ$. If $v,w$ are valuations such that $v|_{\op{occ}(ϕ)} = w|_{\op{occ}(ϕ)}$, then $v(ϕ) = w(ϕ)$.

Definition (alphabet, terms, formulas, sentences in predicate logic) open_in_new

Fix a signature $a: I \sqcup J \to \N$ and an infinite set $V$ of variables. ($I, J, V$ may not be countable.)

The function symbols are $Σ_0^a := \sb{s_i}{i\in I}$, the relation symbols are $Σ_1^a := \sb{r_j}{j\in J}$ and the logical symbols are $$ \begin{align*} L = \set{\wedge, \vee, \Rightarrow, \neg, \bot, \top, =, \exists, \forall, ), (}. \end{align*} $$ The alphabet of signature $a$ is $$ \begin{align*} Σ^a := Σ_0^a \cup Σ_1^a \cup V \cup L. \end{align*} $$

The set $\mathrm{Term}^a$ of $a$-terms is the smallest subset of $(Σ^a)^\ast$ containing $V$ such that $s_i t_0 t_1 \ldots t_{n-1}\in \mathrm{Term}^a$ for any $s_i\in Σ_0^a$ and $t_0, \ldots, t_{n-1} \in \mathrm{Term}^a$ with $n = a(i)$.

For $t\in \mathrm{Term}^a$, write $\op{occ}(t)$ for the set of variables occurring in $t$.

The set $\mathrm{Fml}^a$ of $a$-formulas is the smallest subset of $(Σ^a)^\ast$ containing

  • $\perp$ and $\top$,

  • $t = t'$ for any $t, t'\in \mathrm{Term}^\ast$, and

  • $r_j t_0 t_1 \ldots t_{n-1}$ for any $r_j\in Σ_1^\ast$ and $t_0, \ldots, t_{n-1} \in \mathrm{Term}^a$ with $n = a(j)$,

and such that, if $ϕ, ψ\in \mathrm{Fml}^a$, then so are the following:

  • $\exists v ϕ$ for any $v\in V$,

  • $\forall v ϕ$ for any $v\in V$,

  • $(ϕ \wedge ψ)$,

  • $(ϕ\vee ψ)$,

  • $(ϕ\Rightarrow ψ)$, and

  • $\neg ϕ$.

Define a function $\op{free}$ on $\mathrm{Fml}^a$ recursively:

  • $\op{free}(\bot) = \op{free}(\top) = \emptyset$,

  • $\op{free}(t = t') = \op{occ}(t) \cup \op{occ}(t')$,

  • $\op{free}(r_j t_0 \ldots t_{n-1}) = \op{occ}(t_0) \cup \ldots\op{occ}(t_{n-1})$,

  • $\op{free}((ϕ \wedge ψ)) = \op{free}((ϕ \vee ψ)) = \op{free}((ϕ \Rightarrow ψ)) = \op{free}(ϕ) \cup \op{free}(ψ)$,

  • $\op{free}(\neg ϕ) = \op{free}(\neg ϕ)$,

  • $\op{free}(\exists v ϕ) = \op{free}(\forall v ϕ) = \op{free}(ϕ) \setminus \set{v}$.

An $a$-formula $ϕ$ is an $a$-sentence if $\op{free}(ϕ) = \emptyset$.

Definition (interpretation, model, theory in predicate logic) open_in_new

Let $a$ be a signature, $V$ be an infinite set of variables, and $\mathbf{X}$ be an $a$-structure.

An $\mathbf{X}$-interpretation or $\mathbf{X}$-assignment is any function $\mathfrak{I}: V\to X$. Extent to $\mathrm{Term}^a$ by recursion: $$ \begin{align*} \mathfrak{I}(s_i t_0 \ldots t_{n-1}) := s_i^\mathbf{X}(\mathfrak{I}(t_0), \ldots, \mathfrak{I}(t_{n-1})) \end{align*} $$ where $s_i^\mathbf{X}$ is the operation in $\mathbf{X}$ indexed $i$.

Given an $\mathbf{X}$-interpretation $\mathfrak{I}$, define for $x\in X$, $v\in V$ another $\mathbf{X}$-interpretation $$ \begin{align*} \mathfrak{I}\tfrac{x}{v}(w) = \begin{cases} \mathfrak{I}(w), &\text{if }w\neq v, \\ x, &\text{if }w = v. \end{cases} \end{align*} $$

Now interpret $a$-formulas in $\mathbf{X}$ using $\mathfrak{I}$ according to Tarski's recursive definition of truth:

  • $\mathbf{X}, \mathfrak{I} \vDash \top$ always holds.

  • $\mathbf{X}, \mathfrak{I} \vDash \top$ never holds.

  • $\mathbf{X}, \mathfrak{I} \vDash t = t'$ iff $\mathfrak{I}(t) = \mathfrak{I}(t')$.

  • $\mathbf{X}, \mathfrak{I} \vDash r_j t_0 \ldots t_{n-1}$ iff $a(j) = n$ and $(\mathfrak{I}(t_0), \ldots, \mathfrak{I}(t_{n-1})) \in r_j^\mathbf{X}$, where $r_j^\mathbf{X}$ is the relation in $\mathbf{X}$ indexed $j$.

  • $\mathbf{X}, \mathfrak{I}\vDash (ϕ \wedge ψ)$ iff $\mathbf{X}, \mathfrak{I}\vDash ϕ$ and $\mathbf{X}, \mathfrak{J} \vDash ψ$, etc.

  • $\mathbf{X}, \mathfrak{I}\vDash \exists v ϕ$ iff there exists some $x\in X$ such that $\mathbf{X}, \mathfrak{I}\tfrac{x}{v} \vDash ϕ$.

  • $\mathbf{X}, \mathfrak{I}\vDash \forall v ϕ$ iff for all $x\in X$, there holds $\mathbf{X}, \mathfrak{I}\tfrac{x}{v} \vDash ϕ$.

If $ϕ$ is an $a$-sentence, write $\mathbf{X}\vDash ϕ$ if for all (equivalently some) $\mathbf{X}$-interpretation $\mathfrak{I}$, we have $\mathbf{X}, \mathfrak{I}\vDash ϕ$. In this case we say $ϕ$ is true in $\mathbf{X}$; otherwise say $ϕ$ is false in $\mathbf{X}$.

Let $T\subseteq \mathrm{Fml}^a$. Write $\mathbf{X}\vDash T$ if $\mathbf{X}\vDash ϕ$ for all $ϕ\in T$. In this case, say $\mathbf{X}$ is a model of $T$. Say $T$ is satisfiable if $T$ has a model.

Let $T,S$ be sets of $a$-sentences. Write $T\vDash S$ for whenever $\mathbf{X}\vDash T$, we have $\mathbf{X} \vDash S$.

The theory $\op{Th}(\mathbf{X})$ of $\mathbf{X}$ is the set of $a$-sentences which are true in $\mathbf{X}$. Call two $a$-structures $\mathbf{X}$ and $\mathbf{Y}$ elementarily equivalent if $\op{Th}(\mathbf{X}) = \op{Th}(\mathbf{Y})$.

Note the duality of $\forall$ and $\exists$: $\mathbf{X}, \mathfrak{I} \vDash \exists v\ \neg ϕ$ iff $\mathbf{X}, \mathfrak{I} \vDash \neg \forall v\ ϕ$.

Lemma (coincidence lemma in predicate logic) open_in_new

Let $a$ be a signature, $\mathbf{X}$ be an $a$-structure, and $\mathfrak{I}$ and $\mathfrak{J}$ be $\mathbb{X}$-interpretations.

  1. If $t$ is an $a$-term where $\mathfrak{I}|_{\op{occ}(t)} = \mathfrak{J}|_{\op{occ}(t)}$, then $\mathfrak{J}(t) = \mathfrak{J}(t)$.

  2. If $ϕ$ is an $a$-formula where $\mathfrak{I}|_{\op{free}(ϕ)} = \mathfrak{J}|_{\op{free}(ϕ)}$, then $\mathbf{X}, \mathfrak{I}\vDash ϕ$ iff $\mathbb{X}, \mathfrak{J} \vDash ϕ$.

Proof

Proof in predicate logic open_in_new

Let $T\subseteq{}$$\mathrm{Fml}^a$. We require the following properties of $\vdash$ in predicate logic:

  1. Finiteness: if $T \vdash ϕ$, then there is a finite $T_0\subseteq T$ such that $T_0\vdash ϕ$.

  2. Soundness: if $T \vdash ϕ$, then $T \vDash ϕ$.

  3. Assumption: if $ϕ\in T$, then $T \vdash ϕ$.

  4. Strengthening: if $T \subseteq T'$ and $T \vdash ϕ$, then $T'\vdash ϕ$.

  5. Deduction theorem: $T \vdash (ϕ \implies ψ)$ iff $T \cup \set{ϕ} \vdash ψ$.

  6. Modus ponens: $T \vdash (ϕ \implies ψ)$ and $T \vdash ϕ$, then $T\vdash ψ$.

  7. Propositional tautologies: let $χ$ be a propositional tautology with propositional variables $p_1, \ldots, p_n$. For any predicate formulas $ϕ_1, \ldots, ϕ_n$, let $ϕ$ be the predicate formula obtained from replacing $p_i$ with $ϕ_i$. Then $T \vdash ϕ$.

  8. Implicativity: $T \vdash ϕ$ iff $T \vdash s(ϕ)$ where $s: \mathrm{Fml}^a \to \mathrm{IFml}^a$ is defined here.

  9. Equality: the relation on $a$-terms $$ \begin{align*} t\sim t' :\iff T \vdash t = t' \end{align*} $$ is an equivalence relation.

  10. Congruence: relations and operations respect equality, i.e.

    • If $r$ is an $n$-ary relation symbol, and $t_0, \ldots, t_{n-1}$ and $t_{0}', \ldots, t_{n-1}'$ are $a$-terms such that $T \vdash t_i = t_i'$ for all $i<n$, then $T \vdash r t_0 \ldots t_{n-1}$ iff $T \vdash r t_0' \ldots t_{n-1}'$.

    • If $s$ is a $n$-ary function symbol, and $t_0, \ldots, t_{n-1}$ and $t_{0}', \ldots, t_{n-1}'$ are $a$-terms such that $T \vdash t_i = t_i'$ for all $i<n$, then $T \vdash s t_0 \ldots t_{n-1} = s t_{0}' \ldots t_{n-1}'$.

  11. Universality: if $T \vdash \forall xϕ$, we have $T \vdash ϕ\frac{t}{x}$ for all $a$-terms $t$.

Definition (language of set theory) open_in_new

The language of set theory or $\in$-language is the signature with a single binary relation $\in$.

The formulae in this language are called $\in$-formulae. The set of all $\in$-formulae is denoted $\mathrm{Fml}^\in$.

Structures in this language are called $\in$-structures and can be represented as a directed graph $\mathbf{X} = (X, E)$ where $E \subseteq X^2$.

We will use abbreviations in $\in$-formulae, e.g. $ϕ \Leftrightarrow ψ$ for $ϕ\Rightarrow ψ\wedge ψ \Rightarrow ϕ$, $x\not\in y$ for $\neg x \in y$ etc.

Definition (class, coextensional) open_in_new

Elements of $X$ are called $\mathbf{X}$-sets, and subsets of $X$ are called $\mathbf{X}$-classes.

We say a class $A \subseteq X$ is coextensional with a set $x\in X$ if for all $z\in X$, we have $z\in A$ iff $zEx$.

A class $A \subseteq X$ is proper if it is not coextensional to any set.

Axioms of set theory open_in_new

Definition (axiom of extensionality) open_in_new

The axiom of extensionality is the $\in$-formula $$ \begin{align*} \mathsf{Ext} := \forall x\forall y (x = y \Leftrightarrow \forall z(z\in x\Leftrightarrow z\in y)). \end{align*} $$

"Two sets are equal iff they have the same elements."

Definition (axiom schema of comprehension) open_in_new

For any $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, z}$, define $$ \begin{align*} \mathsf{Compr}_ϕ := \forall v_0 \ldots\forall v_{n-1} \exists c \forall z(z\in c \Leftrightarrow ϕ). \end{align*} $$ The collection of all $\mathsf{Compr}_ϕ$ is $\mathsf{Compr}$, the axiom schema of comprehension.

Proposition (Russell's paradox) open_in_new

For any $\in$-structure $\mathbf{X}$, $\mathsf{Compr}_ϕ$ is false in $\mathbf{X}$ where $$ϕ = \neg z \in z.$$ In particular $\mathsf{Compr}$ does not hold in $\mathbf{X}$.

Proof

Therefore $X$ is a proper class.

Definition (axiom of empty set) open_in_new

The axiom of empty set is the $\in$-formula $$ \begin{align*} \mathsf{Emp} := \exists c \ \forall z (z\in c \Leftrightarrow \bot). \end{align*} $$

By $\mathsf{Ext}$, this defines a unique object in the model, denoted $\emptyset$.

Definition (axiom of pairing) open_in_new

The axiom of pairing is the $\in$-formula $$ \begin{align*} \mathsf{Pair} := \forall x\forall y \ \exists p \ \forall z(z\in p \Leftrightarrow (z=x \vee z=y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x,y\in X$ this defines a unique object in a model $X$, denoted $\set{x,y}$, or $\set{x}$ if $x=y$.

Definition (axiom of union) open_in_new

The axiom of union is the $\in$-formula $$ \begin{align*} \mathsf{Union} := \forall x\ \exists u\ \forall z(z\in u \Leftrightarrow \exists y(y\in x \wedge z\in y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\bigcup x$.

Definition (axiom of power set) open_in_new

The axiom of power set is the $\in$-formula $$ \begin{align*} \mathsf{Powerset} :={}& \forall x\ \exists p\ \forall z(z\in p \Leftrightarrow \forall y(y\in z \Rightarrow y\in x)) \\ \equiv{}& \forall x\ \exists p\ \forall z(z\in p\Leftrightarrow z\subseteq x). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\mathcal{P}(x)$.

Definition (axiom of separation) open_in_new

For each $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, z}$, define $$ \begin{align*} \mathsf{Sep}_ϕ := \forall v_0 \ldots \forall v_{n-1} \ \forall x\ \exists s\ \forall z(z\in s \Leftrightarrow (z\in x\wedge ϕ)). \end{align*} $$

The collection of all $\mathsf{Sep}_ϕ$ is $\mathsf{Sep}$, the axiom schema of separation.

By $\mathsf{Ext}$, for each $ϕ\in \op{Fml}^\in$, $x\in X$, $\v v\in X^n$ this defines a unique object in a model $X$, denoted $\sb{z\in x}{ϕ}$.

Definition (finite set theory) open_in_new

Finite set theory $\mathsf{FST}$ is the axiom system consisting of $\mathsf{Ext}$, $\mathsf{Emp}$, $\mathsf{Pair}$, $\mathsf{Union}$, $\mathsf{Powerset}$, and $\mathsf{Sep}$.

Definition (successor, inductive set, axiom of infinity) open_in_new

Work in finite set theory.

For any set $x$, the successor of $x$ is $s(x) := x \cup \set{x}$.

A set $a$ is inductive if it satisfies the formula $$ \begin{align*} \op{ind}(a) := \emptyset \in a \ \wedge \ \forall x(x\in a \Rightarrow s(x) \in a). \end{align*} $$

The axiom of infinity is the formula $$ \begin{align*} \mathsf{Inf} := \exists a \ \op{ind}(a). \end{align*} $$

Definition (axiom of replacement) open_in_new

For each $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, v, w}$, write $ϕ \tfrac{x}{v} \tfrac{y}{w}$ for the formula where we replace all $v$ and $w$ in $ϕ$ with $x$ and $y$ respectively. Define $$ \begin{align*} \mathsf{Repl}_ϕ :={} \quad &\forall v_0 \ldots \forall v_{n-1}\ \forall x \forall y \forall y' (ϕ \tfrac{x}{v} \tfrac{y}{w} \wedge ϕ \tfrac{x}{v} \tfrac{y'}{w} \Rightarrow y = y') \\ \Rightarrow{}& \forall v_0 \ldots \forall v_{n-1}\ \forall d \exists r \ \forall y(y\in r \Leftrightarrow \exists x(x\in d \wedge \phi \tfrac{x}{v} \tfrac{y}{w})). \end{align*} $$ $ϕ$ is said to be functional if the premise holds.

The collection of all $\mathsf{Repl}_ϕ$ is $\mathsf{Repl}$, the axiom schema of replacement.

Definition (axiom of choice) open_in_new

In the language of set theory, let $x$ be a set. $f$ is a choice function for $x$ if it satisfies $$ \begin{align*} \op{cf}(f, x) := \bigl(f: x\to \bigcup x\bigr) \wedge \forall y \bigl(y\in x \wedge y\neq \emptyset \Rightarrow f(y) \in y\bigr). \end{align*} $$

The axiom of choice is the $\in$-formula $$ \begin{align*} \mathsf{AC} := \forall x \exists f\ \op{cf}(f,x). \end{align*} $$

Definition (axiom of foundation) open_in_new

The axiom of foundation is the $\in$-formula $$ \begin{align*} \mathsf{Found} := \forall x (x \neq \emptyset \Rightarrow \exists m (m\in x \wedge m \cap x = \emptyset)). \end{align*} $$

$m \cap x = \emptyset$ iff $m$ is $\in$-minimal in $x$.

Definition (relation) open_in_new

For sets $a,b$, an element $r\in \mathcal{P}(a\times b)$ is a relation between $a$ and $b$.

  • $r$ is functional if $\forall x \forall y \forall y'\ (x,y)\in r \wedge (x,y')\in r \Rightarrow y = y'$.

  • $r$ is total if $\forall x\ x\in a \Rightarrow \exists y(y\in b \wedge (x,y)\in r)$.

  • $r$ is a function if $r$ is functional and total.

  • $r$ is injective if $\forall x\forall x'\forall y\ (x,y)\in r \wedge(x', y)\in r \Rightarrow x = x'$.

  • $r$ is surjective if $\forall y\ y \in b \Rightarrow \exists x(x\in a \wedge (x,y)\in r)$.

Then $r$ is called a binary relation on $a$.

  • $r$ is reflexive if $\forall x\ (x,x)\in r$.

  • $r$ is irreflexive if $\forall x\ (x,x)\not\in r$.

  • $r$ is symmetric if $\forall x\forall y\ (x,y)\in r \Leftrightarrow (y,x)\in r$.

  • $r$ is transitive if $\forall x\forall y\forall z\ ((x,y)\in r\wedge (y,z)\in r) \Rightarrow (x,z)\in r$.

  • $r$ is antisymmetric if $\forall x\forall y ((x,y)\in r \wedge (y,x)\in r) \Rightarrow x=y$.

  • $r$ is linear if $\forall x\forall y\ (x,y)\in r \vee (y,x)\in r\vee x=y$.

  • $r$ is a partial order if it is reflexive, transitive and antisymmetric.

  • $r$ is a strict partial order if it is irreflective and transitive.

  • $r$ is a linear order if it is a partial order which is linear.

  • $r$ is a strict linear order if it is a strict partial order which is linear.

  • $r$ is an equivalence relation if it is reflexive, symmetric and transitive.

Definition (initial ordinal, cardinal) open_in_new

An ordinal $α$ is called initial if $|γ| < |α|$ for all $γ<α$. An initial ordinal is called a cardinal.

In $\mathsf{FST}$ + $\mathsf{Repl}$, if $X$ is a set which can be well-ordered (which is always the case assuming $\mathsf{AC}$), write $|X|$ for the unique cardinal in bijection with $X$.

If $κ$ is an initial ordinal, then $κ$ is the minimal element of $\sb{\text{ordinal }α}{|α| = |κ|}$.

If $A$ is a set of initial ordinals, then $\bigcup A$ is also an initial ordinal.

Definition (von Neumann universe, Mirimanoff rank) open_in_new

Define by transfinite recursion $$ \begin{align*} V_0 ={}& \emptyset, \\ V_{s(α)} ={}& \mathcal{P}(V_α), \\ V_λ ={}& \bigcup_{α<λ} V_α, &&\text{$λ$ is a limit ordinal}. \end{align*} $$

A set $x$ is a von Neumann set if $x\in V_α$ for some ordinal $α$. The class of all von Neumann sets is called the von Neumann universe.

If $x$ is von Neumann, its Mirimanoff rank is the minimum $α$ such that $x\in V_{α+1}$ (or equivalently $x \subseteq V_α$).

$V_α$ is transitive by transfinite induction.

$α\in V_{α+1}$ for any ordinal $α$. Moreover $\set{\text{ordinals in }V_α} = α$.

For $x$ von Neumann, $$ \begin{align*} ρ(x) = \bigcup \sb{ρ(y)+1}{y \in x}. \end{align*} $$
