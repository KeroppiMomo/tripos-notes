If $T$ is consistent, then either $T \cup \set{ϕ}$ or $T \cup \set{\neg ϕ}$ is consistent for any $ϕ\in \mathrm{Fml}$

Suppose $T \cup \set{ϕ}$ is not consistent, i.e. $T \cup \set{ϕ} \vdash \bot$. By the deduction theorem, $T \vdash (ϕ \Rightarrow \bot)$.

Here is a $\set{(ϕ \Rightarrow \bot)}$-proof of $\neg ϕ$:

  1. $(ϕ \Rightarrow \bot)$ (hypothesis)

  2. $((ϕ \Rightarrow \bot) \Rightarrow \neg ϕ)$ (axiom of type 4)

  3. $\neg ϕ$ (modus ponens using 0, 1)

As $T$ is consistent, so is $T \cup \set{(ϕ \Rightarrow \bot)}$.

Construction of negation complete set

Enumerate the countable set $\mathrm{Fml} = \sb{ϕ_i}{i\in \N}$ (or well-order it). Let $T_0 = T$ and assume $T_i$ is consistent by induction. By what we've shown, set $T_{i+1} = T_i \cup \set{ϕ_i}$ or $T_i \cup \set{\neg ϕ_i}$ so that $T_{i+1}$ is consistent. Take $T^\ast = \bigcup_{i\in \N} T_i$.

$T^\ast$ is negation complete: for each $ϕ\in \mathrm{Fml}$, either $ϕ$ or $\neg ϕ$ is contained in $T^\ast$, so $T^\ast\vdash ϕ$ or $\neg ϕ$.

$T^\ast$ is consistent: if $T^\ast\vdash \bot$, by finiteness, there exists some $i$ such that $T_i \vdash \bot$, which is impossible.
