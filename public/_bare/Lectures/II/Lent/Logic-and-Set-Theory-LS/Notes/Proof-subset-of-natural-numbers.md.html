$m=n$ or $m\in n$ $\implies$ $m\subseteq n$

Trivial if $m=n$. If $m\in n$, then $m\subseteq n$ by transitivity.

$m\subseteq n$ $\implies$ $m=n$ or $m\in n$

By induction on $n$. If $n=\emptyset$, then $m=\emptyset = n$.

Suppose this is true for $n$ and consider $m\subseteq s(n) = n \cup \set{n}$.

  • If $m \subseteq n$, then by induction hypothesis, $m=n$ or $m\in n$ so in both cases $m \in s(n)$.

  • Otherwise if $n\in m$, then $n\subseteq m$ by transitivity. Together this means $n \cup \set{n} \subseteq m$, so hypothesis implies $m = n\cup \set{n} = s(n)$.
