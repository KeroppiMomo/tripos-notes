Suppose not, so there is some $x$ such that $ϕ(x)$ does not hold. By hypothesis, $\sb{z\in x}{\neg ϕ(z)}\neq \emptyset$.

By $\mathsf{Inf} + \mathsf{Repl}$, find the transitive closure $t := \op{tcl}(x)$. Define by separation $$ \begin{align*} y := \sb{z\in t}{\neg ϕ(z)} \neq \emptyset. \end{align*} $$ By $\mathsf{Found}$, find the $\in$-minimal element $z\in y$. Then all elements of $z$ are in $t$ (by transitivity) but not $y$, so $ϕ(z)$ holds, which is a contradiction.
