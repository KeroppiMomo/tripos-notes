Consider a model $\mathbf{X}$ of $\mathsf{ZF}$${}= \mathsf{FST} + \mathsf{Inf} + \mathsf{Repl} + \mathsf{Found}$.

A class $A \subseteq X$ is said to be bounded if $A \subseteq V^\mathbf{X}_α$ for some ordinal $α$, where $V^\mathbf{X}_α\subseteq X$ is the class coextensional to the von Neumann stage $V_α$.

A definable subset $A \subseteq X$ is a proper class iff $A$ is unbounded.
