An ordinal $α$ is called initial if $|γ| < |α|$ for all $γ<α$. An initial ordinal is called a cardinal.

In $\mathsf{FST}$ + $\mathsf{Repl}$, if $X$ is a set which can be well-ordered (which is always the case assuming $\mathsf{AC}$), write $|X|$ for the unique cardinal in bijection with $X$.

If $κ$ is an initial ordinal, then $κ$ is the minimal element of $\sb{\text{ordinal }α}{|α| = |κ|}$.

If $κ, λ$ are initial ordinals, then either $|κ|<|λ|$, $κ = λ$, or $|κ|>|λ|$.

If $A$ is a set of initial ordinals, then $\bigcup A$ is also an initial ordinal.
