Definition (construction of natural numbers from Inf) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$.

For an inductive set $a$, which exists by $\mathsf{Inf}$, define by $\mathsf{Sep}$ $$ \begin{align*} N_a := \sb{z\in a}{\forall x(\op{ind}(x) \Rightarrow z\in x)}. \end{align*} $$ Check this does not depend on $a$ and is the smallest inductive set. Call this $$ \begin{align*} \N := N_a \end{align*} $$ and call its elements the natural numbers.

Write $0 := \emptyset$, $1 := s(0) = \set{0} = \set{\emptyset}$, $2 := s(1) = \set{0, 1} = \set{\emptyset, \set{\emptyset}}$, $3 := s(2) = \set{0, 1, 2} = \set{\emptyset, \set{\emptyset}, \set{\emptyset, \set{\emptyset}}}$ etc.

Definition (minimal element, well-founded relation) open_in_new

Let $R$ be a binary relation of a set $X$.

For a subset $S\subseteq X$, an $R$-minimal element of $S$ is an element $m\in S$ such that for all $s\in S$, it is not the case that $sRm$.

$R$ is well-founded if all non-empty subsets of $X$ have an $R$-minimal element.

Definition (transitive set) open_in_new

A set $x$ is transitive if for all sets $y,z$, if $z\in y\in x$, then $z\in x$.

Equivalently, all elements of $x$ are subsets of $x$.

Proposition (transitivity of natural numbers) open_in_new

Construct $\N$ as here.

  1. $\N$ is transitive.

  2. Any natural number is transitive.

Proposition (subset of natural numbers) open_in_new

Construct $\N$ as here.

If $n,m\in \N$, then $m\subseteq n$ iff $m = n$ or $m\in n$.

Definition (finite, infinite, countable, uncountable, countably infinite) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$.

A set $X$ is finite if there exists $n\in{}$$\N$ such that $X$ is in bijection with $n$; otherwise $X$ is infinite.

$X$ is countable if there exists an injection $X \hookrightarrow \N$; otherwise $X$ is uncountable.

$X$ is countably infinite if there exists a bijection $X\to \N$.
