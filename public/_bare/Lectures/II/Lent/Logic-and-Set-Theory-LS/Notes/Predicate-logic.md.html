Definition (alphabet, terms, formulas, sentences in predicate logic) open_in_new

Fix a signature $a: I \sqcup J \to \N$ and an infinite set $V$ of variables. ($I, J, V$ may not be countable.)

The function symbols are $Σ_0^a := \sb{s_i}{i\in I}$, the relation symbols are $Σ_1^a := \sb{r_j}{j\in J}$ and the logical symbols are $$ \begin{align*} L = \set{\wedge, \vee, \Rightarrow, \neg, \bot, \top, =, \exists, \forall, ), (}. \end{align*} $$ The alphabet of signature $a$ is $$ \begin{align*} Σ^a := Σ_0^a \cup Σ_1^a \cup V \cup L. \end{align*} $$

The set $\mathrm{Term}^a$ of $a$-terms is the smallest subset of $(Σ^a)^\ast$ containing $V$ such that $s_i t_0 t_1 \ldots t_{n-1}\in \mathrm{Term}^a$ for any $s_i\in Σ_0^a$ and $t_0, \ldots, t_{n-1} \in \mathrm{Term}^a$ with $n = a(i)$.

For $t\in \mathrm{Term}^a$, write $\op{occ}(t)$ for the set of variables occurring in $t$.

The set $\mathrm{Fml}^a$ of $a$-formulas is the smallest subset of $(Σ^a)^\ast$ containing

  • $\perp$ and $\top$,

  • $t = t'$ for any $t, t'\in \mathrm{Term}^\ast$, and

  • $r_j t_0 t_1 \ldots t_{n-1}$ for any $r_j\in Σ_1^\ast$ and $t_0, \ldots, t_{n-1} \in \mathrm{Term}^a$ with $n = a(j)$,

and such that, if $ϕ, ψ\in \mathrm{Fml}^a$, then so are the following:

  • $\exists v ϕ$ for any $v\in V$,

  • $\forall v ϕ$ for any $v\in V$,

  • $(ϕ \wedge ψ)$,

  • $(ϕ\vee ψ)$,

  • $(ϕ\Rightarrow ψ)$, and

  • $\neg ϕ$.

Define a function $\op{free}$ on $\mathrm{Fml}^a$ recursively:

  • $\op{free}(\bot) = \op{free}(\top) = \emptyset$,

  • $\op{free}(t = t') = \op{occ}(t) \cup \op{occ}(t')$,

  • $\op{free}(r_j t_0 \ldots t_{n-1}) = \op{occ}(t_0) \cup \ldots\op{occ}(t_{n-1})$,

  • $\op{free}((ϕ \wedge ψ)) = \op{free}((ϕ \vee ψ)) = \op{free}((ϕ \Rightarrow ψ)) = \op{free}(ϕ) \cup \op{free}(ψ)$,

  • $\op{free}(\neg ϕ) = \op{free}(\neg ϕ)$,

  • $\op{free}(\exists v ϕ) = \op{free}(\forall v ϕ) = \op{free}(ϕ) \setminus \set{v}$.

An $a$-formula $ϕ$ is an $a$-sentence if $\op{free}(ϕ) = \emptyset$.

Definition (interpretation, model, theory in predicate logic) open_in_new

Let $a$ be a signature, $V$ be an infinite set of variables, and $\mathbf{X}$ be an $a$-structure.

An $\mathbf{X}$-interpretation or $\mathbf{X}$-assignment is any function $\mathfrak{I}: V\to X$. Extent to $\mathrm{Term}^a$ by recursion: $$ \begin{align*} \mathfrak{I}(s_i t_0 \ldots t_{n-1}) := s_i^\mathbf{X}(\mathfrak{I}(t_0), \ldots, \mathfrak{I}(t_{n-1})) \end{align*} $$ where $s_i^\mathbf{X}$ is the operation in $\mathbf{X}$ indexed $i$.

Given an $\mathbf{X}$-interpretation $\mathfrak{I}$, define for $x\in X$, $v\in V$ another $\mathbf{X}$-interpretation $$ \begin{align*} \mathfrak{I}\tfrac{x}{v}(w) = \begin{cases} \mathfrak{I}(w), &\text{if }w\neq v, \\ x, &\text{if }w = v. \end{cases} \end{align*} $$

Now interpret $a$-formulas in $\mathbf{X}$ using $\mathfrak{I}$ according to Tarski's recursive definition of truth:

  • $\mathbf{X}, \mathfrak{I} \vDash \top$ always holds.

  • $\mathbf{X}, \mathfrak{I} \vDash \top$ never holds.

  • $\mathbf{X}, \mathfrak{I} \vDash t = t'$ iff $\mathfrak{I}(t) = \mathfrak{I}(t')$.

  • $\mathbf{X}, \mathfrak{I} \vDash r_j t_0 \ldots t_{n-1}$ iff $a(j) = n$ and $(\mathfrak{I}(t_0), \ldots, \mathfrak{I}(t_{n-1})) \in r_j^\mathbf{X}$, where $r_j^\mathbf{X}$ is the relation in $\mathbf{X}$ indexed $j$.

  • $\mathbf{X}, \mathfrak{I}\vDash (ϕ \wedge ψ)$ iff $\mathbf{X}, \mathfrak{I}\vDash ϕ$ and $\mathbf{X}, \mathfrak{J} \vDash ψ$, etc.

  • $\mathbf{X}, \mathfrak{I}\vDash \exists v ϕ$ iff there exists some $x\in X$ such that $\mathbf{X}, \mathfrak{I}\tfrac{x}{v} \vDash ϕ$.

  • $\mathbf{X}, \mathfrak{I}\vDash \forall v ϕ$ iff for all $x\in X$, there holds $\mathbf{X}, \mathfrak{I}\tfrac{x}{v} \vDash ϕ$.

If $ϕ$ is an $a$-sentence, write $\mathbf{X}\vDash ϕ$ if for all (equivalently some) $\mathbf{X}$-interpretation $\mathfrak{I}$, we have $\mathbf{X}, \mathfrak{I}\vDash ϕ$. In this case we say $ϕ$ is true in $\mathbf{X}$; otherwise say $ϕ$ is false in $\mathbf{X}$.

Let $T\subseteq \mathrm{Fml}^a$. Write $\mathbf{X}\vDash T$ if $\mathbf{X}\vDash ϕ$ for all $ϕ\in T$. In this case, say $\mathbf{X}$ is a model of $T$. Say $T$ is satisfiable if $T$ has a model.

Let $T,S$ be sets of $a$-sentences. Write $T\vDash S$ for whenever $\mathbf{X}\vDash T$, we have $\mathbf{X} \vDash S$.

The theory $\op{Th}(\mathbf{X})$ of $\mathbf{X}$ is the set of $a$-sentences which are true in $\mathbf{X}$. Call two $a$-structures $\mathbf{X}$ and $\mathbf{Y}$ elementarily equivalent if $\op{Th}(\mathbf{X}) = \op{Th}(\mathbf{Y})$.

Note the duality of $\forall$ and $\exists$: $\mathbf{X}, \mathfrak{I} \vDash \exists v\ \neg ϕ$ iff $\mathbf{X}, \mathfrak{I} \vDash \neg \forall v\ ϕ$.

Lemma (coincidence lemma in predicate logic) open_in_new

Let $a$ be a signature, $\mathbf{X}$ be an $a$-structure, and $\mathfrak{I}$ and $\mathfrak{J}$ be $\mathbb{X}$-interpretations.

  1. If $t$ is an $a$-term where $\mathfrak{I}|_{\op{occ}(t)} = \mathfrak{J}|_{\op{occ}(t)}$, then $\mathfrak{J}(t) = \mathfrak{J}(t)$.

  2. If $ϕ$ is an $a$-formula where $\mathfrak{I}|_{\op{free}(ϕ)} = \mathfrak{J}|_{\op{free}(ϕ)}$, then $\mathbf{X}, \mathfrak{I}\vDash ϕ$ iff $\mathbb{X}, \mathfrak{J} \vDash ϕ$.

Proof

If $\op{occ}(t) = \set{v_0, \ldots, v_k}$, denote $$ \begin{align*} t(x_0, \ldots, x_k) := \mathfrak{I}\tfrac{x_0}{v_0} \ldots \tfrac{x_k}{v_k}(t) \end{align*} $$ and if $\op{free}(ϕ) = \set{v_0, \ldots, v_k}$, denote $$ \begin{align*} \mathbf{X} \vDash ϕ(x_0, \ldots, x_k) \quad :\iff \quad \mathbf{X}, \mathfrak{I}\tfrac{x_0}{v_0} \ldots \tfrac{x_k}{v_k} \vDash ϕ. \end{align*} $$ This result shows these do not depend on the choice of interpretation $\mathfrak{I}$.

Definition (definable) open_in_new

Let $\mathbb{X}$ be an $a$-structure.

An operation $f: X^n\to X$ is definable over $\mathbf{X}$ if there is a formula $ϕ$ with $n+1$ free variables such that $f(\v x) = x$ iff $\mathbf{X}$${}\vDash{}$$ϕ(\v x, x)$.

A relation $R\subseteq X^n$ is definable over $\mathbf{X}$ if there is a formula $ϕ$ with $n$ free variables such that $\v x\in R$ iff $\mathbf{X}\vDash ϕ(\v x)$.

Definition (implication formula in predicate logic) open_in_new

In predicate logic, an implication formula is a formula which does not contain the symbols $\wedge$, $\vee$, $\neg$, $\top$, $\exists$.

Write $\mathsf{IFml}^a$ for the set of implicative $a$-formulas.

As before define recursively the surjection $$ \begin{align*} s: \mathrm{Fml} &\to \mathrm{IFml} \\ \exists x ϕ &\mapsto \forall x(s(ϕ) \Rightarrow \bot)\Rightarrow \bot. \end{align*} $$

Proof in predicate logic open_in_new

Let $T\subseteq{}$$\mathrm{Fml}^a$. We require the following properties of $\vdash$ in predicate logic:

  1. Finiteness: if $T \vdash ϕ$, then there is a finite $T_0\subseteq T$ such that $T_0\vdash ϕ$.

  2. Soundness: if $T \vdash ϕ$, then $T \vDash ϕ$.

  3. Assumption: if $ϕ\in T$, then $T \vdash ϕ$.

  4. Strengthening: if $T \subseteq T'$ and $T \vdash ϕ$, then $T'\vdash ϕ$.

  5. Deduction theorem: $T \vdash (ϕ \implies ψ)$ iff $T \cup \set{ϕ} \vdash ψ$.

  6. Modus ponens: $T \vdash (ϕ \implies ψ)$ and $T \vdash ϕ$, then $T\vdash ψ$.

  7. Propositional tautologies: let $χ$ be a propositional tautology with propositional variables $p_1, \ldots, p_n$. For any predicate formulas $ϕ_1, \ldots, ϕ_n$, let $ϕ$ be the predicate formula obtained from replacing $p_i$ with $ϕ_i$. Then $T \vdash ϕ$.

  8. Implicativity: $T \vdash ϕ$ iff $T \vdash s(ϕ)$ where $s: \mathrm{Fml}^a \to \mathrm{IFml}^a$ is defined here.

  9. Equality: the relation on $a$-terms $$ \begin{align*} t\sim t' :\iff T \vdash t = t' \end{align*} $$ is an equivalence relation.

  10. Congruence: relations and operations respect equality, i.e.

    • If $r$ is an $n$-ary relation symbol, and $t_0, \ldots, t_{n-1}$ and $t_{0}', \ldots, t_{n-1}'$ are $a$-terms such that $T \vdash t_i = t_i'$ for all $i<n$, then $T \vdash r t_0 \ldots t_{n-1}$ iff $T \vdash r t_0' \ldots t_{n-1}'$.

    • If $s$ is a $n$-ary function symbol, and $t_0, \ldots, t_{n-1}$ and $t_{0}', \ldots, t_{n-1}'$ are $a$-terms such that $T \vdash t_i = t_i'$ for all $i<n$, then $T \vdash s t_0 \ldots t_{n-1} = s t_{0}' \ldots t_{n-1}'$.

  11. Universality: if $T \vdash \forall xϕ$, we have $T \vdash ϕ\frac{t}{x}$ for all $a$-terms $t$.

Definition (term structure) open_in_new

Fix a set $T$ of $a$-formulas and define the equivalence relation on $\mathrm{Term}^a$ by $t \sim t' :\iff T \vdash t = t'$.

The term structure $\mathbf{H}$ of $T$ is an $a$-structure with an underlying set $$ \begin{align*} H = \mathrm{Term}^a/{\sim} \end{align*} $$ and operations and relations $$ \begin{gather*} s^\mathbf{H}([t_0], \ldots, [t_{n-1}]) := [st_0\ldots t_{n-1}], \\ ([t_0], \ldots, [t_{n-1}]) \in r^\mathbf{H} :\iff T\vdash rt_0 \ldots t_{n-1}, \end{gather*} $$ well-defined by congruence properties of $\vdash$.

The term interpretation of $T$ is $$ \begin{align*} \mathfrak{I}^\mathbf{H}(t) := [t]. \end{align*} $$

Theorem (Lindenbaum's lemma) open_in_new

Let $T\subseteq \mathrm{Fml}$ is a set of formulae in proposition or predicate logic. Suppose $\mathrm{Fml}$ can be well-ordered. (Either $\mathrm{Fml}$ is countable, or assume the axiom of choice.)

If $T$ is consistent, then there is some $T^\ast \subseteq \mathrm{Fml}$ containing $T$ which is negation complete and consistent.

Definition (witness) open_in_new

Fix a signature $a$.

A subset $T \subseteq \mathrm{Fml}^a$ has a witness for $a$ if for all $ϕ\in \mathrm{Fml}^a$ and $x\in V$, there exists a term $t$ such that $$ \begin{align*} T \vdash (\exists x ϕ) \Rightarrow ϕ\tfrac{t}{x}. \end{align*} $$

Theorem (Henkin's lemma) open_in_new

Let $a$ be a signature.

If $T \subseteq \mathrm{Fml}^a$ is consistent, negation complete and has witness for $a$, then the term structure satisfies $$ \begin{align*} \mathbf{H}, \mathfrak{I}^\mathbf{H} \vDash ϕ \iff T \vdash ϕ \end{align*} $$ for all $ϕ\in \mathrm{Fml}^a$.

In particular $\mathbf{H}, \mathfrak{I}^\mathbf{H} \vDash T$.

Proof

Theorem (Henkenisation, model existence) open_in_new

Work in $\mathsf{ZFC}$.

Given $T\subseteq \mathrm{Fml}^a$, let $T_0 := T$ and $a_0 := a$. For each $n\in \N$, let

  • $a_{n+1}$ be the signature $a_n$ with one new constant symbol $c_{ϕ,x}$ for each $(ϕ,x)\in \mathrm{Fml}^{a_n} \times V$,

  • $\tilde T_{n+1} := T_n \cup \sb{(\exists x ϕ) \Rightarrow ϕ\tfrac{c_{ϕ,x}}{x}}{ϕ\in \mathrm{Fml}^{a_n}, x\in V}$ and $T_{n+1}\supseteq \tilde T_{n+1}$ be any superset that is negation complete for $a_{n+1}$ (by Lindenbaum).

Take $$ \begin{align*} a_\infty := \bigcup_{n\in \N} a_n, \quad T_\infty := \bigcup_{n\in \N} T_n. \end{align*} $$

Then $T_\infty\subseteq \mathrm{Fml}^{a_\infty}$ is consistent, negation complete for $a_\infty$ and has witness for $a_\infty$.

Thus the term structure $\mathbf{H}$ of $T_\infty$ is a model of $T_\infty$, hence of $T$.

Proof

Corollary (compactness theorem in predciate logic) open_in_new

Definition (axiomatisation) open_in_new

Let $\mathcal{C}$ be a class of $a$-structures.

A set $T$ of $a$-sentences is called an axiom system or axiomatisation of $\mathcal{C}$ if $\mathbf{X} \in \mathcal{C}$ iff $\mathbf{X}$${}\vDash{}$$T$.

Say $\mathcal{C}$ is axiomatisable if such an axiomatisation exists. If $T$ is finite, say $\mathcal{C}$ is finitely axiomatisable.

Definition (categorical) open_in_new

Work in $\mathsf{ZFC}$. Let $T$ be a set of $a$-sentences and $κ$ be an cardinal.

  • $T$ is categorical if all models of $T$ are isomorphic.

  • $T$ is $κ$-categorical if all models of $T$ of cardinality $κ$ are isomorphic.

Theorem (upward Löwenheim–Skolem) open_in_new

Let $T$ be a set of $a$-sentences.

If $T$ has a model of cardinality $\geq n$ for all $n\in \N$ (such as having an infinite model), then $T$ has a model of cardinality $\geq |K|$ for all set $K$.

Proof

Therefore the class of finite $a$-structures is not axiomatisable: there is an $a$-structure of arbitrary finite cardinality with all operations being constant and all relations being empty.

Such $T$ is not categorical.

Work in $\mathsf{ZFC}$. Let $T$ be a set of $a$-sentences.
