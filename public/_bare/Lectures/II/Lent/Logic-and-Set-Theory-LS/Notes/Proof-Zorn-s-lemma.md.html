$\mathsf{AC} \implies \mathsf{ZL}$

Let $\mathbf{P}$ be a non-empty chain-complete partial order.

Fix a choice function $f: \mathcal{P}(P) \to P$ by $\mathsf{AC}$, and $p_0\in P$ (as $P \neq \emptyset$). Introduce a new set $\mathrm{STOP}\not\in P$, and define by transfinite induction $$ \begin{align*} g: α &\to P \cup \set{\mathrm{STOP}} \\ 0 &\mapsto p_0, \\ s(β) &\mapsto \begin{cases} f(S_{g(β)}), &\text{if $S_{g(β)}\neq \emptyset$}, \\ \mathrm{STOP}, &\text{otherwise}, \end{cases} \\ γ &\mapsto \begin{cases} f(B_{\op{ran}(g|_γ)}), &\text{if $\op{ran}(g|_γ) \subseteq P$}, \\ \mathrm{STOP}, &\text{otherwise}, \end{cases} &&\text{if $λ$ is a limit ordinal} \end{align*} $$ where $α := \aleph(P)$ is the Hartogs aleph, $S_p := \sb{q\in P}{p < q}$ and $B_A := \sb{q\in P}{q \text{ is a bound of }A}$.

Note for $β\leq α$, if $\mathrm{STOP}\not\in \op{ran}(g|_β)$, then $g|_β: β \to P$ is a order-preserving injection. In particular, by definition of $α$, $\mathrm{STOP}\not\in \op{ran}(g)$.

Let $γ\in α$ be minimal such that $g(γ) = \mathrm{STOP}$. By construction, $γ$ must be a successor ordinal, say $γ = s(β)$, and $S_{g(β)} = \emptyset$. This means $β$ is maximal.

$\mathsf{ZL} \implies \mathsf{AC}$

It suffices to produce a choice function for $\mathcal{P}(X)$ for a given set $X$.

Consider the set $$ \begin{align*} P := \sb{f\in \mathcal{P}(X) \times X}{\text{$f$ is a choice function for some $Y\subseteq \mathcal{P}(X)$}} \end{align*} $$ with the partial order $\leq$ on $P$ defined by $$ \begin{align*} f \leq g :\iff f \subseteq g, \end{align*} $$ i.e. $\op{dom}(g) \supseteq \op{dom}(f)$ and $f = g|_{\op{dom}(f)}$.

$P$ is non-empty as it contains $\emptyset$.

To show chain-completeness, let $C$ be a chain. Then $$ \begin{align*} f := \bigcup C \end{align*} $$ is a choice function such that $g\subseteq f$ for all $g\in C$, so $f$ is a bound of $C$.

Therefore by Zorn's lemma, $P$ has a maximal element $f$, which we claim to have domain $\mathcal{P}(X)$. Otherwise suppose $A \in \mathcal{P}(X) \setminus \op{dom}(f)$. If $A = \emptyset$, pick $z$ to be anything, and if $A \neq \emptyset$, pick any $z\in A$. Then $$ \begin{align*} g := f \cup \set{(A, z)} \end{align*} $$ is a choice function strictly greater than $f$.
