Let $\mathcal{C}$ be a class of $a$-structures.

A set $T$ of $a$-sentences is called an axiom system or axiomatisation of $\mathcal{C}$ if $\mathbf{X} \in \mathcal{C}$ iff $\mathbf{X}$${}\vDash{}$$T$.

Say $\mathcal{C}$ is axiomatisable if such an axiomatisation exists. If $T$ is finite, say $\mathcal{C}$ is finitely axiomatisable.
