For sets $a,b$, an element $r\in \mathcal{P}(a\times b)$ is a relation between $a$ and $b$.

  • $r$ is functional if $\forall x \forall y \forall y'\ (x,y)\in r \wedge (x,y')\in r \Rightarrow y = y'$.

  • $r$ is total if $\forall x\ x\in a \Rightarrow \exists y(y\in b \wedge (x,y)\in r)$.

  • $r$ is a function if $r$ is functional and total.

  • $r$ is injective if $\forall x\forall x'\forall y\ (x,y)\in r \wedge(x', y)\in r \Rightarrow x = x'$.

  • $r$ is surjective if $\forall y\ y \in b \Rightarrow \exists x(x\in a \wedge (x,y)\in r)$.

Then $r$ is called a binary relation on $a$.

  • $r$ is reflexive if $\forall x\ (x,x)\in r$.

  • $r$ is irreflexive if $\forall x\ (x,x)\not\in r$.

  • $r$ is symmetric if $\forall x\forall y\ (x,y)\in r \Leftrightarrow (y,x)\in r$.

  • $r$ is transitive if $\forall x\forall y\forall z\ ((x,y)\in r\wedge (y,z)\in r) \Rightarrow (x,z)\in r$.

  • $r$ is antisymmetric if $\forall x\forall y ((x,y)\in r \wedge (y,x)\in r) \Rightarrow x=y$.

  • $r$ is linear if $\forall x\forall y\ (x,y)\in r \vee (y,x)\in r\vee x=y$.

  • $r$ is a partial order if it is reflexive, transitive and antisymmetric.

  • $r$ is a strict partial order if it is irreflective and transitive.

  • $r$ is a linear order if it is a partial order which is linear.

  • $r$ is a strict linear order if it is a strict partial order which is linear.

  • $r$ is an equivalence relation if it is reflexive, symmetric and transitive.
