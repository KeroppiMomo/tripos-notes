By construction, $T_{n+1}$ is negation complete for $a_{n+1}$ and has witness for $a_n$. We will skip the proof that if $T_n$ is consistent, then $T_{n+1}$ is consistent.

Then for $T_\infty$:

  • Consistency: by finiteness, if $T_\infty\vdash \bot$, then $T_n\vdash \bot$ for some $n\in \N$, which is not true.

  • Negation completeness for $a_\infty$: for $ϕ\in \mathrm{Fml}^{a_\infty}$, as $ϕ$ is a finite string, $ϕ\in \mathrm{Fml}^{a_n}$ for some $n$. Then apply negation completeness of $T_n$.

  • Witness for $a_\infty$: any $ϕ\in \mathrm{Fml}^{a_\infty}$ is in $\mathrm{Fml}^{a_n}$ for some $n\in \N$ as before, so use the fact $T_{n+1}$ has witness for $a_n$.
