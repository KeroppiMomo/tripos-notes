$\mathsf{ZWOP} \implies \mathsf{AC}$

It suffices to produce a choice function for $\mathcal{P}(X)$ for a given set $X$. If $X = \emptyset$, then the function works.

By $\mathsf{ZWOP}$, let $(X,<)$ be a well-order. Fix some $x_0\in X$. Then define (by separation) $$ \begin{align*} f: \mathcal{P}(X) &\to X \\ Y &\mapsto \begin{cases} \text{$<$-minimal element of $Y$}, &\text{if }Y\neq \emptyset, \\ x_0, &\text{otherwise}. \end{cases} \end{align*} $$ This is a choice function.

$\mathsf{AC} \implies \mathsf{ZWOP}$

Let $X$ be a set, and find Hartogs's aleph $α := \aleph(X)$. By $\mathsf{AC}$, fix a choice function $f: \mathcal{P}(X) \to X$.

Introduce a new set $\mathrm{STOP}\not\in X$. Define by induction $$ \begin{align*} g: α &\to X\cup \set{\mathrm{STOP}} \\ γ &\mapsto \begin{cases} f(X \setminus \op{ran}(g|_γ)), &\text{if $X\not \subseteq \op{ran}(g|_γ)$}, \\ \mathrm{STOP}, &\text{if $X \subseteq \op{ran}(g|_γ)$}. \end{cases} \end{align*} $$

Note by construction for $β \leq γ$, $\mathrm{STOP}\not\in \op{ran}(g|_{β})$ implies $g|_β : β\to X$ is injective. In particular by definition of $α$, we have $\mathrm{STOP}\in \op{ran}(g)$.

Let $γ\in α$ be least such that $g(γ) = \mathrm{STOP}$. Then $g|_γ: γ\to X$ is an injection by construction. Moreover $X \subseteq \op{ran}(g|_γ)$, so $g|_γ$ is also a surjection.

Define a relation $<$ on $X$ by $x<x'$ iff $g\inv(x) \in g\inv(y)$. Then $g|_γ: (γ, \in) \to (X, <)$ is an isomorphism, so $(X, <)$ is a well-order.
