Apply transfinite induction to prove if $κ$ is an infinite ordinal, then $κ = \aleph_α$ for some $α$.

This is true for $κ\leq ω$.

Suppose induction hypothesis holds for all $λ<κ$ and suppose $κ>ω$ is an infinite cardinal.

  • If there is a largest infinite cardinal in $κ$, then it is $\aleph_α$ for some $α$. Then $\aleph_{s(α)} = \aleph(\aleph_α)$ is not in $κ$, so $κ \leq \aleph_{s(α)}$. Also $\aleph_{s(α)}$ is the smallest cardinal greater than $\aleph_α$, so $κ \geq \aleph_{s(α)}$. Hence $κ = \aleph_{s(α)}$.

  • Otherwise, $\bigcup \sb{λ<κ}{λ\text{ is an infinite cardinal}} = κ$ (because $ω<κ$). Each $λ<κ$ equals $\aleph_α$ for some $α$, so there is a limit ordinal $η$ such that $\bigcup \sb{λ<κ}{λ\text{ is an infinite cardinal}} = \bigcup \sb{\aleph_α}{α<η} = \aleph_η$.
