Let $\mathbf{X} = (X,E)$ be a model of set theory.

Elements of $X$ are called $\mathbf{X}$-sets, and subsets of $X$ are called $\mathbf{X}$-classes.

We say a class $A \subseteq X$ is coextensional with a set $x\in X$ if for all $z\in X$, we have $z\in A$ iff $zEx$.

A class $A \subseteq X$ is proper if it is not coextensional to any set.
