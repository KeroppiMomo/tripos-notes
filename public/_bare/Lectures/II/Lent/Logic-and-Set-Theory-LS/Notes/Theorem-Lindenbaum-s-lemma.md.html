Let $T\subseteq \mathrm{Fml}$ is a set of formulae in proposition or predicate logic. Suppose $\mathrm{Fml}$ can be well-ordered. (Either $\mathrm{Fml}$ is countable, or assume the axiom of choice.)

If $T$ is consistent, then there is some $T^\ast \subseteq \mathrm{Fml}$ containing $T$ which is negation complete and consistent.
