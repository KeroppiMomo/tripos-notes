Definition (language of set theory) open_in_new

The language of set theory or $\in$-language is the signature with a single binary relation $\in$.

The formulae in this language are called $\in$-formulae. The set of all $\in$-formulae is denoted $\mathrm{Fml}^\in$.

Structures in this language are called $\in$-structures and can be represented as a directed graph $\mathbf{X} = (X, E)$ where $E \subseteq X^2$.

We will use abbreviations in $\in$-formulae, e.g. $ϕ \Leftrightarrow ψ$ for $ϕ\Rightarrow ψ\wedge ψ \Rightarrow ϕ$, $x\not\in y$ for $\neg x \in y$ etc.

Definition (class, coextensional) open_in_new

Let $\mathbf{X} = (X,E)$ be a model of set theory.

Elements of $X$ are called $\mathbf{X}$-sets, and subsets of $X$ are called $\mathbf{X}$-classes.

We say a class $A \subseteq X$ is coextensional with a set $x\in X$ if for all $z\in X$, we have $z\in A$ iff $zEx$.

A class $A \subseteq X$ is proper if it is not coextensional to any set.

Axioms of set theory open_in_new

Definition (axiom of extensionality) open_in_new

The axiom of extensionality is the $\in$-formula $$ \begin{align*} \mathsf{Ext} := \forall x\forall y (x = y \Leftrightarrow \forall z(z\in x\Leftrightarrow z\in y)). \end{align*} $$

"Two sets are equal iff they have the same elements."

Definition (axiom schema of comprehension) open_in_new

For any $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, z}$, define $$ \begin{align*} \mathsf{Compr}_ϕ := \forall v_0 \ldots\forall v_{n-1} \exists c \forall z(z\in c \Leftrightarrow ϕ). \end{align*} $$ The collection of all $\mathsf{Compr}_ϕ$ is $\mathsf{Compr}$, the axiom schema of comprehension.

Proposition (Russell's paradox) open_in_new

For any $\in$-structure $\mathbf{X}$, $\mathsf{Compr}_ϕ$ is false in $\mathbf{X}$ where $$ϕ = \neg z \in z.$$ In particular $\mathsf{Compr}$ does not hold in $\mathbf{X}$.

Proof

Therefore $X$ is a proper class.

Definition (axiom of empty set) open_in_new

The axiom of empty set is the $\in$-formula $$ \begin{align*} \mathsf{Emp} := \exists c \ \forall z (z\in c \Leftrightarrow \bot). \end{align*} $$

By $\mathsf{Ext}$, this defines a unique object in the model, denoted $\emptyset$.

Definition (axiom of pairing) open_in_new

The axiom of pairing is the $\in$-formula $$ \begin{align*} \mathsf{Pair} := \forall x\forall y \ \exists p \ \forall z(z\in p \Leftrightarrow (z=x \vee z=y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x,y\in X$ this defines a unique object in a model $X$, denoted $\set{x,y}$, or $\set{x}$ if $x=y$.

Definition (axiom of union) open_in_new

The axiom of union is the $\in$-formula $$ \begin{align*} \mathsf{Union} := \forall x\ \exists u\ \forall z(z\in u \Leftrightarrow \exists y(y\in x \wedge z\in y)). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\bigcup x$.

Definition (axiom of power set) open_in_new

The axiom of power set is the $\in$-formula $$ \begin{align*} \mathsf{Powerset} :={}& \forall x\ \exists p\ \forall z(z\in p \Leftrightarrow \forall y(y\in z \Rightarrow y\in x)) \\ \equiv{}& \forall x\ \exists p\ \forall z(z\in p\Leftrightarrow z\subseteq x). \end{align*} $$

By $\mathsf{Ext}$, for each $x\in X$ this defines a unique object in a model $X$, denoted $\mathcal{P}(x)$.

Definition (axiom of separation) open_in_new

For each $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, z}$, define $$ \begin{align*} \mathsf{Sep}_ϕ := \forall v_0 \ldots \forall v_{n-1} \ \forall x\ \exists s\ \forall z(z\in s \Leftrightarrow (z\in x\wedge ϕ)). \end{align*} $$

The collection of all $\mathsf{Sep}_ϕ$ is $\mathsf{Sep}$, the axiom schema of separation.

By $\mathsf{Ext}$, for each $ϕ\in \op{Fml}^\in$, $x\in X$, $\v v\in X^n$ this defines a unique object in a model $X$, denoted $\sb{z\in x}{ϕ}$.

Definition (finite set theory) open_in_new

Finite set theory $\mathsf{FST}$ is the axiom system consisting of $\mathsf{Ext}$, $\mathsf{Emp}$, $\mathsf{Pair}$, $\mathsf{Union}$, $\mathsf{Powerset}$, and $\mathsf{Sep}$.

Definition (successor, inductive set, axiom of infinity) open_in_new

Work in finite set theory.

For any set $x$, the successor of $x$ is $s(x) := x \cup \set{x}$.

A set $a$ is inductive if it satisfies the formula $$ \begin{align*} \op{ind}(a) := \emptyset \in a \ \wedge \ \forall x(x\in a \Rightarrow s(x) \in a). \end{align*} $$

The axiom of infinity is the formula $$ \begin{align*} \mathsf{Inf} := \exists a \ \op{ind}(a). \end{align*} $$

Definition (axiom of replacement) open_in_new

For each $ϕ\in{}$$\mathrm{Fml}^\in$ with $\op{free}(ϕ) = \set{v_0, \ldots, v_{n-1}, v, w}$, write $ϕ \tfrac{x}{v} \tfrac{y}{w}$ for the formula where we replace all $v$ and $w$ in $ϕ$ with $x$ and $y$ respectively. Define $$ \begin{align*} \mathsf{Repl}_ϕ :={} \quad &\forall v_0 \ldots \forall v_{n-1}\ \forall x \forall y \forall y' (ϕ \tfrac{x}{v} \tfrac{y}{w} \wedge ϕ \tfrac{x}{v} \tfrac{y'}{w} \Rightarrow y = y') \\ \Rightarrow{}& \forall v_0 \ldots \forall v_{n-1}\ \forall d \exists r \ \forall y(y\in r \Leftrightarrow \exists x(x\in d \wedge \phi \tfrac{x}{v} \tfrac{y}{w})). \end{align*} $$ $ϕ$ is said to be functional if the premise holds.

The collection of all $\mathsf{Repl}_ϕ$ is $\mathsf{Repl}$, the axiom schema of replacement.

Definition (axiom of choice) open_in_new

In the language of set theory, let $x$ be a set. $f$ is a choice function for $x$ if it satisfies $$ \begin{align*} \op{cf}(f, x) := \bigl(f: x\to \bigcup x\bigr) \wedge \forall y \bigl(y\in x \wedge y\neq \emptyset \Rightarrow f(y) \in y\bigr). \end{align*} $$

The axiom of choice is the $\in$-formula $$ \begin{align*} \mathsf{AC} := \forall x \exists f\ \op{cf}(f,x). \end{align*} $$

Definition (axiom of foundation) open_in_new

The axiom of foundation is the $\in$-formula $$ \begin{align*} \mathsf{Found} := \forall x (x \neq \emptyset \Rightarrow \exists m (m\in x \wedge m \cap x = \emptyset)). \end{align*} $$

$m \cap x = \emptyset$ iff $m$ is $\in$-minimal in $x$.

Definition (Zermelo–Fraenkel set theory) open_in_new

Define the following axiom systems:

  • $\mathsf{Z} :={}$$\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Found}$, the Zermelo set theory.

  • $\mathsf{ZC} := \mathsf{Z}$ + $\mathsf{AC}$, the Zermelo set theory with choice.

  • $\mathsf{ZF} := \mathsf{Z}$ + $\mathsf{Repl}$, the Zermelo-Fraenkel set theory.

  • $\mathsf{ZFC} := \mathsf{ZF}$ + $\mathsf{AC}$, the Zermelo-Fraenkel set theory with choice.

Reconstruction of abstract mathematics in finite set theory open_in_new

We can reconstruct abstract operations in finite set theory:

  • Ordinary (binary) union: $x \cup y := \bigcup \set{x,y}$ (using $\mathsf{Pair}$ and $\mathsf{Union}$)

  • Intersection: $x \cap y := \sb{z\in x}{z\in y} = \sb{z\in y}{z\in x}$ (using $\mathsf{Sep}$).

  • Ordered pair: $(x,y) := \set{\set{x}, \set{x,y}}$ known as the Kuratowski pair.

    This has the property $(x, y) = (x', y')$ iff $x = x'$ and $y = y'$.

  • The Cartesian product $$ \begin{align*} a \times b := \sb{p\in \mathcal{P}(\mathcal{P}(a\cup b))}{\exists x\exists y(x\in a \wedge y\in b\wedge p = (x,y))} \end{align*} $$ using $\mathsf{Powerset}$ and $\mathsf{Sep}$.

Definition (relation) open_in_new

For sets $a,b$, an element $r\in \mathcal{P}(a\times b)$ is a relation between $a$ and $b$.

  • $r$ is functional if $\forall x \forall y \forall y'\ (x,y)\in r \wedge (x,y')\in r \Rightarrow y = y'$.

  • $r$ is total if $\forall x\ x\in a \Rightarrow \exists y(y\in b \wedge (x,y)\in r)$.

  • $r$ is a function if $r$ is functional and total.

  • $r$ is injective if $\forall x\forall x'\forall y\ (x,y)\in r \wedge(x', y)\in r \Rightarrow x = x'$.

  • $r$ is surjective if $\forall y\ y \in b \Rightarrow \exists x(x\in a \wedge (x,y)\in r)$.

Then $r$ is called a binary relation on $a$.

  • $r$ is reflexive if $\forall x\ (x,x)\in r$.

  • $r$ is irreflexive if $\forall x\ (x,x)\not\in r$.

  • $r$ is symmetric if $\forall x\forall y\ (x,y)\in r \Leftrightarrow (y,x)\in r$.

  • $r$ is transitive if $\forall x\forall y\forall z\ ((x,y)\in r\wedge (y,z)\in r) \Rightarrow (x,z)\in r$.

  • $r$ is antisymmetric if $\forall x\forall y ((x,y)\in r \wedge (y,x)\in r) \Rightarrow x=y$.

  • $r$ is linear if $\forall x\forall y\ (x,y)\in r \vee (y,x)\in r\vee x=y$.

  • $r$ is a partial order if it is reflexive, transitive and antisymmetric.

  • $r$ is a strict partial order if it is irreflective and transitive.

  • $r$ is a linear order if it is a partial order which is linear.

  • $r$ is a strict linear order if it is a strict partial order which is linear.

  • $r$ is an equivalence relation if it is reflexive, symmetric and transitive.

Definition (construction of natural numbers from Inf) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$.

For an inductive set $a$, which exists by $\mathsf{Inf}$, define by $\mathsf{Sep}$ $$ \begin{align*} N_a := \sb{z\in a}{\forall x(\op{ind}(x) \Rightarrow z\in x)}. \end{align*} $$ Check this does not depend on $a$ and is the smallest inductive set. Call this $$ \begin{align*} \N := N_a \end{align*} $$ and call its elements the natural numbers.

Write $0 := \emptyset$, $1 := s(0) = \set{0} = \set{\emptyset}$, $2 := s(1) = \set{0, 1} = \set{\emptyset, \set{\emptyset}}$, $3 := s(2) = \set{0, 1, 2} = \set{\emptyset, \set{\emptyset}, \set{\emptyset, \set{\emptyset}}}$ etc.

Definition (minimal element, well-founded relation) open_in_new

Let $R$ be a binary relation of a set $X$.

For a subset $S\subseteq X$, an $R$-minimal element of $S$ is an element $m\in S$ such that for all $s\in S$, it is not the case that $sRm$.

$R$ is well-founded if all subsets of $X$ have an $R$-minimal element.

Definition (transitive set) open_in_new

A set $x$ is transitive if for all sets $y,z$, if $z\in y\in x$, then $z\in x$.

Equivalently, all elements of $x$ are subsets of $x$.

Definition (finite, infinite, countable, uncountable, countably infinite) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$.

Well-orders open_in_new

Theorem (order induction and well-foundedness) open_in_new

Let $\mathbf{X} = (X, <)$ be a strict partial order. Write $\op{pred}(x) := \sb{z\in X}{z<x}$ for $x\in X$.

$\mathbf{X}$ is well-founded iff it satisfies order induction, i.e. for all $A\subseteq X$, if there holds $$ \begin{align*} \forall x\in X (\op{pred}(x) \subseteq A \implies x\in A), \end{align*} $$ then $A = X$.

Proof

Theorem (recursion) open_in_new

Work in finite set theory.

Let $(X, <)$ be a well-founded strict partial order and $ϕ$ be an $\in$-formula with $\op{free}(ϕ) = \set{a,b,c}$. Suppose

  • $ϕ$ is functional: for all $a,b\in X$ and $c,c'$ sets, if $ϕ(a,b,c)$ and $ϕ(a,b,c')$ hold, then $c = c'$; and

  • $ϕ$ is total: for all $a,b\in X$, there exists $c$ such that $ϕ(a,b,c)$ holds.

Assume either

  • $\mathsf{Repl}$ holds; or

  • there exists some $r$ such that for all $a,b\in X$, if $ϕ(a,b,c)$ holds, then $c\in r$.

Then there exists a unique function $F$ with domain $X$ such that for all $x\in X$, $$ \begin{align*} F(x) = z \iff ϕ(x, F|_{\op{pred}(x)}, z). \end{align*} $$

Proof

Proposition (transitive closure) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Repl}$.

For all sets $x$, there exists a smallest transitive superset $t \supseteq x$, i.e. if $t'\supseteq x$ is a transitive set, then $t' \supseteq t$. We call $\op{tcl}(x) := t$ the transitive closure of $x$.

Proof

Definition (well-order, initial segment) open_in_new

A well-order $\mathbf{X} = (X, <)$ is a well-founded strict linear order.

An initial segment of $\mathbf{X}$ is a subset $A \subseteq X$ such that $\op{pred}(x) \subseteq A$ for all $x\in A$.

$A$ is a proper initial segment iff $A = \op{pred}(x)$ for some $x\in X$. Proof

If $A \subseteq X$ is a subset, then $(A, {<} \cap (A \times A))$ is a wellorder.

Definition (sum of well-orders) open_in_new

Let $\mathbf{X}$ and $\mathbf{Y}$ be well-orders. Assume $X$ and $Y$ are disjoint.

Their sum is $\mathbf{X} \oplus \mathbf{Y} := (X \sqcup Y, <^+)$, where $$ \begin{align*} a <^+ b :\iff \begin{cases} a\in X, b\in X, a<b, & \text{or} \\ a\in Y, b\in Y, a<b, & \text{or} \\ a\in X, b\in Y. \end{cases} \end{align*} $$ This is a well-order.

Writing $\mathbf{1} = (1, <)$, $s(X)$ is isomorphic to $\mathbf{X} \oplus \mathbf{1}$.

Definition (product of well-orders) open_in_new

Let $\mathbf{X}$ and $\mathbf{Y}$ be well-orders.

Their product is $\mathbf{X} \otimes \mathbf{Y} := (X \times Y, <^\times)$, where $<^\times$ follows reverse lexicographical order: $$ \begin{align*} (x,y)<^\times (x', y') :\iff y < y' \vee (y = y' \wedge x< x'). \end{align*} $$ This is a well-order.

Proposition (uniqueness of isomorphisms between well-orders) open_in_new

Let $\mathbf{X}$ and $\mathbf{Y}$ be well-orders, and let $A,B \subseteq Y$ be initial segments.

If $f: \mathbf{X} \to \mathbf{A}$ and $g: \mathbf{X} \to \mathbf{B}$ are isomorphisms of well-orders, then $A = B$ and $f = g$.

Proof

This shows a well-order is not isomorphic to any proper initial segment.

Theorem (fundamental theorem of well-orders) open_in_new

Let $A$ be a set of well-orders such that no two distinct elements are isomorphic.

Then $(A, \prec)$ is a well-order, where $\mathbf{X}\prec \mathbf{Y}$ iff there is an isomorphism from $\mathbf{X}$ to a proper initial segment of $\mathbf{Y}$.

Proof

Ordinals open_in_new

Definition (ordinal) open_in_new

A set $α$ is an ordinal if it is a transitive set and $(α, \in)$ is a well-order.

An ordinal $α$ is either

  • zero $α = \emptyset$;

  • a successor ordinal if $α = s(β)$ for some ordinal $β$; or

  • a limit ordinal if otherwise.

Write $α<β$ for $α\in β$.

If $x\in α$, then $\op{pred}(x) = \sb{y\in α}{y\in x} = x$ as $x\subseteq α$. So proper initial segments of $α$ are precisely elements of $α$.

Elements of ordinals are ordinals. (Proof)

If $α \isom β$ as well-orders, then $α = β$. (Proof)

$α\prec β$ iff $α\in β$. (Proof)

A transitive set of ordinals is an ordinal. (Proof) Therefore if $A$ is a set of ordinals, then $\bigcup A$ is an ordinal.

Assuming $\mathsf{Inf}$, we write $ω = \N$.

Theorem (transfinite induction) open_in_new

Let $ϕ$ is a formula with one free variable. Suppose

  • $ϕ(0)$ holds;

  • for all ordinal $α$, if $ϕ(α)$ holds, then $ϕ(s(α))$ holds; and

  • for all limit ordinal $λ$, if $ϕ(α)$ holds for all ordinals $α<λ$, then $ϕ(λ)$ holds.

Then $ϕ(α)$ holds for all ordinals $α$.

Proof

Ordinal arithmetic open_in_new

Define by transfinite recursion $$ \begin{align*} α + 0 &:= α & α\cdot 0 &:= 0 & α^0 &:= 1 \\ α + s(β) &:= s(α + β) & α\cdot s(β) &:= α \cdot β + α & α^{s(β)} &:= α^β \cdot α \\ α + λ &:= \bigcup \sb{α+γ}{γ<λ} & α\cdot λ &:= \bigcup \sb{α\cdot γ}{γ<λ} & α^λ &:= \bigcup \sb{α^γ}{γ<λ}. \end{align*} $$

  • Commutativity fails for all three.

  • Addition:

    • $(α + β, \in)\isom (α, \in)$${}\oplus{}$$(β, \in)$.

    • Associativity holds.

    • $α + 0 = α = 0 + α$.

    • Increasing: if $α < β$, then $γ + α < γ + β$ but $α + γ \leq β + γ$.

    • Left cancellation: if $α + β = α + γ$, then $β = γ$.

    • Left subtraction: if $α\leq β$, then there is a unique $δ$ such that $α + δ = β$.

  • Multiplication:

    • $(α\cdot β, \in)\isom(α, \in)$${}\otimes{}$$(β, \in)$

    • Associativity holds.

    • $α \cdot 0 = 0 = 0 \cdot α$.

    • $α \cdot 1 = α = 1 \cdot α$.

    • Increasing: If $α<β$ and $γ>0$, then $γ \cdot α < γ \cdot β$ but $α \cdot γ \leq β \cdot γ$.

    • Left cancellation: if $α \cdot β = α \cdot γ$ and $α>0$, then $β = γ$.

  • Left distributivity: $α\cdot (β + γ) = α \cdot β + α\cdot γ$.

  • Exponentiation:

    • $α^0 = 1$.

    • $0^α = 0$ if $α>0$.

    • $α^1 = 1$.

    • $1^α = 1$.

    • $α^{β + γ} = α^β \cdot α^{γ}$.

    • $α^{βγ} = (α^β)^γ$.

    • If $α<β$ and $γ>1$, then $γ^α < γ^β$.

    • If $α<β$, then $α^γ \leq β^{γ}$.

    • If $α^β = α^γ$ and $α>1$, then $β = γ$.

Theorem (Zorn's lemma) open_in_new

Let $\mathbf{P} = (P, \leq)$ be a partial order.

Say $p\in P$ is an (upper) bound of a subset $A\subseteq P$ if $a\leq p$ for all $a\in A$. If such $p$ exists, say $A$ is bounded.

Zorn's lemma $\mathsf{ZL}$ is the statement "all non-empty chain-complete partial orders have a maximal element".

In $\mathsf{FST}$ + $\mathsf{Repl}$, $\mathsf{ZL}$ is equivalent to $\mathsf{AC}$.

Definition (initial ordinal, cardinal) open_in_new

An ordinal $α$ is called initial if $|γ| < |α|$ for all $γ<α$. An initial ordinal is called a cardinal.

In $\mathsf{FST}$ + $\mathsf{Repl}$, if $X$ is a set which can be well-ordered (which is always the case assuming $\mathsf{AC}$), write $|X|$ for the unique cardinal in bijection with $X$.

If $κ$ is an initial ordinal, then $κ$ is the minimal element of $\sb{\text{ordinal }α}{|α| = |κ|}$.

Definition (von Neumann universe, Mirimanoff rank) open_in_new

Define by transfinite recursion $$ \begin{align*} V_0 ={}& \emptyset, \\ V_{s(α)} ={}& \mathcal{P}(V_α), \\ V_λ ={}& \bigcup_{α<λ} V_α, &&\text{$λ$ is a limit ordinal}. \end{align*} $$

A set $x$ is a von Neumann set if $x\in V_α$ for some ordinal $α$. The class of all von Neumann sets is called the von Neumann universe.

If $x$ is von Neumann, its Mirimanoff rank is the minimum $α$ such that $x\in V_{α+1}$ (or equivalently $x \subseteq V_α$).

$V_α$ is transitive by transfinite induction.

$α\in V_{α+1}$ for any ordinal $α$. Moreover $\set{\text{ordinals in }V_α} = α$.

For $x$ von Neumann, $$ \begin{align*} ρ(x) = \bigcup \sb{ρ(y)+1}{y \in x}. \end{align*} $$
