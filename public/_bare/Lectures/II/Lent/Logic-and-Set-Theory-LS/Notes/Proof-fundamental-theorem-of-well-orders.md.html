Transitivity

If $\mathbf{X} \prec \mathbf{Y} \prec \mathbf{Z}$ with isomorphisms $f: \mathbf{X} \to \mathbf{Y}'$, $g: \mathbf{Y}\to \mathbf{Z}'$ where $Y'\subseteq Y$ and $Z'\subseteq Z$ are proper initial segments, then $g \circ f: \mathbf{X} \to \mathbf{Z}''$ is an isomorphism, where $Z''\subseteq Z'$ is the range of $g$. Note $Z''$ is a proper initial segment of $Z'$ so of $Z$, so $\mathbf{X} \prec \mathbf{Z}$.

Linearity

Given $\mathbf{X}, \mathbf{Y}\in A$, introduce a new element $\mathrm{STOP}\not\in Y$, and construct by recursion $$ \begin{align*} f: X&\to Y \cup \set{\mathrm{STOP}} \\ x &\mapsto \begin{cases} y &\text{if $Y \setminus \op{ran}(f|_{\op{pred}(x)})\neq \emptyset$ and $y$ is its minimal element}, \\ \mathrm{STOP} &\text{otherwise}. \end{cases} \end{align*} $$

Two cases:

  1. If $\mathrm{STOP} \in \op{ran}(f)$, by well-foundedness find a minimal $x\in X$ such that $f(x) = \mathrm{STOP}$. Then $f|_{\op{pred}(x)}: \op{pred}(x)\to Y$ is a surjection. By construction, it is a isomorphism, so $\mathbf{Y} \prec \mathbf{X}$.

  2. If $\mathrm{STOP} \not\in \op{ran}(f)$, then $f: X\to \op{ran}(f) \subseteq Y$ is an isomorphism from $X$ to an initial segment of $Y$.

    If $\op{ran}(f) = Y$, then $\mathbf{X}\isom \mathbf{Y}$, so by hypothesis, $\mathbf{X} = \mathbf{Y}$. Otherwise $\mathbf{X} \prec \mathbf{Y}$.

Well-foundedness

Let $B\subseteq A$ be a non-empty subset, and take any $\mathbf{X} \in B$. If $\mathbf{X}$ is $\prec$-minimal, done. Otherwise, $B_\mathbf{X} := \sb{\mathbf{Y}\in B}{\mathbf{Y} \prec \mathbf{X}}$ is non-empty, and a minimal element of $B_\mathbf{X}$ is a minimal element of $B$. By definition of $\prec$, for each $\mathbf{Y}\in B_\mathbf{X}$, there exists $x_\mathbf{Y}\in X$ such that $\mathbf{Y} \isom \op{pred}(x_\mathbf{Y})$, which is unique.

Apply separation to construct $$ \begin{align*} \sb{x\in \mathbf{X}}{\exists \mathbf{Y}\in B_\mathbf{X}: x = x_\mathbf{Y}} \subseteq \mathbf{X}, \end{align*} $$ which is non-empty. By well-foundedness of $\mathbf{X}$, find a minimal $x_0$ of this set and the corresponding $\mathbf{Y}_0 \in B_\mathbf{X}$. For any other $\mathbf{Y}\in B_\mathbf{X}\setminus \set{\mathbf{Y}_0}$, since $x_{\mathbf{Y}_0} < x_\mathbf{Y}$, we have $\mathbf{Y}_0 \isom \op{pred}(x_\mathbf{Y_0}) \prec \op{pred}(x_\mathbf{Y}) \isom\mathbf{Y}$, so $\mathbf{Y}_0$ is $\prec$-minimal in $B$.
