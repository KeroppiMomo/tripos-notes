A set $α$ is an ordinal if it is a transitive set and $(α, \in)$ is a well-order.

An ordinal $α$ is either

  • zero $α = \emptyset$;

  • a successor ordinal if $α = s(β)$ for some ordinal $β$; or

  • a limit ordinal if otherwise.

Write $α<β$ for $α\in β$.

If $x\in α$, then $\op{pred}(x) = \sb{y\in α}{y\in x} = x$ as $x\subseteq α$. So proper initial segments of $α$ are precisely elements of $α$.

Elements of ordinals are ordinals. (Proof)

If $α \isom β$ as well-orders, then $α = β$. (Proof)

$α\prec β$ iff $α\in β$. (Proof)

A transitive set of ordinals is an ordinal. (Proof) Therefore if $A$ is a set of ordinals, then $\bigcup A$ is an ordinal.

Assuming $\mathsf{Inf}$, we write $ω = \N$.
