The language of set theory or $\in$-language is the signature with a single binary relation $\in$.

The formulae in this language are called $\in$-formulae. The set of all $\in$-formulae is denoted $\mathrm{Fml}^\in$.

Structures in this language are called $\in$-structures and can be represented as a directed graph $\mathbf{X} = (X, E)$ where $E \subseteq X^2$.

We will use abbreviations in $\in$-formulae, e.g. $ϕ \Leftrightarrow ψ$ for $ϕ\Rightarrow ψ\wedge ψ \Rightarrow ϕ$, $x\not\in y$ for $\neg x \in y$ etc.
