Define by transfinite recursion $$ \begin{align*} α + 0 &:= α & α\cdot 0 &:= 0 & α^0 &:= 1 \\ α + s(β) &:= s(α + β) & α\cdot s(β) &:= α \cdot β + α & α^{s(β)} &:= α^β \cdot α \\ α + λ &:= \bigcup \sb{α+γ}{γ<λ} & α\cdot λ &:= \bigcup \sb{α\cdot γ}{γ<λ} & α^λ &:= \bigcup \sb{α^γ}{γ<λ}. \end{align*} $$

  • Commutativity fails for all three.

  • Addition:

    • $(α + β, \in)\isom (α, \in)$${}\oplus{}$$(β, \in)$.

    • Associativity holds.

    • $α + 0 = α = 0 + α$.

    • Increasing: if $α < β$, then $γ + α < γ + β$ but $α + γ \leq β + γ$.

    • Left cancellation: if $α + β = α + γ$, then $β = γ$.

    • Left subtraction: if $α\leq β$, then there is a unique $δ$ such that $α + δ = β$.

  • Multiplication:

    • $(α\cdot β, \in)\isom(α, \in)$${}\otimes{}$$(β, \in)$

    • Associativity holds.

    • $α \cdot 0 = 0 = 0 \cdot α$.

    • $α \cdot 1 = α = 1 \cdot α$.

    • Increasing: If $α<β$ and $γ>0$, then $γ \cdot α < γ \cdot β$ but $α \cdot γ \leq β \cdot γ$.

    • Left cancellation: if $α \cdot β = α \cdot γ$ and $α>0$, then $β = γ$.

  • Left distributivity: $α\cdot (β + γ) = α \cdot β + α\cdot γ$.

  • Exponentiation:

    • $α^0 = 1$.

    • $0^α = 0$ if $α>0$.

    • $α^1 = 1$.

    • $1^α = 1$.

    • $α^{β + γ} = α^β \cdot α^{γ}$.

    • $α^{βγ} = (α^β)^γ$.

    • If $α<β$ and $γ>1$, then $γ^α < γ^β$.

    • If $α<β$, then $α^γ \leq β^{γ}$.

    • If $α^β = α^γ$ and $α>1$, then $β = γ$.
