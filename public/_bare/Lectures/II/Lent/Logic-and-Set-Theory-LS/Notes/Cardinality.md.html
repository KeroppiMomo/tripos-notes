Definition (cardinality) open_in_new

Let $X,Y$ be sets.

$X,Y$ are said to be of the same size, equinumerous or equivpollent if there is a bijection $X\to Y$. We write $|X| = |Y|$.

We write $|X| \leq |Y|$ if there is an injection $X\to Y$.

Assuming $\mathsf{AC}$, $|X|\leq |Y|$ iff there is a surjection $Y \to X$.

Theorem (Cantor-Schröder-Bernstein) open_in_new

Work in a model of $\mathsf{ZF}$. Let $X, Y$ be sets.

If $|X|\leq |Y|$ and $|Y| \leq |X|$, then $|X| = |Y|$.

Definition (initial ordinal, cardinal) open_in_new

An ordinal $α$ is called initial if $|γ| < |α|$ for all $γ<α$. An initial ordinal is called a cardinal.

In $\mathsf{FST}$ + $\mathsf{Repl}$, if $X$ is a set which can be well-ordered (which is always the case assuming $\mathsf{AC}$), write $|X|$ for the unique cardinal in bijection with $X$.

If $κ$ is an initial ordinal, then $κ$ is the minimal element of $\sb{\text{ordinal }α}{|α| = |κ|}$.

If $κ, λ$ are initial ordinals, then either $|κ|<|λ|$, $κ = λ$, or $|κ|>|λ|$.

If $A$ is a set of initial ordinals, then $\bigcup A$ is also an initial ordinal.

Definition (aleph numbers) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Repl}$. Define by transfinite recursion

  • $\aleph_0 :={}$$ω$,

  • $\aleph_{s(α)} :={}$$\aleph$$(\aleph_α)$,

  • $\aleph_γ := \bigcup \sb{\aleph_α}{α<λ}$ if $λ$ is a limit ordinal.

An ordinal is called an aleph if it is $\aleph_α$ for some $α$.

$\aleph_α$ is called a successor cardinal if $α$ is a successor ordinal. Otherwise it is a limit cardinal.

By transfinite induction, $\aleph_α$ is a cardinal for all ordinal $α$.

Theorem (all infinite cardinals are alephs) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Repl}$.

Any infinite cardinal is an aleph.

Proof

Theorem (Hessenberg) open_in_new

Proposition (cardinal addition and multiplication) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Repl}$.

Define cardinal addition and multiplication by $$ \begin{align*} κ + λ &:= |κ \oplus λ| = |κ \times \set{0} \cup λ \times \set{1}|, \\ κ \cdot λ &:= |κ \otimes λ| = |κ \times λ|. \end{align*} $$

For cardinals $κ,λ$ with both at least 1 and either infinite, $$ \begin{align*} κ + λ = \max\set{κ, λ} = κ\cdot λ. \end{align*} $$

Proof

Definition (cardinal exponentiation) open_in_new

Work in a model of $\mathsf{FST}$ + $\mathsf{Repl}$ + $\mathsf{AC}$. For cardinals $κ, λ$, define $$ \begin{align*} κ^λ = \left|\sb{f\in \mathcal{P}(λ\times κ)}{f: λ\to κ}\right|. \end{align*} $$

  • $(κ$${}\cdot{}$$λ)^μ = κ^μ \cdot λ^μ$;

  • $κ^{λ + μ} = κ^λ \cdot κ^μ$;

  • $κ^{λ\cdot μ} = (κ^λ)^{μ}$;

  • If $κ\leq λ$, then $κ^μ \leq λ^μ$ and $μ^κ \leq μ^λ$.

  • $|\mathcal{P}(λ)| = 2^λ$.

  • $|\R| = 2^{\aleph_0}$.

Lemma (cardinal exponentiation with small base) open_in_new

Work in $\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Repl}$ + $\mathsf{AC}$.

Let $κ,λ$ be cardinals. If $λ$ is infinite and $2\leq κ\leq{}$$λ^+$, then the exponentiation satisfies $$ \begin{align*} κ^λ = 2^λ. \end{align*} $$

Proof

Definition (beth numbers) open_in_new

Work in a model of $\mathsf{FST}$ + $\mathsf{Inf}$ + $\mathsf{Repl}$ + $\mathsf{AC}$. Define by transfinite recursion

  • $\beth_0 :={}$$ω$,

  • $\beth_{s(α)} :={}$$2^{\beth_α}$,

  • $\beth_{λ} := \bigcup \sb{2^{\beth_α}}{α<λ}$.

By induction, $\aleph_α$${}\leq \beth_α$ because $\aleph(κ) = κ^+ \leq 2^κ$.
