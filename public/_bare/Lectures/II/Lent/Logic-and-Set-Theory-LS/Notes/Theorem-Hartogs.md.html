For every set $X$, there is a smallest ordinal $\aleph(X)$, called the Hartogs aleph of $X$, which does not inject into $X$.

Proof

Therefore $|X| < |\aleph(X)|$, so there is no set of largest size.

$\aleph(X)$ is an cardinal. For $κ$ a cardinal, its cardinal successor is $κ^+ := \aleph(κ)$.
