Let $ξ$ be an ordinal. Define a relation on $ξ\times ξ$ by $$ \begin{align*} (α, β) < (γ, δ) \iff &\max(α, β) < \max(γ, δ) \\ &\text{or }(\max(α, β) = \max(γ, δ) \text{ and }α<γ) \\ &\text{or }(\max(α, β) = \max(γ, δ) \text{ and }β < δ). \end{align*} $$

(Illustration)

Note $(ξ \times ξ, <)$ is a well-order. Then by the representation theorem, there exists a unique ordinal $γ_ξ$ with an isomorphism $g_ξ: (ξ \times ξ, <) \to (γ_ξ, \in)$. Then $|γ_ξ| = |ξ \times ξ|$. Moreover, if $ξ < η$, then $ξ \times ξ$ is an $<$-initial segment of $η$, so $g_ξ = g_η|_{ξ \times ξ}$ by uniqueness. We therefore drop the subscript and write $g$.

Perform transfinite induction to show $κ = γ_κ$ for all infinite cardinal $κ$. For $κ = ω$, notice $g_ω: \N \times \N\to \N$ is an isomorphism.

Now suppose $κ>ω$ is an infinite cardinal and $γ_δ = δ$ for all infinite cardinals $δ<κ$. Consider $(α, β)\in κ \times κ$ with either $α,β$ infinite (which exists as $κ>ω$). Take $δ = s(\max\set{α, β})$, which is infinite and satisfies $(α,β)\in δ \times δ$. This implies $g(α,β) < γ_δ$ and so $|g(α,β)| \leq |γ_δ| = |δ \times δ|$. Moreover as $κ$ is an infinite cardinal, $κ$ is a limit ordinal, so $δ<κ$ and hence $|δ| < κ$.

By the induction hypothesis, $|δ| = |γ_{|δ|}| = |δ \times δ|$, so putting everything together, $$ \begin{align*} |g(α,β)| \leq |δ\times δ| = |δ| < κ \end{align*} $$ so $$ \begin{align*} g(α,β) < κ \end{align*} $$ for all $(α,β) \in κ \times κ$. Therefore $γ_κ\leq κ$.

Finally since $|γ_κ| = |κ \times κ| \geq κ$, we have $γ_κ \geq κ$. Hence $γ_κ = κ$.
