An analytic function element is a pair $(f, D)$ where $D \subset \C$ is a domain and $f: D\to \C$ is analytic.

Say $(g,E)$ is a direct analytic continuation of $(f,D)$ (written $(f,D)\sim (g,E)$) if $D \cap E \neq \emptyset$ and $f|_{D\cap E} = g|_{D\cap E}$.

Say that $(g,E)$ is an analytic continuation of $(f,D)$ (written $(f, D) \approx (g, E)$) if there exists function elements $(f_i, D_i)$ for $0\leq i\leq n$ with $(f_0, D_0) = (f, D), (f_n, D_n) = (g,E)$ and $(f_i, D_i) \sim (f_{i+1}, D_{i+1})$ for all $0\leq i<n$. This is an equivalence relation.

If $γ: [0,1]\to \C$ is continuous, say $(g,E)$ is an analytic continuation of $(f,D)$ along $γ$ if

  • $γ(i/n) \in D_i$ for all $i=0,1,\ldots,n$, and

  • $γ([i/n, (i+1)/n]) \subseteq D_i \cup D_{i+1}$ for all $i=0,1,\ldots,n-1$.

A complete analytic function is an equivalence class under $\approx$.
