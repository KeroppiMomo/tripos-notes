Let $D\subseteq \C$ be a domain. A function $f: D\to \R$ is harmonic if $$ \begin{align*} 0 = Δ f \equiv f_{x x} + f_{y y}. \end{align*} $$

Let $X$ be a Riemann surface. A function $f: X\to \R$ is harmonic if for all charts $(U, ϕ)$ in some atlas, $f \circ ϕ\inv: ϕ(U)\to \R$ is harmonic.

If $D$ is a disc, then $f$ is harmonic iff it is the real part of some analytic function $D\to \C$. (Proof)

Identity principle: $\sb{x\in X}{f(x) = 0}$ either is $X$ or has empty interior.
